# 068 — 采音方式：全踩 / 舍音 / 留白（官方谱的分布倾向）

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：160 首官方 ST 曲包（官方 mp3 × 官方 `&inote_5`，定数 13.0–14.5）的 **13 535 个小节**，逐小节按"骨架轨"统计；**"这一小节算哪个词"的切点是工具内部诊断口径**（`tools/calibration/sampling.py`），**不是术语定义**，也不向用户索取。

- **日期**：2026-09-20
- **要点**：描述"目标音轨的音被踩了多少"，社区谱师用三个词——**全踩**（把这条轨的音基本都踩上）、**舍音**（只踩一部分、舍掉一部分）、**留白**（音乐有音而谱面故意不踩）。官方谱的分布倾向是：**默认全踩**，**越难的段落越往舍音和留白走**，而**踩下去的音总量几乎不变**——省的是"踩满"，不是"踩多少"。
- **详情**：

  1. **三词的分布**：全踩最多、舍音其次、留白少；另有约一成小节音轨本身就没发出几个音，**判不出、不下结论**（不算一种采音方式）。
  2. **越难越省着采**：在**体力**与**手序**这两条互相独立的难度轴上方向一致——难的那一档里**舍音与留白一起上升、全踩下降**，而"踩了多少个音"这个量几乎不动。**硬配置是用"同样多的音、更狠的摆位"换来的，不是用"更多的音"换来的。**
  3. **一只手被星星／长条钉住的配置天然舍音**：拆弹、同起点拍滑、一笔画、双压连续拍滑、出张、连续拍滑、井字星星、定拍、绕圈星星、鼓动段、三叉戟、穿心、错位、挥手段——另一只手只能挑着踩。**可以反过来用：想让某段变成舍音，就给一只手派一条星星线。**
  4. **手型预先定死、不跟音走的几何配置几乎全踩**：三角交互、楼梯交互、散点、轴交互、普通交互。
  5. **舍音时踩的多半是"显眼的音"**（社区叫**主高**），但这个比例**不随难度变化**——**不能说"难的地方谱师更讲究踩重音"**。
  6. **骨架轨决定默认疏密**：以鼓为骨架时更常舍音；以 `other` / `vocals` / `piano` 为骨架时更接近全踩（知识 032「鼓骨架 + 非鼓填充」在采音疏密侧的对应面）。
  7. **低 BPM 曲天然采得省**：BPM 越低、每小节音轨给的音越多，谱面反而踩得更少——这是知识 003 第 4 条「低 BPM ≠ 简单」的另一面：**低 BPM 不要试图踩满**。
  8. **谱师的主动选择不体现在"采多少"上**：曲内逐小节看，"踩了几成"主要跟**谱面密度 ÷ 音轨密度**走，跟音乐强度、跟配置难度都几乎不相关。真正要设计的是**"舍音时舍哪一半"**与**"要不要采空音"**。

  **证据注脚（数字只作注脚，不作要点）**：全踩 59.2% / 舍音 24.3% / 留白 8.4% / 判不出 8.1%；去环体力硬度低→高 舍音 22.0%→29.2%、留白 7.7%→9.8%、全踩 59.9%→55.8%，coverage 0.698→0.665；手序难度低→高 同向；舍音中"踩重音"低/中/高档 65.1%/65.5%/65.3%（随机平移对照 58%）；三角 93.2% 全踩、楼梯 95.0%，拆弹 59.5% 舍音、同起点拍滑 51.4%；鼓骨架 coverage 0.663 vs other/vocals/piano 0.73–0.74；ρ(BPM, 每小节候选音数) = −0.653；曲内 ρ(谱面 note/小节, coverage) = +0.437 而 ρ(强度, coverage) ≈ +0.04。

- **理由**：160 首官方音频 × 官方谱逐小节实测；随机平移对照下 coverage 从 0.687 掉到 0.422、全踩从 33.4% 掉到 7.2%，**分布不是密度伪影**。三个词取自中文制谱社区实际用语（见知识 081），不是 agent 自造类名。
- **来源**：`docs/research/sampling-mode-study.md` §10（三词重跑）/§11（社区术语校正）；`docs/research/configs-hand-rewrite.md` §7；工具 `tools/calibration/sampling.py`。
- **置信度**：**经验（agent 观察，n=160 首 / 13 535 小节，骨架轨逐小节口径，未经用户确认）** / **存疑**（① 三个词在社区里**不是一组互斥分类**，把连续的"踩了几成"切成三档是本项目的操作化；② 切点一动，绝对占比会大幅变化，只有**相对趋势**可引用；③ 人声轨的分离质量不可信，见知识 032；④ 只覆盖 ST 谱、定数 13.0–14.5）。
- **关联**：知识 **002**（切轨）、**005**（采音要简——"舍音/留白"正是"简"的谱面侧形态）、**003**（第 4 条低 BPM）、**031**（密度曲线）、**032**（踩音归因）、**069**（采音跟着音乐走）、**081**（采音术语对照）、**086**（**似踩非踩**：MMFC 5.3 的第四个社区说法——它**不是第四个档位**，而是**藏在「全踩」里**的一种写法：谱面按匀速分音铺满，但这些音并不跟音轨；指纹是 coverage 高 **+ extra 高**）；`docs/research/sampling-mode-study.md`。

# 031 — 官方谱逐小节密度曲线的实测规律

- **日期**：2026-09-11
- **要点**：388 个官方 ST 谱的逐小节 note 密度曲线呈现一组可直接当规则用的规律——**形状先验平缓、存在可玩性地板、末段最强（不减压收尾）、第二副歌只微幅加密、休息靠低密段而非空小节、约每 12 小节换一次密度基调**。
- **详情**：

  ### 1. 密度形状先验 `T_density`（结构对齐五段，归一到峰值 = 1）

  ```
  T_density = [0.62, 0.77, 0.72, 0.78, 0.82]
  95% 自助 CI 下界 [0.599, 0.747, 0.699, 0.755, 0.800]
  95% 自助 CI 上界 [0.639, 0.785, 0.744, 0.799, 0.835]        (n = 388)
  ```

  - 等分五段口径则是 `[0.81, 0.92, 0.91, 0.97, 1.00]`（相对全曲均值 `[0.88, 0.99, 0.98, 1.06, 1.09]`）。
  - **⚠️ 口径说明：两种口径不可混用，引用时必须注明。** "结构对齐"= L2 变点检测分 5 段（**带最小段长约束 `min_len_frac=0.10`**）；"等分"= 按小节数等分 5 段。
  - **方法学坑**：变点检测若不加最小段长约束，37.4% 的谱第 5 段会短于全曲 5%，**凭空制造"尾部渐弱"的假象**。
  - 段序（由弱到强）= **1 → 3 → 2 → 4 → 5**：知识 001 的「弱 → 较强 → 较弱 → 强」前四段被 388 谱完整验证（s3 = 0.721 确实低于 s2 = 0.766，"较弱"的回落真实存在，只是等分切法会抹平它）。

  ### 2. 密度地板（映射的核心非线性）

  **音频强度可以逼近 0，谱面密度不能**——任何一小节只要还在出音，就得给出基本踩音密度。

  - 归一化逐小节密度分位（388 谱取均值）：**p10 = 0.264 / p50 = 0.514 / p90 = 0.730**（峰值 = 1）；
  - 段落尺度上地板被抬高到 **≈ 0.62**（结构对齐五段的最弱段）；
  - 建议映射式：
    ```
    density_norm = floor + (1 − floor) · intensity_norm
      段落尺度（给每段定基调）：floor ≈ 0.60
      小节尺度（段内细分）：    floor ≈ 0.25
    ```
  - 不加地板直接用形状模板驱动生成，会产出官方谱里根本不存在的"空段"。

  ### 3. 末段最强，不减压收尾

  - 曲末 10% 的密度 = **1.084 × 全曲均值**（曲末 5% 为 1.047×）；只有 32.2% 的谱曲末 10% 低于全曲均值；
  - **24.2% 的谱把高潮段放在最后 10%——这是高潮位置分布的最大单一众数**；
  - 高潮段（4 小节滑动均值最大处）相对位置：**中位 0.72**、均值 0.668、**74.7% 落在后半程**、66.2% 落在 [0.6, 1.0]；
  - 32-bin 平均曲线的末 bin 回落到 0.63 只是"最后一两小节收尾"的边缘效应，**不是段落级的渐弱**（末小节相对全曲均值的密度中位 0.73）。

  ### 4. 第二副歌更强，但幅度不大

  - 后半程 / 前半程 高密段强度比：**中位 1.119（≈ +12%）**，均值 1.150；
  - **79.6% 的谱后半强于前半**；提升 > 5% 占 69.1%、> 10% 占 55.7%。

  ### 5. 休息靠低密段，不靠空小节

  - 休息小节（note ≤ 1）**只占全曲 2.43%**，**35% 的谱一个都没有**（64.9% 至少有 1 个）；
  - 官方谱的"休息"主要靠**低密段**（归一密度 < 中位 × 0.5）实现：每谱均值 **5.91 段 × 1.69 小节**；
  - **"高密 → 低密 → 高密"三明治结构是主流：61.9% 的谱至少出现一次，每谱均值 2.41 次**——直接对应知识 002「高强度段落之间插入低强度休息段」。

  ### 6. 密度台阶 ≈ 7 个 / 谱 ≈ 每 12 小节换一次基调

  - 密度台阶（3 小节中值平滑 → 0.125 量化 → 长度 ≥ 4 小节的同档连续段）每谱均值 **7.09、中位 7**；
  - 中位小节数 85 → **平均每 12 小节换一次密度基调**。这是生成器做段落规划的天然粒度。

  ### 7. 绝对量级（note / 小节）

  | 定数档 | note/小节 均值 | p10–p90 | NPS 均值 | 峰值小节 note 均值 |
  |---|---:|---|---:|---:|
  | 13.0 | **8.03** | 6.04–10.22 | 5.29 | 15.8 |
  | 13.5 | **9.15** | 6.74–11.51 | 6.13 | 18.3 |
  | 14.0 | **10.54** | 7.58–13.65 | 7.14 | 23.2 |
  | 14.5 | 10.10 | 8.33–11.65 | 7.70 | 24.7 |
  | 全库 | 8.96 | — | — | 18.3 |

  - **峰值小节 / 全曲均值 ≈ 2.06 倍**——官方谱"最猛一小节"相对自身平均水平的天花板；
  - 小节数中位 85（p10 56 / p90 113）。

  ### 8. 强度 ≠ 密度（重要警告）

  - SPICY SWINGY STYLE（MMFC 教程举例）第二副歌密度只比第一副歌 **+5.1%**，而知识 002 说它"配置升级（单星星 → 双手星星）"；
  - 全库层面一致：后半/前半强度比中位只有 1.119。
  - → **强度提升不等于密度提升。更大的强度差异由配置复杂度（知识 003 的四大因素：note 种类 / 错位 / 位移 / BPM）承担，密度只是强度的一个维度。**

  ### 9. 形状是连续谱系，不是离散流派

  - 对 388 条 32-bin 曲线做 k-means，k=3/4/5 的**轮廓系数全部 < 0.08** → 只能当"典型倾向"描述，不可当可判别类别；
  - k=3 的三簇：全程高密平台型 40.7%（靠配置而非密度制造变化）/ 双段递进型 33.5% / 单峰后置型 25.8%；k=5 时从簇 1 分出"中段挖谷型"17.3%。
  - 推论：知识 001「谱面强度必须随歌曲情绪起伏、不能全程匀速」**部分成立但要打折**——40.7% 的官方谱密度曲线几乎不动，**密度起伏不是表达强度的唯一手段**。

  ### 10. 结尾形态统计（2026-09-11 补充）

  判据（**本项目自定，引用时必须连判据一起引**，实现见 `tools/calibration/ending.py`）：

  ```
  tail       = 逐小节密度曲线的末 N 小节
  tail_ratio = mean(tail) / mean(全曲)
  trend      = spearman(0..N-1, tail)          # −1 = 严格下降
  尾杀 : tail_ratio >= 1.00
  渐弱 : tail_ratio < 0.70 且 trend <= −0.50
  其他 : 其余
  ```

  387/388 谱（解析成功者）的结果与尾窗长度敏感性：

  | 尾窗 N | 尾杀 | 渐弱 | 其他 | `tail_ratio` 中位 | 对照口径尾杀（末段 ≥ 最后一个高密平台的 90%） |
  |---|---:|---:|---:|---:|---:|
  | 6 小节 | **62.3%**（241） | **2.3%**（9） | 35.4%（137） | 1.072 | 27.7% |
  | **8 小节** | **65.1%**（252） | **1.0%**（4） | 33.9%（131） | 1.082 | 26.1% |
  | 12 小节 | **71.6%**（277） | **1.6%**（6） | 26.9%（104） | 1.081 | 23.3% |

  - **尾杀约 2/3、渐弱 1–2%、其他 27–35%**；换 6/8/12 小节结论定性稳定（尾窗越长尾杀比例越高）。
  - **"其他" 是真实的第三类**（末段低于全曲均值但不单调下降，常见形态是"最后 1–2 小节收尾、之前仍高密"），不应并入"渐弱"。
  - 对照口径只有 23–28% → **绝大多数谱末段强于全曲均值，但弱于自己最猛的那个平台**；与上面 §3「曲末 10% = 1.084 × 全曲均值」互为交叉验证。

  **配对音频侧（8 首官方曲包，n=8，仅供参考）**：末 8 小节里 **7/8 曲的密度末段比 > 音频强度末段比**；音频真的淡出的两首（幻想のサテライト −1.55 dB、麒麟 −2.19 dB）谱面密度**也降了**（0.62、0.80），只是降幅远小于音频（0.36、0.57）。→ **谱面的收尾减压幅度系统性小于音频，但不是"谱面完全不减压"。**

- **理由**：388 个官方 ST 谱（定数 13.0–14.5，MASTER/Re:MASTER）的逐小节密度全量统计。解析覆盖率 387/388 = 99.74%；与 manifest 官方 note 计数对账：总数完全一致 376/387 = 97.16%、|Δ| ≤ 3 占 100%；知识 004 的 note 总数分布被独立复核通过（四档均值误差 ≤ 4%）。SPICY SWINGY STYLE 个案中变点检测自动找出的 4 个边界（小节 33/49/82/98）精确对应知识 002 用听感描述的「间奏 / 第一副歌 / 过渡 / 第二副歌」——**密度曲线可以当结构代理**。

# 017 — 配置：错位

- **日期**：2026-09-10
- **要点**：错位 = 在星星头与星星条启动拍之间的空拍里**塞入其他音符**的配置；本质是**双手任务错开**（一手在头线、一手在启动拍线）。
- **详情**：
  - **结构与时序**：星星头拍下后，星星条空一拍（启动拍 = 60/BPM）才开始滑；错位就是把这个空档利用起来塞音符。例 `{8}2,1/8-4[8:1],7,1-5[8:1]/8,2,1/8-4[8:1],7,1-5[8:1]/8,`：8-4 的头（8）与上一个星星的启动拍 tap（1）同拍 → 下一拍塞错位音 7 → 再下一拍 8-4 的启动拍 tap（8）与新星星头（1-5）同拍——两条星星线环环相扣，错位音塞在链的缝隙里。
  - **手序（无变体）**：错位音固定由**滑动的那只手自己**拍——"头 → 错位音 → 启动拍"连续作业（如左手：头 8 → 错位音 7 → 启动拍 8 → 划 8-4）。若看到另一只手拍错位音，是玩家打错了，不是合法配置。
  - **与双押的界限**：双手任务错开 = 错位；双手**同刻同任务**（都拍星星头 / 都拍错位处 / 都拍启动拍划星星）= 双押，不叫错位。
  - **启动拍 tap 可选**：放启动拍 tap = "拍下去把星星条带下来"的提示 / 情绪点缀；不放 = 直接划。对难度几乎无影响（有没有它星星条都得划、手都得到位）。
  - **素材不限星星种类**：直线、弧线等任何形状都能进错位。海底谭基础形 = 1-5 / 8-4 两条过心直星 + 7/8/1/2 四个位置（恰好以竖直中线对称，只是特例不是规则）；弧线错位实例：336 第 90/93/96 行 `2-6[8:1]`、`8^5[8:1]`、`1^4[8:1]`。
  - **摆位自由**：不必对称，如左边 8-5、右边 2-4（长短不一）也合法。
  - **变换词汇**：上下反 = 沿水平轴翻转（1↔4、2↔3、5↔8、6↔7）；左右反 = 沿竖直轴翻转（1↔8、2↔7、3↔6、4↔5）；全反 = 上下反 + 左右反 ≈ 旋转 180°（1↔5、2↔6、3↔7、4↔8），例 `8^5` 全反 → `4^1`。舞萌不支持普遍的 45° 旋转（游戏层面），制谱讨论中可口头表达。
  - **BPM 是强度放大器**：同配置海底谭 120BPM（13.4）→ 患部 200BPM Re:MASTER（14.0），难度与体力大幅上升（925 第 235/238 行，原文与海底谭同构）；高 BPM 下错位段的配置选择与长度要谨慎。
  - **错位音密度边界**：舒适区 = 单个 8 分；"子弹"（间隙塞两个 16 分）官方 ATLAS RUSH（156BPM、14.7）出现过但手感差、被玩家诟病 → 制作时避免。
  - **使用时机**：适用范围极广、任何段落都能放；但不要全程连续错位（节制，否则强度失去起伏）。
- **理由**：错位的强度真正来自"间隙必须处理额外音符"；启动拍 tap 只是情绪点缀（谱师体感）。
- **来源**：用户谱师讲授（2026-09-10 会话）；官谱实证：336 海底谭第 84/87/90/93 行、925 患部 Re:MASTER 第 235/238 行（200BPM）与第 247 行（绝赞头版 `8b/1-5[8:1],2,1b/8-4[8:1],7,...`）、ATLAS RUSH（DX 谱，仅作说明）。
- **置信度**：确信（谱师讲授 + 官谱实证）
- **关联**：知识 003（错位强度归因，已修订）、014（启动拍机制）、016（ST 要素）。

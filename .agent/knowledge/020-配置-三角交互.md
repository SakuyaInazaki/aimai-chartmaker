# 020 — 配置：三角交互

- **日期**：2026-09-10
- **要点**：三角交互 = 交互的一种，**3 个 tap 为一组**，按击打先后顺序连线呈三角形；分**占 2 键**与**占 3 键**两类（3 键的配置更松散）。它是**摆位**上的划分，与实际节奏无关。
- **详情**：
  - **定义**：3 tap 一组、连线呈三角。占 2 键（如 `3,4,3`——3 个音只落在 2 个键上）与占 3 键（如 `3,4,2`——3 个音落在 3 个键上）；**3 键配置更松散**（跨度更大）。
  - **与节奏无关**：三分组只是摆位特征，节奏可以是有空隙的 16 分三连、匀速 12 分三连、匀速 16 分三组等——具体看采音。
  - **官谱实例 1（占 2 键 + 3 键混合，匀速 12 分）**：id 648 アンノウン・マザーグース（standard，222BPM，MASTER 13.3）：
    - `{12}3,4,3,6,5,6,3,4,3,6,5,6,...` → 占 2 键（{3,4}、{5,6}）
    - `2,1,2,7,8,7,2,1,2,7,8,7,...` → 占 2 键（{1,2}、{7,8}）
    - `3,4,2,6,5,7,2,1,3,7,8,6,3,4,1,6,5,8,2,1,3,7` → 占 3 键（{2,3,4}、{5,6,7}、{1,2,3}、{6,7,8}、{1,3,4}、{5,6,8}）
    - 匀速 `{12}` ≈ 11.1 键/秒；块间以空拍分隔
  - **官谱实例 2（匀速 16 分三组）**：Hainuwele（**DX 谱**，175BPM，MASTER 14.3，仅作说明）：`{16}3b,4,2,6,5,7,3b,4,2,6,5,7,...`
  - **正三角 / 反三角（手感分类）**：
    - **正三角**：打起来**顺**。
    - **反三角**：仍是 3 tap 一组，但打起来**别扭、卡、更累**。
    - ⚠️ **目前区分依据只有手感**——用户表示"不清楚有没有具体规则，还没认真思考"。记录时不得把任何结构规则当作定论（见文末"Agent 观察（待核实）"）。
  - **反三角实例**：
    - id 311 **Caliburne ～Story of the Legendary sword～**（standard，190BPM，MASTER 14.3）：`{16}2,4,3,7,5,6,1,3,2,8,6,7,`（4 组，≈12.7 键/秒）——引文即配置边界，其后内容不属于三角交互。
    - **Excalibur ～Revived resolution～**（standard，200BPM，**MASTER 定数 14.8**——超出本项目 13.0–14.5 抓取范围，故本地无此 txt）：`{16}2,4,3,7,5,6,2,4,3,7,5,6,1,3,2,8,6,7,1,3,2,8,6,7,`（8 组，用户引文，未本地核对）。
  - **反三角的官谱分布**：仅见于"**圣剑**"系列曲子的谱面（Caliburne、Excalibur 本身都属圣剑系）——**但不是限制，可以通用**。
- **理由**：正/反差异来自击打顺序带来的顺/卡手感（用户体感）；官谱分布显示反三角是圣剑系列的特色写法，但通用可用。

## Agent 观察（待核实，勿当定论）

对照 648（正，7 个三键组）与 311（反，4 组）发现：两边的**键位集合是同一批**（{2,3,4}、{5,6,7}、{1,2,3}、{6,7,8}），**区别只在击打顺序**——

- 正：**中间键起手**（中间 → 一端 → 另一端），如 `3,4,2`（3 是 {2,3,4} 的中间键）；
- 反：**端键起手**（端 → 另一端 → 中间），如 `2,4,3`（2 是 {2,3,4} 的端键）。

用户在确认的实例范围内尚未确认存在此类规则，故仅作为待核实观察记录，不作为判断依据。

# 063 — 配置：拆弹

- **日期**：2026-09-19
- **要点**：拆弹 = **同屏挂着多根星星、必须按正确顺序逐根处理，打错顺序就"爆炸"（连锁掉分）**的配置。教程原话只有一句：「**不按顺序打会爆炸的星星**」。它是**低 BPM 专属**的可读性难点——谱例 BPM 79/90/57 全是慢曲。
- **详情**：

  ### 教程说明（转述）
  - `[44:48]`「**拆弹：不按顺序打会爆炸的星星**」——**全片原文仅此一句**，之后是 8 个纯示例（连标题都不再写）。
  - 谱例：**四月の雨 13.9 BPM79**、Caterpillar Song 13.9 BPM90、**Last Samurai 13.9 BPM57**、Link 12.5 BPM132、（缺名）13.2 BPM190、朝食 13.2 BPM260、（缺名）13.4 BPM172、Lift Off 13.9 BPM137、Panopticon 14.3 BPM110、花と、雪と、ドラムンベース。13.8 RE:MAS BPM180。

  ### agent 理解
  - **"爆炸"的机制（agent 推断，存疑）**：星星本体在**启动拍之后才开始判定**（014），而在低 BPM 下启动等待长达 `60/79 ≈ 760 ms`，于是**多根星星会同时处于"已落头、未开划"的状态**。玩家若划错顺序：
    1. 划到还没启动的那根 → 无效，原本该划的那根超时 → GOOD/MISS；
    2. 错划的手还会**蹭到其他轨道**（010/011）→ 一错连环错。
    这正是"爆炸"的字面含义——**一个顺序错误会沿着链条传播**。
  - **手级定义（agent 推断，存疑）**：
    - **拍头手 / 划轨手**：拆弹段通常仍是 057 一笔画的手序（一手拍头、一手一路划），**但难点不在分工而在"该划哪一根"**；
    - **另一只手任务**：继续按后续的头；
    - **换手时机**：不换；
    - **真正的负担**：**记忆与读谱**——教程在 060 电车段里也说"不提前背板根本看不清顺序"，与此同源。
  - **和 003 第 4 条的直接印证**：知识 003 已记「**低 BPM ≠ 简单**：星星启动按拍计时，BPM 越慢启动窗口越长，大量未启动星星挂屏会造成视觉迷惑、启动时机困惑，强度反而提升（例：四月的雨，BPM 79）」——**本条就是那条规律的术语化**，而且教程给的谱例第一首就是四月の雨。**003 与本条互为独立来源的交叉验证。**
  - **可机检判据草案（B 档）**：对每个时刻统计"**已落头但尚未划完**的 slide 条数" `N_pending`；若 `N_pending ≥3` 持续超过一个四分音符，且这些 slide 的轨道在屏幕上有交叠 → 标 `defuse`。阈值需在官谱上跑分布（*未实测*）。
  - **对生成器的含义**：低 BPM 段（教程谱例 BPM 57–132）写星星时，**必须按"同屏未启动星星数"而不是按 note 密度来控难度**。这是 031 密度曲线覆盖不到的一类强度（*推断*）。
- **理由**：术语定义为教程明文（虽只一句）；机制由 014 的启动拍与低 BPM 换算推出，并与知识 003 的既有条目独立吻合；谱例形态在四月の雨官方谱上核对。

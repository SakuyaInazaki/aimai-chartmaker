# 064 — 手序：舒适区与出张（用户定义）

- **日期**：2026-09-19
- **要点**：左手的舒适区 = 左半屏 **8765** + 向右方延伸的**上方 1** 和**下方 4**；右手 = 右半屏 **1234** + **8** 和 **5**。**右手需要拍 6/7、左手需要拍 2/3 就是出张**；**轻易不要写出张**，写了就要判断"是容易游玩的还是故意设置的难点"，**就算是难点也要做好引导**。
- **详情**：

  ### 用户原话（逐字）
  > 轻易不要写出张，左手最好处理左半屏（8765）以及向右方延伸的上方1和下方4、右手最好处理右半屏（1234）以及85，如果写出来涉及到右手需要拍6或者7，左手拍2或者3那你就要好好考虑难度了，判断这是否是容易游玩的还是故意设置的难点，就算是难点也要做好引导。

  ### 主会话解读（把原话摆成表；未超出原话）
  | 键位 | 左手 | 右手 |
  |---|---|---|
  | **1** | ✅（"向右方延伸的上方 1"） | ✅（右半屏） |
  | **2** | ❌ **出张** | ✅ |
  | **3** | ❌ **出张** | ✅ |
  | **4** | ✅（"下方 4"） | ✅ |
  | **5** | ✅（左半屏） | ✅（"以及 85"） |
  | **6** | ✅ | ❌ **出张** |
  | **7** | ✅ | ❌ **出张** |
  | **8** | ✅ | ✅（"以及 85"） |

  - **共享区 = {1, 4, 5, 8}**：两只手都"最好处理"，不构成出张；
  - **左手专属 = {6, 7}**、**右手专属 = {2, 3}**；
  - **出张 = 右手落 6/7，或左手落 2/3**——只有这四个「手 × 键」组合；
  - 出张的写谱程序（用户原话的三步）：① **轻易不要写**；② 写了要**好好考虑难度**，判断它是"容易游玩"还是"故意设置的难点"；③ **就算是难点也要做好引导**（"引导"的定义见知识 030 的 2026-09-19 补充）。

  ### 对手序模型的含义
  1. **分页先验要从"二分"改成"带共享区的三分"**。知识 006 记的是右手 1234 / 左手 5678 的中线二分，知识 023 与 `hands.py` 由此给出"越界深度"（右手够到 5/8 = 深度 1、够不到 6/7 = 深度 2）。用户口径把**深度 1 那一档归零**：右手打 5/8、左手打 1/4 **不是越界**。
  2. **出张只有一档、但代价显著**。"轻易不要写"意味着触发出张的代价应明显大于普通位移代价；但用户**没有**给出数值，也**没有**说出张的代价随深度/时长变化——量化是 agent 操作化，须另行标定。
  3. **出张不是无理**。用户给的是"要好好考虑难度 / 做好引导"，不是"不能写"——它属于风格预算（`docs/hand-sequencing.md` §6.2 的 `budget.chuzhang`），不属于 `muri`。
  4. **旧的出张统计口径作废**。知识 060 与 `docs/hand-sequencing.md` §5.1 把出张定义成"划轨手与知识 007「末尾半边」规则冲突的根数"；007 该条已被知识 **065** 降级为社区经验/打分项，**出张一律改按本条目的键位定义统计**。
  5. 重调清单见 `docs/research/hand-alignment-user-2026-09-19.md`。

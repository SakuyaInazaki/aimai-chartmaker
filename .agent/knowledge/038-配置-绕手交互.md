  ### agent 理解
  - **共性（agent 归纳，存疑）**：这些段落都不是"固定两个键对敲"（018 普通交互）也不是"一只手钉死"（021 轴交互），而是**那个被反复敲的键（轴）或那一对键，每隔两三个音就挪一格或跳一次**：
    - Streak `8,7`×3 → `8,1`×3 → `2,1`×3：轴从 8 变到 1，伙伴键从 7 跳到 1 再跳到 2；
    - トルコ `8,1`×2 → `8,5`×2 → `8,2`×2 → `4,2`×2：轴不动但伙伴键在满屏跳，然后轴自己换掉；
    - Blew Moon m069–m070：`3,4` → `5,6` → `7,8` → `1,2`，两键一组绕着圈往前推；
    - おちゃめ機能：长条把一只手钉在 2，另一只手却要去够 7、6——**手被迫交叉**（与 037 反手同源）。
  - **为什么"绕"**：交互本身不快（150–180BPM 的 `{12}`/`{16}`，9–12 键/秒，远低于 015 的红线），难的是**手的分配每两三个音就要重算一次**——没有一个稳定的手型可以套。这和 025 散点"看不出规律"是同一类难度（读谱与预判），但散点是单点摆位分散，绕手是**交互结构在动**。
  - **和已有条目的关系**：是 018 普通交互的一个**手感型子类**；当"轴在动"时和 021 轴交互相邻（轴交互是轴固定）；当"两手被挤进同一半圈"时和 037 反手重叠。
  - **⚠️ 教程没给结构规则**，上面这一整段共性都是 agent 从五个谱例反推的，**不得当作判据硬用**；真要机检只能先按"交互键对的更换频率"做弱信号。
- **理由**：定义是教程明文（只有一句手感描述）；共性是 agent 在五个谱例范围内的归纳，已标存疑。

# 101 — 尾杀 = **最后一小节的最强一击**，打完**真停手**

> ⚠️ **本条为 agent 观察，未经用户确认。** 来源：同曲官谱抄谱对照（note 069）。n=1。

- **日期**：2026-09-20
- **要点**：参考谱把**全曲密度峰值放在主段的最后一小节**（m121，**21 个 note**，全谱最大），
  写法是「`{16}` 双键交替 → `{32}` 十二连、**每四个一个绝赞** → 收在一个绝赞上」；
  打完之后 **连空四小节**（尾奏 m122–m125），m126 才用一条**占满整小节的长条**重新出声，
  一路慢下来到最后一根 `pp` 大曲线。**先尾杀、再停手、再渐弱，三段都有，顺序是关键。**
- **详情**：

  ```
  m121（205）21 note   {32}1,,5,,1,,5,,2,,6,,2,,6,,2b,3,4,5,8b,7,6,5,1b,2,3,4,5b,,,,
  m122（221）空  m123（197）空  m124（190）空  m125（165）空
  m126（175）7 note    {16}6h[1:1],,,,5,4,3,2,1,8,,,,,,,      ← 整小节长条 + 一串下行
  m127（135）5 note    {16}5h[1:1],,,,4,3,2,1,,,,,,,,,
  m128（108）9 note    整小节长条 + 慢下行 + 一根 qq 大曲线
  ```

  我们上一轮：m121 写了 **8 个** note（一对绝赞 + 一个顶双押 + 一对拖进尾奏的 3 拍长星星），
  尾奏 m122–m128 每小节 2–4 个匀速走到底，**没有一个空小节**。

  **两件具体手法**：
  1. **尾杀里分音往下切一档**（本谱 `{16}` → `{32}`），不是靠加双押；
  2. **绝赞按节奏点**（每四个 32 分一个 `b`），让那一串有重音，不是一片平的连打。

- **理由**：知识 **031** §10 的 388 谱 / 160 首统计说结尾 65.6% 是尾杀、1.9% 渐弱、32.5% 其他，
  但没有说尾杀**长什么样**、也没有说尾杀之后怎么办。本条补的是形态：
  **峰值在最后一小节 + 之后的空**。
- **来源**：`docs/research/test-01-vs-reference.md` §2.12 / §2.13 / §3.5；
  同曲官谱抄谱对照（note 069）。
- **置信度**：**经验**（形态与计数为直接观察）/ **存疑**（n=1；参考谱尾奏部分自己标了 `|| not sure`，
  那几小节的空可能是抄谱未完成而不是设计——**这一条的"停手四小节"要打问号**）
- **关联**：**031 §10**（结尾形态三分）、**001**（情绪走势）、**095**（密度攒起来）、
  **098**（细分音写一串）、**016**（ST 白名单：`pp` 大曲线合法）。

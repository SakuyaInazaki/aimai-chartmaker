# 079 — 出张在官方谱里的实测分布（知识 064 口径）

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：388 个官方 ST 谱，出张按知识 **064** 的定义计数（**右手落 6/7、左手落 2/3** 这四个"手 × 键"组合）。⚠️ **官方谱只给了 note，没给手序**——这里的出张次数是**本项目分配器选出的那套手序**下的计数，**不是官方谱标注的事实**；换一套合法手序，数字会变。

- **日期**：2026-09-20
- **要点**：出张在官方谱里是**少数派，但并不罕见**——平均**每四五条 slide 才摊上一次**（064 口径下约 0.23 次／条）。它**最集中在落ちサビ**（那一段密度低、手更闲，正好塞一次跨界），其次是 Bメロ，**不是副歌**。这与知识 064「轻易不要写出张」是一致的：官方谱确实写得省，而且挑手闲的地方写。
- **详情**：

  1. **两个口径差一倍，必须写明用的哪个**：
     - **教程口径（知识 043）**：粗略地说"某只手离开自己半圈 / 左手打右边"，按知识 006 的中线二分算；
     - **用户口径（知识 064）**：共享区 {1,4,5,8} 两手都算本分，**只有右手 6/7、左手 2/3 才算出张**。
     同一批谱、同一套手序下，064 口径给出的出张比"跨中线"口径**少很多**；反过来"跨中线的任务比例"却是**上升**的——**跨中线变多、跨出舒适区变少**，正是用户口径想要的方向。
  2. **出张是手序难度最强的共变量**（知识 078）：按 064 重新定义之后，这条相关不降反升——说明 064 的"出张"比"跨半圈"更贴近"手序到底难在哪"。
  3. **出张不是无理**（知识 064）：它属于风格预算，要判断"是容易游玩的还是故意设置的难点"，**就算是难点也要做好引导**。模型里它是**布尔判定 + 计数，不分档**（用户 2026-09-20：「出张本来是一件很小的事啊，怎么就分档了？」）。
  4. **知识 007 旧口径的出张统计已作废**：验证报告早先写的"每条 slide 平均 0.431 次出张"用的是"末尾半边"违规数，知识 065 已把那条规则降级——**按 064 的口径是约 0.23 次／条**（已在知识 043 与 007 的修订记录中对齐）。
  5. **出张最多的两类配置**：`出张` 本身与 `侧边双押`（后者必定产生出张，知识 030 与 064 的交叉推论）。

  **证据注脚**：388 谱 37 398 条 slide、272 207 个手任务；出张落点 5 739（21.1 / 1000 任务）、**出张 / slide = 0.232**；把可及性模型从分页二分换成 064 舒适区后，出张落点从约 11 000 降到约 5 700（−48%）而**绝对无理一个没变**（146）；跨中线任务比例 0.191 → 0.248；段落 lift 落ちサビ 1.66 / Bメロ 1.43。

- **理由**：知识 064 是用户逐字讲授的边界；本条只是在这个边界下把官方谱数一遍，用来回答"官方谱到底写了多少出张、写在哪里"。
- **来源**：`docs/research/hand-assignment-validation.md` §V1、§V1.1、§V9.1；`docs/research/sampling-mode-study.md` §9.4。
- **置信度**：**经验（agent 观察，n=388 谱，064 计数口径，未经用户确认）** / **存疑**（① 计数依赖分配器选出的**一套**手序，而合法手序不止一套（知识 065）；② 分配器里出张的代价数值是 agent 设定，直接影响模型愿意写出多少出张；③ 段落 lift 继承音频分段的误差）。
- **关联**：知识 **064**（出张定义与写谱程序）、**043**（教程口径）、**037**（反手＝出张极端形）、**006**（分页二分）、**030**（侧边双押必定出张）、**060**（旧出张口径作废）、**065**（合法手序不止一套）、**078**（手序难度）、**080**（侧边双押分布）。

- **2026-09-20（官谱普查，agent 观察）**：本条的总量与段落结论**未变**（5 739 个落点、出张/slide ≈ 0.232、落ちサビ 与 Bメロ 最集中），新增**场景侧**与**定数走向**两块，见**知识 087**：

  - 上下文六类里**"纯单点出张"占三成是最大的一类**，"被长条/星星钉住"合计只占三分之一；
  - **出张几乎不与纵连同现**（约 2%）；出张落点离**本手上一次落键**通常**不近**（中位约三格）——与侧边双押（手就在隔壁，知识 082）正好相反；
  - **出张密度随定数下降**（13 字头最多、14.5 档最少），而 `出张/slide` 四个定数段几乎不变。

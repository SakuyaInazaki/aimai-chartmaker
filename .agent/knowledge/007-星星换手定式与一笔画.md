# 007 — 星星换手定式与一笔画原则

- **日期**：2026-09-10
- **要点**：划 slide 的手应"与 slide 末尾所在半边相同"；四种经典换手定式 + 一笔画原则是生成 slide 配置时的手序依据。
- **详情**：
  1. **风车星星**（等速穿心）：可提前绕手或换手，口诀"一只手拍键、一只手划屏"；
  2. **一圈星星头连续飞出**：星星头轮流出现，双手交替击打；
  3. **死亡镰刀**（一圈音符 + slide 方向与出键方向相反）："tap 分页，拍打与星星头相隔一个四分音符的 tap 时用另一只手一下子划完 slide"；
  4. **一对贴边对称双押 slide**：打完立即双手换位划。
  - **一笔画**：一只手专门拍、一只手专门划；划 slide 的手开始后不停（连续划完）。
- **理由**：slide 的换手是舞萌谱面手序设计最难的部分；官方谱例总结出的定式能保证"不换手冲突、不撞手"。
- **来源**：舞萌简明初级教程（星星篇进阶）https://www.bilibili.com/opus/461149354380109054
- **置信度**：经验（社区共识）
- **关联**：知识 006/008。

## 补充（2026-09-19，B 站教程三期视角）

B 站 wasllll《配置术语第三期（星星篇）》BV1WW42197zB 用整整两节讲了本条目的两个主题，**结论与本条目一致**，并补上了三点：

1. **"星星头和星星本体是两个独立的部分"是换手的机制根据**（`[14:31]`）——它们**不必在同一个手顺里解决**（左手拍头、右手划）。本条原文只给了四种定式，没说清"为什么能换"；机制侧见知识 **054**。
2. **一笔画的谱面判据**（`[24:26]`）：「**至少 2 条星星头尾相连，手能在不抬起来的情况下把星星滑掉**」——本条原文记的是手序原则（一手拍、一手划、开划后不停），教程补上了**可机检的形状定义**（`end(slide_i) == head(slide_{i+1})`）。详见知识 **057**。
3. **一笔画的启动方式**（`[24:26]`）：「**第一个星星头打完以后不要立即滑，等一拍后（可能会有夹键），当另一只手打完星星头开始滑动**」——即整条链的划轨由**另一只手的落头来触发**，不是自己数拍。这条本条目原先没有。
4. 教程 `[16:58]` 还给了反向的一条：「**平常都是在换手的地方你选择不换手也能获得不一样的乐趣**」——说明**同一段谱存在多套合法手序**，本条的四种定式是"常用解"而非"唯一解"。

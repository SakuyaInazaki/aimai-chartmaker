# 056 — 配置：绕圈星星

- **日期**：2026-09-19
- **要点**：绕圈星星 = **把穿心配置里的直线星星换成沿圆周走的弧线（`^`/`<`/`>` 等），头依次沿圈推进**，于是手不是"来回穿过中心"而是"**一路绕着屏幕转**"。教程对它只给了一句话：「**直线变成其他形状叻**」。
- **详情**：

  ### 教程说明（转述）
  - `[22:41]`「**绕圈星星：直线变成其他形状叻**」——**全片原文仅此一句**（句末"叻"是 UP 主原文，`corrections.md` 已确认）。它紧接在穿心/风车（055）之后，语境上是"**同一骨架换星型**"。
  - 谱例五首，全部本地有谱：（缺名）12.8 EXPERT BPM100、キズナの物語 13.2 BPM128、**Mysterious Destiny 13.3 BPM140**、光線チューニング 13.7 BPM190、緋色のDance 13.7 RE:MAS BPM155、My First Phone 13.8 BPM114。

  ### 谱例
  **定位成功（agent 依形态核对）**：`resource/official-chart/112-Mysterious Destiny-mas.txt`，**m020–m023**（教程 示例三 定数 13.3 / MASTER / BPM140 三项全对）：

  ```
  m020| 8^3[8:1],,3^6[8:1],,,,,,7-3[8:1],,,1-5[8:1],,,,,
  m021| 1^6[8:1],,6^3[8:1],,,,,,2-6[8:1],,,8-4[8:1],,,,,
  ```
  前半是**弧线接力**：`8^3` 走 8→1→2→3，`3^6` 接着走 3→4→5→6——**前一根的终点就是后一根的起点，沿圆周同向推进**；后半立刻换成两根穿心直星（`7-3`、`1-5`）作对比。同曲 m016–m019 是纯直线版（`1-6, 8-3 / 5-2, 4-7`），可作"直线 vs 绕圈"的同谱对照。

  ### agent 理解
  - **⚠️ 定义几乎全是 agent 补的**：教程只说"直线变成其他形状"，**没有给"绕圈"的形状判据**。本条采用的判据——**弧线型 slide（`^`/`<`/`>`/`p`/`q`）沿同一方向沿圆周接力**——是从谱例反推的（**存疑**）。
  - **手级定义（agent 推断，存疑）**：
    - **拍头手 / 划轨手**：因为弧线的终点就在**下一根的起点**，而按 007「划 slide 的手＝末尾所在半边」，划完的手正好停在下一个头上 → **最经济的打法是"一只手一路划到底"（＝ 057 一笔画）**，另一只手只在需要时补头；
    - **另一只手任务**：处理段内的 tap / 补拍头；
    - **换手时机**：**绕过半圈（中线）时**——这是 006 分页处理的必然要求（右手 1234、左手 5678）；Mysterious Destiny 的 `8^3`（跨 8→1 这条缝）与 `3^6`（跨 4→5 这条缝）各换一次。
  - **与 055 穿心的对照（本条的核心价值）**：两者是**同一骨架的两种星型**——
    | | 055 穿心 | 056 绕圈 |
    |---|---|---|
    | 星型 | `-` 直线过圆心 | `^`/`<`/`>` 沿圆周 |
    | 手的运动 | 反复穿过中心、**出张/反手频发** | 沿圈平移、**出张少** |
    | 主要风险 | 中心区轨道互撞、011 整条直径都要查撞尾 | **贴边轨道压住沿途 A 区**（＝033 死镰段的同一风险） |
    | 教程给的手法 | 四种（正攻/换手/直接滑/同时处理） | 未给 |
  - **它和 033 死镰段的关系**：死镰段＝"绕圈的 tap 链 + 贴边弧星"，本条＝"贴边弧星自己接力绕圈"。**两者的防蹭要求相同**：弧线轨道整段压在按键圈上，必须核对轨道经过的 A 区在其持续时间内是空的（010/011）。
  - **定数分布**：五首谱例 12.8–13.8，**比穿心（12.8–14.8）窄**。合理的解释是绕圈的位移成本低于穿心（不用跨过中心），所以拉不到最高难度档（*推断，存疑*）。

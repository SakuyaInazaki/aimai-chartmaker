# 078 — 手序难度与配置硬度是两个轴；音乐强度不通过"手更忙"传导

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：388 个官方 ST 谱（手序版配置识别 + v0.2 分配器）与 160 首配对曲包的曲内相关。**两个"分数"本身都是 agent 操作化的量，本条只取它们之间的关系方向，不把任何分值当结论。**

- **日期**：2026-09-20
- **要点**：**"这一段有多累"（体力/配置硬度）和"这一段手够不够用"（手序难度）是两个近乎正交的轴**，不能合成一个分数。更重要的一条方向：**音乐强度是通过"写得更快、摆得更狠"传导的，几乎不通过"让手更忙"传导。**
- **详情**：

  1. **两个轴正交**：逐小节与逐谱看，配置硬度与手序难度之间几乎没有相关。**所以两个分数必须并存、不得合成**——这与用户撤回 `(D+H)/2` 合成分的裁定同向。
  2. **几何越规整的配置，手序越省心**：手序难度垫底的是长纵连、定拍、楼梯交互、方向盘、三角交互、纵连；**大宇宙的体力权重最高而手序难度很低**——它们难在体力与稳定性，不难在手的调度。
  3. **最费手序的是"跨界"那一族**：榜首是**出张**，紧接着是**侧边双押**；按知识 030 与 064 的交叉推论，侧边双押 `{2,3}`/`{6,7}` 恰好是"**必定产生出张**"的那两组相邻双押——**最费手序的两类其实是同一个机制的两层**。错位也在前列，与知识 003「错位是同踩音同键位中强度最高的星星用法」一致。
  4. **强度不走"手更忙"这条路**：曲内看，音乐强度与体力硬度有中等相关，与手序难度几乎不相关；**手序难度最强的共变量是出张次数**，不是强度、不是密度、也不是蹭的压力。
  5. **手序难度不是难度代理**：它与定数只有弱相关（远低于体力侧），**不能拿来当定数预测量**；它量的是**手的调度余量**。
  6. **给写谱的用法**：选配置时两个量都要看——体力侧定"这段有多累"，手序侧定"这段手够不够用"。

  **证据注脚**：逐小节 ρ(手序难度, 配置硬度) = 0.075、逐谱 0.057；曲内 ρ(强度, 体力硬度) = +0.201 vs ρ(强度, 手序难度) = **+0.046**；ρ(手序难度, 出张率) = **0.464**（v0.1 的 0.334 在按 064 重定义出张后反而上升 38%）；ρ(手序难度, 定数) = 0.229 vs ρ(配置硬度, 定数) = 0.369；配置平均手序难度 出张 0.565 / 侧边双押 0.551 / 二连扫 0.486 / 散点 0.469 / 穿心 0.449 / 错位 0.432 …… 长纵连 0.174 / 定拍 0.183 / 楼梯 0.193 / 方向盘 0.206 / 纵连 0.226 / 大宇宙 0.292。

- **理由**：用户 2026-09-19 撤回了把配置密度与难度合成一个分数的做法；本条给出"为什么不能合成"的实测理由——两个量与外部变量（强度、定数、出张）的相关模式根本不同。

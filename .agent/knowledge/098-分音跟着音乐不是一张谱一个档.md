# 098 — 分音跟着音乐走，不是一张谱一个 `{8}`；**高 BPM 的细分音写"一串"不写"一段"**

> ⚠️ **本条为 agent 观察，未经用户确认。** 来源：同曲官谱抄谱对照（note 069）。n=1。

- **日期**：2026-09-20
- **要点**：205 BPM 下我们把"写不起成段的十六分"执行成了"全谱 `{8}`"——
  87% 的 note 落在 `{8}`、**75% 的时间槽落在四分位上**。参考谱在同一首曲子上
  用了 `{1}{2}{4}{6}{8}{12}{16}{24}{32}{48}` **十档**，八个八分位上的分布基本均分（7–17%）。
  它写得起细分音，是因为**每次只写一串 3–12 个槽**（一串 `{24}` 三连、半小节 `{48}` 扫键），
  爆完立刻回到八分。**分音的上限不该按"能不能成段写"去定。**
- **详情**：

  | | 参考谱 | 我们 |
  |---|---|---|
  | 分音占比（按 note） | `{4}`12% `{8}`34% `{16}`37% `{24}`11%，另有 `{1}{2}{6}{12}{32}{48}` 共 6% | **`{8}`87%** `{16}`12% `{12}`0.3% |
  | 主段时间槽落在八个八分位 | 7 / 9 / 13 / 13 / 17 / 13 / 13 / 14 % | **20 / 3 / 19 / 4 / 17 / 6 / 19 / 12 %** |
  | 三连音族（`{6}{12}{24}`） | 13% | 0.3% |

  **细分音的用法（本谱形态）**：
  - `{24}` **一串三到十二个**：段落进场（`2b,3,4,5` 四个 24 分起手）、下行扫键；
  - `{48}` **半小节**：drop 里的绕圈扫键、段落收尾的一趟下行；
  - `{32}` **一小节**：尾杀（十二连带绝赞）。

  ⚠️ **这两个数与"每小节第一拍在音乐的哪里"无关**——两份谱的绝对时钟差约一拍
  （`docs/research/test-01-vs-reference.md` §0.4 第 2 条，**待听音乐裁定**），
  但"分音占比"和"八分位是否均分"在任何相位下都成立。

- **理由**：分音是**节奏从哪来**的直接体现。全谱一个 `{8}` + 四分位占七成五，
  等价于"谱面的节奏来自网格"；八个八分位均分 + 十档分音，等价于"节奏来自音轨"。
  这正是 AGENT 准则 12「采音按音乐事件判定，不得按网格 / 分音 / BPM 数格子」在结果上的样子。
- **来源**：`docs/research/test-01-vs-reference.md` §3.1；同曲官谱抄谱对照（note 069）。
- **置信度**：**经验**（占比为直接计数，相位无关）/ **存疑**（n=1；"一串不一段"是 agent 归纳的说法）
- **关联**：**072**（BPM 只换分音与块长）、**015**（速度密度红线）、**003**（配置强度四因素）、
  **047**（乐理：X 分音符）、**086**（似踩非踩：按匀速分音铺满而不跟音轨）、
  AGENT 准则 12。

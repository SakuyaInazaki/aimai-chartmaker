# 072 — BPM 是分音与块长的旋钮，不是配置种类的旋钮；低 BPM 靠错位撑密度

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：388 个官方 ST 谱（定数 13.0–14.5），控住定数档后看 BPM 的效应。

- **日期**：2026-09-20
- **要点**：控住定数之后，**BPM 高低几乎不改变一张谱用哪些配置**。变的是两件事：
  ① **分音**——BPM 越高，8 分占比越大、16 分占比越小；
  ② **块长**——同一类配置被切成更多、更短的片段。
  相应地，**低 BPM 谱靠"错位"撑起密度**：错位在慢曲里占掉大量时长，快曲里大幅缩水。
- **详情**：

  1. **BPM 不换配置种类**：控定数后，"用了几类配置"与 BPM 几乎无关，也没有哪一类配置的出现率被 BPM 明显带动。
  2. **"高 BPM 应避开几何配置"不成立**：三角交互、楼梯交互、大宇宙的出现率随 BPM **上升**。
  3. **谱师用分音把等效速度换回来**：知识 003 第 3 条「同配置 BPM 越高越强」在谱面侧的体现，不是"高 BPM 改用更简单的配置"，而是**换一档分音**（等效速度 = 分音 ÷4 × BPM ÷60，知识 015）。
  4. **低 BPM 靠错位撑密度**（知识 003 第 4 条的谱面侧证据）：错位的小节占比与 BPM 是全表最强的负相关；慢曲里错位片段又长又多，快曲里又短又少。**机制**：星星启动按"拍"计时（知识 014），BPM 越低启动窗口越长，越塞得进错位音；高 BPM 下塞不进，密度改由速度本身提供。
  5. 同向但更弱的还有跳拍、定拍、纵连——**慢曲的密度普遍靠"往缝里塞"，不靠"跑得快"**。

  **证据注脚**：控定数后 ρ(BPM, 配置种类数) 从 +0.13 掉到 +0.07，17 类里没有一类 |ρ|>0.21；{8} 分音占比 19%→61%、{16} 32%→5%（全表随 BPM 变化最大的量）；每分钟配置片段数 子弹 +70% / 连续双押 +63% / 普通交互 +70%（5 个定数档全正）；三角 41%→68%、楼梯 41%→57%、大宇宙 31%→41%；错位小节占比 ρ(BPM) = −0.413，<140 BPM 档占 38.5% 时长（片段均 3 小节 ≈ 5.5 秒）→ ≥200 档只剩 12.2%（2 小节 ≈ 2.3 秒）；谱例 `454-FestivaLight`（13.4 / 125 BPM）错位占 47% 小节 vs `825-セハガガガンバッちゃう！！`（13.3 / 202 BPM）只占 14%。

- **理由**：388 谱按定数档分层后的 BPM 趋势；错位那条与知识 014 的启动拍机制在机制上自洽。
- **来源**：`docs/research/chart-config-matrix.md` §5.2、§3.1、§6、§9.2、§10.2。
- **置信度**：**经验（agent 观察，n=388 谱，未经用户确认）** / **存疑**（① "块长"结论受小节粒度影响——低 BPM 档一小节更长，占比会被放大；② 观察性统计，没有控曲风与谱师；③ 配置识别的透镜换成手序版后符号大体一致，数值会动）。

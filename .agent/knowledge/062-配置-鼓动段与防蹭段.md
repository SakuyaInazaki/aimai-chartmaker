# 062 — 配置：左右手连续拍滑 / 防蹭段 / 鼓动段

- **日期**：2026-09-19
- **要点**：左右手连续拍滑 = **两只手轮流"拍一根、滑一根"，而星星轨迹被刻意安排成互相干扰的样子**——教程称"**可以写得非常的蹭，能有效提升难度**"，统称"**防蹭段**"；UP 主个人口径：**连续拍滑的星星数量 ≥6 根即可称"鼓动段"**（得名自东方鼓動）。
- **详情**：

  ### 教程说明（转述）
  - `[39:50]`「**左图是可能出现的星星轨迹，可以写得非常的蹭，能有效提升难度的配置**。这类配置**没啥特定的叫法，可以笼统的称为防蹭段**，**个人认为拍滑星星数量 6 根及以上可以称为鼓动段**，比如东方鼓动」「**先来三首强度没那么高的**」。
  - **视频简介的补充（UP 主本人）**：「**鼓动段说的前三首示例强度不高指的是配置强度，而不是整体的歌曲强度**」——即"强度"在这里专指**配置强度**，与曲子整体难度是两回事。**这条直接支持知识 031 的"强度 ≠ 密度"**。
  - 谱例：**Believe the Rainbow 13.4/133**、（缺名）13.9/190、六兆年と一夜物語【SD】13.8/186、**鼓動 13.3/121**、（缺名）13.7/178、Scream out!【SD】14.0/174、Trricksters!! 14.5/155、**Fragrance 14.5 RE:MAS/143**、（缺名）14.2 RE:MAS/100、（缺名）14.3/100。

  ### 谱例
  **定位成功**：`resource/official-chart/352-鼓動-mas.txt`，**m039–m044**（`{8}` @121BPM；教程 示例四 定数 13.3 / MASTER / BPM121 三项全对；曲名即术语出处）：

  ```
  m039| 1-6[8:1],1,2-5[8:1],2,8-3[8:1],8,7-4[8:1],7,
  m040| 1-5[8:1],1,2-6[8:1],2,8-4[8:1],8,7-3[8:1],7,
  m043| 1-4[8:1],8-5[8:1],1-3[8:1],8-4[8:1],1-5[8:1],8-6[8:1],1-4[8:1],8-3[8:1],
  ```
  m039/m040：**每个八分一根星星**，头依次 1→2→8→7（左右交替），每根后面紧跟自己的启动拍 tap。**m043 一小节内 8 根**，头在 1 和 8 之间逐根对调——**≥6 根，正好命中教程的"鼓动段"阈值**。

  ### agent 理解
  - **手级定义**：
    - **拍头手 / 划轨手**＝同一只手（拍滑单元），两手**严格交替**，每根一换；
    - **另一只手任务**：在对方划的同时按下下一根的头；
    - **换手时机**：**每根一换**（m039 是每八分一换 ⇒ BPM121 下 248 ms 一换）。
    - 骨架与 049 连续拍滑相同，**差别只在星星的摆位被刻意写成互相挡路**。
  - **"蹭"是怎么被写出来的（agent 推断，存疑）**：看 m043——`1-4` 与 `8-5` 紧邻一个八分先后出现，**`8-5` 的头（8）就在 `1-4` 的轨道刚出发的那一侧**，而 `1-4` 的轨道会扫过 1→2→3→4 一路的 A 区。于是：
    1. 前一根的**轨道**压住后一根的**头**（＝ 010 外键无理的形态）；
    2. 后一根的**头 tap**又压在前一根**轨道尚未走完**的区域（＝ 011 撞尾的形态）。
    **防蹭段的本质＝把配置写到 010/011 的红线边缘但不越线**，靠 048 的容错窗口和玩家的"快滑快抬"活下来。这也解释了教程为什么说它"**能有效提升难度**"——它不加密度、不加位移，**只加风险**。
  - **"6 根"这个阈值的性质**：教程明说是"**个人认为**"，属于社区口径而非公认定义；但它是本片**唯一一个给出的可数阈值**，可直接编码为机检规则（见下）。
  - **可机检判据草案（A 档）**：连续的拍滑单元（slide head + 其启动拍 tap）在时间上以固定分音间隔出现、左右侧交替，计数 ≥6 → 标 `drum-beat section`；同时对每一对相邻单元跑 010/011 检查并**统计"贴线"次数**，作为该段"蹭度"的量化指标（*agent 提议，阈值未实测*）。
  - **与 031 的呼应**：简介那句"强度指配置强度不是歌曲强度"正好对上知识 031 的结论"**强度 ≠ 密度**"。鼓動 13.3 全谱只有 436 note（远低于同定数中位），却因为防蹭段而不好打——**note 密度低但配置强度高的官方样本**。
- **理由**：定义、"防蹭段"统称、6 根阈值、简介澄清全部为教程明文；形态在鼓動官方谱上逐格核对；"蹭"的成因为 agent 依 010/011 推断。

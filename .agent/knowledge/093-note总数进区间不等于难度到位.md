# 093 — 「note 总数落进定数区间」不等于难度到位

> ⚠️ **本条为 agent 观察，未经用户确认。** 来源：`docs/research/e2e-trial-01.md`（n=1 试写）
> + 388 官谱的谱级统计。两个"难度"量（`hands.py` 的手序难度、配置硬度）都是**本项目的内部口径**。

- **日期**：2026-09-20
- **要点**：知识 **004** 的 note 总数 p10–p90 区间很宽（13.5 档 492–967）。
  **一张谱的 note 总数落在区间里，说明不了它对不对得起这个定数。**
  至少还要看三件：**note 种类构成**（slide / hold / each 占比，知识 088）、
  **配置的主料构成**（知识 073：官谱 65% 有星星族主料、只有 13% 有几何主料）、
  **手序难度的量级**（知识 078 的内部诊断量）。
- **详情**：

  1. **试写个案**：trial-01 写了 761 note、官谱 946，**两者都在 13.5 档的 492–967 内**；
     但官谱的手序难度是试写的 **2.4 倍**、slide 是 **3.5 倍**、hold 是 **12.5 倍**、出张是 5.5 倍。
     "0 错误 0 警告 + note 数进区间"完全没有拦住"写得太浅"。
  2. **官谱基线（388 谱，只作对照不作判据）**——分档口径 = `chart_matrix.LEVEL_BANDS` 的五档。
     ⚠️ `tools/chart_check/depthlayer.py` 里那张表用的是另一种分档（`floor(定数×2)/2` 的四档，
     与密度层同口径），方向一致、数值略有出入，**两张表不要混着引**：

     | 定数档 | 手序难度 中位[Q1–Q3] | slide 占比 中位 | hold 占比 中位 | each 占比 中位 | 含星星族主料 |
     |---|---|---:|---:|---:|---:|
     | 13.0–13.2 | 0.111 [0.096–0.128] | 0.146 | 0.075 | 0.591 | 59% |
     | 13.3–13.5 | 0.111 [0.095–0.128] | 0.142 | 0.049 | 0.591 | 63% |
     | 13.6–13.8 | 0.112 [0.089–0.131] | 0.127 | 0.044 | 0.550 | 68% |
     | 13.9–14.1 | 0.128 [0.106–0.149] | 0.103 | 0.046 | 0.510 | 66% |
     | 14.2–14.5 | 0.144 [0.121–0.164] | 0.106 | 0.053 | 0.486 | 71% |

     trial-01 的手序难度 **0.069**，低于 13.6–13.8 档的 Q1（0.089）；slide 占比 0.060，低于该档中位的一半。
  3. **★ 但"手序难度"本身不是难度代理**（知识 **078**）：它与配置硬度正交，
     最强的共变量是出张数。所以它只能当**"这张谱是不是异常地省手"的一个信号**，
     **不能当难度分，更不能当目标值去优化**——优化它会直接撞上知识 **064**「出张轻易不要写」
     与 **066**「不以手法为导向」。
  4. **可用的自检清单**（写完之后逐条看，**都只是对照**）：
     ① note 总数在定数区间内（知识 004）；② NPS 贴定数锚（031 §7）；
     ③ slide / hold / each 占比在同定数档官谱的四分位区间附近（知识 088）；
     ④ 逐段的 slide 占比与同段落官谱分布对得上（知识 088 §1）；
     ⑤ 主料 4–5 类，其中有没有星星族、几何族有没有被写成主料（知识 073）；
     ⑥ 手序难度不要明显低于同定数档的 Q1（本条 §2）。
     **每一条都可能有正当理由偏离，偏离时写明理由即可**（知识 073：官谱本身就千差万别）。

- **理由**：试写个案给出"区间内 + 零错误"仍然写浅的存在性证明；官谱基线是 388 谱的直接统计。

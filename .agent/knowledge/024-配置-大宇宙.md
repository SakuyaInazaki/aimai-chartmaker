# 024 — 配置：大宇宙

- **日期**：2026-09-10
- **要点**：大宇宙 = **两只手在 4 个键位上的左右横跳式交互**——4 个键构成**两对相邻键**，**每只手在自己那对相邻键上来回横跳**。
- **详情**：
  - **硬性结构**：
    1. **严格 4 个键**，且必须是**两对相邻键**；
    2. **每只手在自己负责的那一对相邻键之间来回横跳**（本质是 2 键 trill），两手交替 → 整体呈"左右横跳"的交互；
    3. **只能这样，否则没法玩**（硬约束）。
  - **4 键的常见摆位**：顶部四键 `{7,8,1,2}`（ガラテアの螺旋、EmpErroR 的经典位）、右侧块 `{1,2,3,8}`、底部四键 `{3,4,5,6}`，以及 `{1,6,7,8}`、`{1,2,5,6}` 等。
  - **变种**：**the EmpErroR**（Re:MASTER，240BPM，**定数 14.9**）的那段是大宇宙的**变种**——含停顿、换对、一手长时间停在一个键上等不规则写法；在 240BPM 的强度下**或许是全曲最难段**。
  - **实例**（* 为本地 `resource/official-chart/` 已核对）：
    | 例子 | 4 键 | 手A | 手B |
    |------|------|-----|-----|
    | ガラテアの螺旋（id 344，14.6/Re:MAS 14.7，超范围） | {1,2,7,8} | `1↔2` | `8↔7` |
    | 分からない a*（id 695，14.0） | {1,2,3,8} | `2↔3` | `1↔8` |
    | 分からない b* | {1,6,7,8} | `7↔6` | `8↔1` |
    | 分からない c* | {1,2,5,6} | `1↔2` | `5↔6` |
    | 初音ミクの激唱 a*（id 471，14.5） | {3,4,5,6} | `4↔3` | `5↔6` |
    | 初音ミクの激唱 b* | {1,2,3,8} | `3↔2` | `8↔1` |
    | MarbleBlue.（DX 谱，id 1083，14.5） | {1,2,3,8} | 前半停 2 → 后半 `3↔2` | 前半停 1 → 后半 `8↔1` |
    | the EmpErroR（id 518，14.8/Re:MAS 14.9，超范围） | {1,2,7,8} | `1↔2` 为主 | 多停 8，偶 `7↔8` |
  - **难度定位**：本地可核对的实例都在 14.0–14.5，超范围的实例是 14.5–14.9——该配置是**高难度段**的常用手法（EmpErroR 变种为 14.9 谱的最难段候选）。

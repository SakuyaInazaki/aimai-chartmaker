# 041 — 配置：N+1

- **日期**：2026-09-19
- **要点**：N+1 = **纵连带单点**，而且是**数量会变化的纵连**——同键连打的次数 N 在段落内不固定，每段末尾接一个单点。
- **详情**：

  ### 教程说明（转述）
  - `[05:01]`「**N+1：纵连带单点 / 数量变化的纵连**」。教程只有这两行。
  - 教程谱例：**AMABIE**（14.6 / はっぴー / ver.舞萌DX2022 / BPM 190）→ manifest 核对为 **DX MASTER 14+（14.6）**，本地无谱。

  ### 谱例
  - 教程演示的那一段：**未能定位**（AMABIE 是 DX 谱且定数 14.6，超出本地抓取范围）。
  - **agent 另找的同形谱例**（不是教程的例子）：`resource/official-chart/1212-Halcyon-mas.txt` **m055–m056**（`{16}` @191BPM）
    ```
    m055| {16}5/6,,,,4/5,,4,,4,,4,,4,,4,5,
    m056| {16}6,,6,,6,,6,7,8,,8,,8,,8,1,
    ```
    键 4 连打 5 下接单点 5；键 6 连打 4 下接单点 7；键 8 连打 4 下接单点 1——**N=5/4/4 在同一段里变化**，正是教程说的"数量变化的纵连"。

  ### agent 理解
  - **它是 039 / 040 的推广**：2+1、3+1 是 N 固定的特例，N+1 是**N 在段落内变化**的那一档。教程把它单独立一个名字，说明**"N 会变"本身就是难点**。
  - **难在哪**（agent 推断，存疑）：纵连按 019 的常见打法是"一手外键、一手内屏"或直接交互拆；**N 一旦变化，第 N+1 个音落到哪只手上就会随 N 的奇偶来回翻**，玩家没法把手序背成固定循环，必须实时数。密度上它可能比定长纵连还低，但**读谱与手序的不确定性**把强度顶上去。
  - **踩音上的来源**：连打次数变化通常对应鼓的不定长滚奏或人声的断句长度变化——这类音轨本来就不是等长的，所以 N+1 是"忠实踩音"的自然产物而不是刻意设计（对应 002 的切轨思路）。（agent 推断，存疑）
  - **红线**：N 越大，同键连续间隔越是逼近 009 的下限（官谱最快同键纵连 42.2ms）；而 019 提醒 **>5 连就算长纵连、个人差极大**。所以 N+1 段里**单段 N 建议不超过 5**，要更长就改用 019 的长纵连写法并接受个人差。

# 089 — 舍音时舍哪一半：官谱留军鼓与重音、舍单响的踩镲与密集连打里的中间那些

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：160 首官方 ST 曲包（官方 mp3 × 官方 `&inote_5`），
> 只取被 `tools/calibration/sampling.py` 判成 **「舍音」** 的小节（3 191 个小节 / 21 510 个音轨事件），
> 把目标轨（该小节的骨架轨）在这一小节发出的音分成**被踩 / 未踩**两组比较音乐特征。
> 鼓件（kick / snare / hihat）是 `tools/audio_analysis/onsets.py` 的**频带能量启发式**，
> **不是鼓转录模型**（底鼓 ↔ 低音 tom、军鼓 ↔ 拍手、踩镲 ↔ 镲片/齿音泄漏都会混）。
> 每一项都做了**随机平移对照**（把谱面时间槽整体循环平移一个随机量，保留谱面节奏纹理、只打断对齐关系）。
> **数字只作注脚，不作判据，也不是阈值。**

- **日期**：2026-09-20
- **要点**：知识 **068 第 8 条**自己挂着一个缺口——"真正要设计的是**舍音时舍哪一半**"。本条把它补上。
  官方谱在舍音小节里的取舍有**三条方向一致、且互相独立**的倾向：
  1. **留军鼓、舍单响的踩镲**（最强的一条）；
  2. **留响的、舍轻的**（onset 强度）；
  3. **留后面有空隙的那一下、舍密集连打里的中间那些**（长音 vs 短音）。
  另有两条**被证伪的直觉**：「小节的第一个音几乎必踩」**不成立**（反而略低）；
  「多轨齐奏点几乎必踩」**也不成立**（只有很弱的正向，且加到第二条轨就不再涨）。
- **详情**：

  1. **★ 鼓件：军鼓是分界线**。舍音小节里，带**军鼓**成分的那一下被踩的比例比不带的高一大截
     （+0.19，**150 首里 81% 同号**，随机平移对照上这个差**消失**）；
     **踩镲单独响**的那一下是全表最容易被舍掉的（被踩 0.37，而"踩镲 + 鼓皮同时响"是 0.55）。
     底鼓单独响介于两者之间（0.48），**比军鼓弱**。
     ⇒ **舍音时先舍"只有踩镲"的那些格子，军鼓一定留，底鼓看情况。**
  2. **★ 这不是强度的伪影**：把事件按 onset 强度分三档后，军鼓效应在**每一档里都在**
     （低 +0.13 / 中 +0.16 / 高 +0.15）；踩镲单响在每一档里都比"含鼓皮"低约 0.14。
     强度与军鼓是**两条独立的线索**。
  3. **★ 留重音**：onset 强度高于该批中位的那些被踩 0.58、低的 0.44（+0.14，**157 首里 89% 同号**，
     对照 −0.005）。这比知识 **068 第 5 条**"舍音中踩重音 65% vs 随机 58%"给出的印象**更强**——
     068 那个数是"挑重音"这个布尔判据的命中率，本条是直接的两组对比。
     **068 第 5 条"这个比例不随难度变化"仍然成立，本条不推翻它**，只是把效应量说清楚。
  4. **★ 长音优先**：到本轨**下一个音**的间隔在中位以上的那些被踩 0.57、以下的 0.45
     （+0.12，154 首里 81% 同号，对照 +0.007）。与强度交叉看是**两条正交的轴**：
     "强度低 ∧ 间隔短" 被踩 0.34（最常被舍），"强度高 ∧ 间隔长" 0.65（最常被留）。
     ⇒ **密集连打里被删掉的是中间那几下，留下来的是"后面有空"的那一下。**
  5. **★「小节的第一个音」没有优待（与直觉相反）**：小节里最早的那个音被踩 0.469、其余 0.515
     （−0.047，只有 38% 的曲子同号；随机对照也有 −0.028，说明净效应很小）。
     "停顿 ≥1.5 拍后重新开口的第一下"同样是负的（样本很小，只当没有证据）。
     ⇒ **不要按"每小节第一下必踩"来铺。**
  6. **★「多轨齐奏点几乎必踩」不成立**：有 ≥1 条其他轨同刻的音被踩 0.532、没有的 0.479
     （+0.053，66% 同号）；**加到 ≥2 条不再涨**（0.531）。有一点方向，但远不是"必踩"。
  7. **音高**：只有 36 首有 basic-pitch 缓存、539 个事件，音高跳跃大的略高（+0.035）、
     音符时值几乎无差（−0.009）——**样本太薄，不下结论**。
  8. **★ 这套倾向不随段落变化**：サビ / Aメロ / 間奏 / イントロ / 落ちサビ / ドロップ 六个段落上，
     军鼓效应 +0.16 ~ +0.20、强度效应 +0.09 ~ +0.18，**方向与量级都一致**。
     ⇒ 舍哪一半是**乐器层的判断**，不是段落层的判断。
  9. **写谱端怎么用**（`docs/workflow-sop.md` §6 采音步骤）：决定"这一小节舍一半"之后，
     按 **军鼓 → 重音 → 后面有空隙** 的顺序留，**先删只有踩镲的格子**；
     不要按"隔一个取一个"或"只踩强拍"来删（那是网格判据，AGENT.md 准则 12 明令禁止）。

  **证据注脚**：舍音小节 3 191 个（骨架轨 drums 17 378 事件 / piano 1 044 / vocals 790 / bass 750 / other 1 548）；
  总体被踩率 0.508、随机平移对照 0.216。鼓件组合被踩率：踩镲+鼓皮 0.554（n=10 850）＞ 军鼓单独 0.549（663）
  ＞ 底鼓单独 0.484（2 668）＞ 踩镲单独 0.366（2 510）＞ 无标签 0.341（687）。
  强度 × 间隔交叉表（鼓骨架）：0.344 / 0.436 / 0.450 ｜ 0.441 / 0.541 / 0.606 ｜ 0.484 / 0.593 / 0.651。

- **谱例**（官谱原文 1 行 + 目标轨事件表 ≤6 行）：

  `Infantoon Fantasy` MASTER（13.8 / 185 BPM）**m072**（Aメロ，骨架轨 drums，coverage 0.50，判「舍音」）：

  ```
  2-5[8:1]/7,2/8-4[8:1],1-5[8:1]/8,1b,
  ```

  | 拍 | onset 强度 | 鼓件 | 谱面 |
  |---:|---:|---|---|
  | 0.99 | 0.64 | snare+hihat | **踩** |
  | 1.57 | 0.09 | hihat | 舍 |
  | 1.99 | 0.54 | snare+hihat | **踩** |
  | 2.53 | 0.19 | hihat | 舍 |
  | 3.00 | 0.39 | snare+hihat | **踩** |
  | 3.53 | 0.24 | hihat | 舍 |

  一小节 6 个鼓点，官谱**整齐地只踩军鼓那三下**，三下踩镲反拍全舍——同时命中"留军鼓"与"留重音"两条。
  同形另见 `sweet little sister` MASTER（13.4）m010（`1h[4:1],2h[4:1],3h[4:1],4h[4:1],`，5 个鼓点踩 3 舍 2，
  舍掉的两个都是踩镲单响）。

- **理由**：160 首配对实测；每一项都配了随机平移对照（军鼓 / 强度 / 长短音的对照差都在 ±0.01 以内，
  说明不是密度伪影），并做了曲内配对（每首自己比自己）以排除"曲与曲之间难度不同"的混杂。
- **来源**：本条为 `.agent/notes/063` 一轮的新统计；实现依赖
  `tools/calibration/sampling.py`（舍音判定、pool 去重、强度）与
  `tools/audio_analysis/onsets.py::drum_components`（鼓件频带启发式）。
- **置信度**：**经验（agent 观察，n=160 首 / 21 510 个事件，未经用户确认）** / **存疑**
  （① **鼓件是频带启发式不是鼓谱**，"军鼓"这一类里混着拍手、军鼓边击与部分 tom；
  ② 舍音小节由 `THRESHOLDS` 的内部切点选出，换切点样本会变；
  ③ 只看"被踩 / 未踩"，没有看"踩成了什么"（tap / 双押 / 星星头）；
  ④ **没有听审**，所有"音乐特征"都是信号量；
  ⑤ 音高一项样本太薄（36 首）不成立）。

# 084 — 绕手交互的手级形态：两手被挤在三个相邻键里轮流插空，整片区域每两三个音挪一格

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：388 个官方 ST 谱；教程五个谱例用**键序列比对**精确定位（不是逐帧），另按本条描述的形状在全库检索出同形小节再人读原文确认。手的分工由 `hands.py` 给出（AGENT.md 准则 12）。

- **日期**：2026-09-20
- **要点**：知识 038 的「绕手交互」只有教程一句手感（「打起来很绕手，非常吃协调」）。回到官谱看，它在手级上的共同点**不是"分配一直在变"**，而是：**一个两键（偶尔三键）的小交互单元被原地敲 2–3 次，然后整体在环上挪一格或跳一次**；两只手全程被挤在**三个相邻键**的小片区里轮流插空。**难点在单元与单元的接缝，不在"一直重算"。**
- **详情**：

  1. **形状**（agent 归纳）：单元在环上一格一格爬（`{7,8}→{8,1}→{1,2}`、`{7,8}→{6,7}→{5,6}`、`{3,4}→{5,6}`），或者**轴固定、伙伴键换**（轴钉在 8，伙伴 `1→5→2`）。也有整块平移三格、或直接跳到对侧的写法。
  2. **两手的做法**：
     - **每个单元内部是干净的两手交替**，一手一个键，**手型是现成的**；
     - **难点全在接缝上**：单元一挪，两只手要**同时**把自己的落点挪一格，而两只手本来就贴在一起，所以接缝处经常出现「同一只手连着打两下」或者「两手在环上的前后关系**翻个面**」；
     - **两手始终挤在一小片区域里**——这是与 018 普通交互（键对固定）、021 轴交互（轴固定）、025 散点（满屏分散）都不一样的地方。
  3. **★ 它不靠出张制造难度**：教程五段合起来几乎一个出张落点都没有。绕手的难**不是把手推出舒适区**换来的。
  4. **★ 它在手级上比同谱其余地方更"黏"**：绕手段的「两手落点这个二元组换得勤不勤」和「同一只手相邻两次落键隔多远」**都低于同谱中位数**。也就是说手并没有一直在重新分配，恰恰相反——**手型很稳，稳到挪一格都别扭**。
  5. **和 025 散点是反的**：散点的特征是满屏分散（覆盖范围大），绕手恰恰**只占三个相邻键**。两者在"两手占多大地方"这个量上方向相反。
  6. **和 037 反手相邻**：两手落点贴得极近（教程五段里"相距不超过两格"的比例接近 1），接缝处能看到一只手越过另一只手。
  7. **常见亚型**：用一个 **hold 把一只手钉住**、另一只手在小片区里绕（`58-おちゃめ機能` 的手法），以及**全双押版**（整小节写成 `78,78,18,18,12,12,18,18` 这种，键对同样在爬）。

  **证据注脚**（诊断量均为 agent 为本轮临时定义、无社区背书）：教程五例的精确位置 = `149-Blew Moon` m066–m071（已帧核对）、`61-天国と地獄` m040–m041、`58-おちゃめ機能` m030–m035、`41-Streak` m029 末–m030、`106-トルコ行進曲` m039–m044。五段的「连续 6 个击打的最小覆盖弧」**一律 = 2**（同谱其余小节中位 = 4）；「键对变化率」0.235–0.692 vs 同谱中位 0.556–0.875；「同手位移均值」0.529–1.20 vs 同谱中位 1.111–1.429；出张合计 2 个落点。按这个形状在 388 谱里又找到 **195 个同形小节 / 104 张谱**，典型新例：`923-Grip & Break down !!` m061、`93-記憶、記録` m040、`69-Nerverakes` m026、`821-真・ハンサム体操でズンドコホイ` m012、`921-Imperishable Night 2006` m053、`1823-キレキャリオン` m067。

# 060 — 配置：同起点拍滑（同头星星 / 发牌段 / 电车段）

- **日期**：2026-09-19
- **要点**：同起点拍滑 = **星星从同一个起点向不同键位连续放射**，正攻时**左右手每次交替"拍一根、滑一根"**。教程别名"**发牌段**"；密度极高、看不清顺序的极端版叫"**电车段**"。它**考验防蹭**，且"部分曲目按左右左右的手序打会出张"。
- **详情**：

  ### 教程说明（转述）
  - `[35:10]` 定义：「也可以叫**同头星星**……此处特指**星星从一个起点开始向其他键位放射**，在**正攻情况下左右手每次交替拍滑处理一根星星**的配置」「（你也可以叫**发牌段**）（**手速够快单手全滑了这也是一种发牌**）」。
  - `[35:10]` 难点：「**考验防蹭的能力**，**部分曲目按照左右左右的手序打会有出张星星**」。
  - `[35:10]` **三种常见处理手法（教程明列）**：
    1. **一手打星星头一手滑星星**：适用 白火花、**Selector**；
    2. **同时处理手法**：适用"**位置相邻星星，8 分音 75BPM，4 分音 150BPM**"（**教程给出的唯一数值阈值**）；
    3. **画"Z"字手法**：适用 **深海少女标准谱**、**白香水（Fragrance）**。
  - `[36:52]` **电车段**：「当一个配置难到一定程度就能拥有姓名，**大量的连续的单起点拍滑，不提前背板根本看不清顺序**，还很蹭，**基本上第三个星星头开始就得切内屏打**」（曲例 電車電車 13.7/134）；`[37:02]`「**电车段的下位，东方电车，星星头全带保护**」（風神 13.7/135）。
  - 谱例：（缺名）12.0/200、**深海少女【SD】13.2/137**、（缺名，"出张的情况"）13.2/178、（缺名）13.2 RE:MAS/200、**炎歌 13.7/108（"相反起手能规避出张"）**、（缺名，"出张的情况"）13.8→13.9/159、初音天地開闢神話 13.9/240、雷切 14.8 RE:MAS/165。

  ### 谱例
  **定位成功**：`resource/official-chart/752-深海少女-mas.txt`，**m073**（教程 示例二 定数 13.2 / MASTER / BPM137，【SD】＝标准谱，与本地 ST 谱一致）：

  ```
  m073| 3,5-3[8:1],5-7[8:1],5-2[8:1],5-8[8:1],5-1[8:1],,,
  ```
  **五根星星全部以 5 为头**，终点依次 3 → 7 → 2 → 8 → 1，是最标准的"发牌"。同曲 m030（`8-5,8-4,8-3`）、m058（`4^7,4^1,4-8`）是三根版。

  **另一处（教程点名"相反起手能规避出张"）**：`resource/official-chart/64-炎歌 -ほむらうた--mas.txt`，**m051–m052**（教程 示例五 定数 13.7 / MASTER / BPM108 三项全对）：
  ```
  m051| ,1-5[8:1],1^4[8:1],1-6[8:1],1-4[8:1],1-5[8:1],1,,
  m052| ,8-3[8:1],8^5[8:1],8-4[8:1],8-5[8:1],8-3[8:1],8,,
  ```
  五根从 1 放射、再五根从 8 放射——**两组的起手手相反**，正是教程说的"相反起手能规避出张"。

  ### agent 理解
  - **手级定义（正攻）**：
    - **拍头手**：两手**交替**，每人一根——第 k 根由 (k mod 2) 那只手按头；
    - **划轨手**：**与拍头手同一只**（拍一根、滑一根＝"拍滑"）；
    - **另一只手任务**：在对方划的同时按下下一根的头（**头恒比轨道领先一拍**，与 049 同构）；
    - **换手时机**：**每一根换一次**。
  - **出张是怎么产生的（把教程那句话形式化，agent 推断，存疑）**：头固定在 K，终点在 K 两侧轮流出现。按 007「划 slide 的手＝末尾所在半边」，**终点落在哪半边就该由哪只手划**；但正攻的"左右左右"是**按顺序轮转**的，两者一旦冲突，那只手就必须跨界 → **出张（043）**。所以：
    - **起手手的选择决定整串的奇偶性** → 炎歌"相反起手能规避出张"就是在选奇偶；
    - **可机检**：模拟"左右交替"分配，统计有几根的划轨手与 007 规则相悖，即为该段的**出张次数**。
  - **教程的数值阈值（唯一一条，直接可用）**：「**同时处理**适用于位置相邻的星星、**8 分音 75BPM / 4 分音 150BPM**」——两者换算都是**每 400 ms 一根**。即：**相邻的同起点星星，当间隔 ≥400 ms 时一只手可以一次盖两根**。这给了 048 容错窗口一个可用的量化下界（*agent 折算，存疑*）。
  - **"第三个星星头开始就得切内屏"（电车段）的含义**：同一个头键被反复击打（＝019 纵连 / 028 子弹的星星版），密到一定程度外键来不及回位，玩家改用内屏触发——这与 **042 狗刨**是同一现象。**对制谱的提醒**：同起点拍滑的密度上限**不由手速决定，而由"同一个键能被连续击打多快"决定**，直接受 009 约束。
  - **"星星头全带保护"（風神＝东方电车的下位）**：即把头写成 **Ex/绿护 break**，靠判定保护把蹭降级——这与 010/011 里"加 Ex 保护可降级"是同一手段，说明**官方谱确实用保护来放行高风险的同头星星**。
  - **家族位置**：**同头星星**＝ 058（协调段）、060（本条）、061（三叉戟）三条共用的上位概念；058 是"固定手甩两边"、060 是"两手轮流拍滑"、061 是"一手包三根 + 一手干别的"。

# 067 — 手序：段首先出手 = 离上一段结束近的那只手

- **日期**：2026-09-19
- **要点**：一个配置的**先出手**，最好是**离上一段结束（位置近）的那只手**——上一个配置把手带到了这里，在这里放这个配置就更友好、更轻松；**上一个配置结尾的键的附近**也是可以的，因为手就在那个区域，很轻松就能触碰到、移动到。
- **详情**：

  ### 用户原话（逐字）
  > 先出手肯定是最好是里上一段结束的手，因为上一个配置把手带到这里了，那就正好放这个配置会友好一些轻松一些，其实上一个配置结尾的键的附近的地方也是可以的，因为手就在那个区域，是很轻松就可以触碰到移动到的位置。

  ### 主会话解读（用户 2026-09-19 已确认，原话「差不多」）
  - 原话中的「**里**上一段结束的手」按「**离**上一段结束（位置近）的手」理解——即**上一段结束时更靠近新配置起始位置的那只手**先出手。该理解经主会话向用户复述后确认。
  - 原话给的是**两件互相支撑的事**：
    | # | 内容 | 用户给的理由 |
    |---|---|---|
    | ① | **先出手 = 离上一段结束近的手** | 「上一个配置把手带到这里了」→ 放这个配置**友好一些轻松一些** |
    | ② | **新配置可以放在上一个配置结尾的键的附近** | 「手就在那个区域」→ **很轻松就可以触碰到移动到** |
  - 即段与段之间是**位置连续**的：①是"谁起手"的选择依据，②是"起手位置写在哪"的选择依据，两条都由"上一段结束时手在哪"决定。

  ### 对手序模型的含义
  1. **段首起手不是自由参数**。`hands.py` 现在只有整谱级的 `force_first_hand`，`docs/hand-sequencing.md` §7 扩展点 4 还打算做"逐段起手枚举取代价低者"；按本条，段首起手应由**上一段的结束状态**决定——段边界**不重置**两手状态，谁离新配置起点近谁起手。模型里已有的位移项 M 与速度项 V 在段边界继续生效即可表达这一条（主会话解读）。
  2. **与知识 060「相反起手能规避出张」不冲突**（agent 解读，待用户确认）：060 讲的是**星星段内部**起手奇偶如何影响出张根数，本条讲的是**段与段之间**该由谁起手的默认依据。两者作用在不同层级；若冲突（离得近的手起手反而制造出张），用户未给裁定。
  3. **这是一条写谱规则，不只是判定规则**：②要求**新配置的起始键落在上一配置结尾键的附近**——应进 `docs/hand-sequencing.md` §6.1 的写谱顺序（选配置 → 定起手）与 §6.2 的 `hand_plan.start_hand` 字段说明。
  4. **"附近"的量化用户未给**（agent 记录）：多少个键位算"附近"、是否按环距计，原话没有；若要机检须另行标定，并标明是 agent 操作化。
- **理由**：用户谱师讲授，原话即边界；"里→离"的读法经用户确认。
- **来源**：用户讲授 2026-09-19（对齐手序对话）；「里→离」的理解经用户同日确认（原话「差不多」）。
- **置信度**：确信（用户谱师讲授）

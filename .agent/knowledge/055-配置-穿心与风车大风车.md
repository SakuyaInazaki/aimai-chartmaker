# 055 — 配置：穿心 / 风车 / 大风车

- **日期**：2026-09-19
- **要点**：穿心 = **穿过圆心的直线星星（`n-(n+4)`），头沿顺时针或逆时针落在相邻键位上连续出现**；教程口径 **一组 ≥3 根即称穿心配置，绕满一圈称大风车**。它的难点在"滑星星的精度"与"手会打结"，教程给了**四种**互相排斥的处理手法。
- **详情**：

  ### 教程说明（转述）
  - `[17:51]` 定义：「一般情况下，**穿心就是指穿过圆心，以顺时针或逆时针，在相邻键位上连续出现的直线星星**。一般**一组出现 3 根就可以称为穿心配置**，**转一圈的可以称为大风车**，**考验滑星星的精度**」。
  - `[17:51]` **四种处理思路**（教程明列，玩家侧）：
    1. **正攻**：「**大量出张动作发生，手容易打结**，注重动作安排，**可以适当扭腰去处理**」；
    2. **换手**：「每个人在哪里进行换手的时机都不一样，**注重手序设计**」；
    3. **打完星星头直接滑**：「**只要滑得够快就不用防蹭了**，适用于**比较快且没有夹键**的穿心」；
    4. **同时处理手法**：「**从第二根开始滑，滑的时候同时把第一根滑掉**，不同的 BPM 要相对应调整滑动的速度」。
  - **教程自带的形态阶梯**（示例标题）：**只有星星头** → **只有星星头，一圈** → **星星头带夹键** → **星星头带夹键，一圈** → **带启动音** → **示例四+五：启动音+带夹键** → **复杂节奏** → **圣剑穿心**。
  - 谱例（节选）：Justified 12.9 EXPERT/185、-T.V.maimai edit- 12.8/160、Define 13.6/175、Heartbeats 13.2/170、**Oshama Scramble!【SD】14.5/190（带启动音）**、**Ignis Danse 14.6/246（复杂节奏）**、**Caliburne 14.3/190（圣剑穿心）**、Excalibur 14.8/200。

  ### agent 理解
  - **形状判据（可机检，A 档）**：连续的直线 slide 序列，满足 ① `(end-head) mod 8 == 4`（穿过圆心）；② 相邻两根的头键 `Δ = ±1` 且**同向**；③ 连续 ≥3 根 → 穿心；④ 头键走满 8 个 → **大风车**。Ignis Danse m107–m108 是标准阳性样本。
  - **手级定义（四种手法各自的分工，agent 依教程整理）**：
    | 手法 | 拍头手 | 划轨手 | 另一只手 | 换手时机 |
    |---|---|---|---|---|
    | 正攻 | 按 006 分页就近 | **同一只手** | 拍下一根的头 | 每根一换（＝049 骨架） |
    | 换手 | 就近 | **另一只手** | 接力 | **因人而异，教程明说没有定式** |
    | 打完直接滑 | 就近 | 同一只手，**不等启动拍、立刻划完** | 空出来准备下一根 | 每根一换 |
    | 同时处理 | 就近 | **一只手一次盖两条** | 全程只有一只手在划 | 段内不换手 |
    **"同时处理"是四种里唯一改变账本的**——它让"一只手吃两根星星"，与 042 狗刨属于同一类"手法改变占手数"的现象（*推断，存疑*）。
  - **为什么"手容易打结"**：穿心的终点在起点的正对侧，按 007「划 slide 的手＝末尾所在半边」的规则，**每一根都在要求换手**；而头又沿圈推进，于是两只手不断被推向同一侧 → 这正是 **043 出张 / 037 反手**。教程原话"大量出张动作发生""可以适当扭腰"直接印证。
  - **"考验滑星星的精度"的含义（推断，存疑）**：穿心轨道经过屏幕中心，**中心区是所有轨道的公共交叉点**；划偏一点就会压到另一条轨道或另一只手。这与 051 CYCLES"手尽量靠中间"是同一个物理问题的两面。
  - **写谱侧的强度钮**：是否带启动音 tap（→049 骨架）、是否带夹键（→053）、是否绕满一圈、BPM。教程谱例从 **12.8 一路铺到 14.8**，跨度比任何其他星星配置都大——**穿心是星星段最通用的强度载体**。
  - **红线**：穿心轨道会扫过起点与终点之间的**全部 A 区**（经过圆心的直径两端各 1 个 A 区，途中还压住内屏），所以 **011 撞尾的检查必须对整条直径做**，不能只看终点那一个区（*推断*）。
- **理由**：定义、阈值（3 根 / 一圈）与四种手法全部为教程明文；形状判据与手级分工表由 agent 按教程整理，并在 Ignis Danse / Oshama Scramble 官谱上验证阳性。

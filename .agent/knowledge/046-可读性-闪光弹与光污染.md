# 046 — 可读性：闪光弹 / 光污染（连续全屏 touch 特效）

- **日期**：2026-09-19
- **要点**：闪光弹 / 光污染 = **touch 用出了连续的全屏闪光特效**，既抬高读谱难度、又实打实伤眼睛、**容易诱发光敏性癫痫**——这是一条**设计禁忌**，不是一种可用配置。

  ### agent 理解
  - **成因是游戏的渲染规则，不是谱面记法**：maimai DX 里每个 touch 命中都会放一圈放射状光效；当 touch **密集且分布在多个区**时，光效彼此叠加就糊成全屏白/彩闪。所以**"闪光弹"是 touch 密度的副作用**，谱面上看不到任何"闪光"这一 note 类型。
  - **它是一条硬规范，不是风格选择**：教程把三件事并列——读谱难度、眼睛伤害、**光敏性癫痫**。前一条还能算难度设计，后两条是健康风险。**生成器不得为了"高潮更炸"而堆连续全屏 touch**。
  - **对本项目的直接影响**：016 已确定 **ST 谱不含 touch**，所以当前的输出天然不会触发这个问题；**一旦将来扩到 DX 谱，必须把"连续全屏 touch"列进黑名单**。可操作的约束建议（agent 推断，存疑，待实测校准）：
    - 同一时间窗内**跨区**的 touch 不要连续堆叠（例如：连续 8 拍内每拍都有 ≥2 个不同区的 touch，就该判警告）；
    - `C`（中心区）连打尤其危险——它的光效覆盖面积最大；
    - 知识 013 记的 touch 摆放经验应当补上"**特效叠加**"这一维度，而不只看手序可达性。
  - **与 038 绕手 / 025 散点的区别**：那两条的读谱难度来自**信息本身**（形状难辨）；光污染的读谱难度来自**信息被遮蔽**（画面被特效盖住）。**前者是合法的难度手段，后者不是**——玩家看不见的不叫难，叫不可读。

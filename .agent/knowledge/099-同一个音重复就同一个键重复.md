# 099 — 同一个音重复，谱面就**同一个键重复**（子弹是采音的主力，不是点缀）

> ⚠️ **本条为 agent 观察，未经用户确认。** 来源：同曲官谱抄谱对照（note 069）。n=1。

- **日期**：2026-09-20
- **要点**：参考谱全谱有 **132 对**"同一个键在半拍内再来一次"，`configs_hand` 把它认成
  **子弹 57 段、全谱第一主料**，而且**每一段都有**（A 段 5、hat 段 8、drop1 19、薄 build 15）。
  我们只有 **40 对 / 2 段**。音乐里同一个音连着响两下，谱面就在**同一个键**上敲两下——
  我们每次都换了键。
- **详情**：

  典型句子（参考谱，`{8}`）：`…,2,2,4,3h[4:1],,1h[4:1],` / `8,8,6,6,5,,4/6,,` /
  `…,3/5,,3,3,4,3,2,1,` / `…,2/8,2/8,,1,2,3,5,`——**连双押也可以整对重复**（`2/8,2/8`）。

  **为什么我们写不出来**：我们的默认动作是"下一个音换一个键"（怕看起来呆），
  于是把"同一个音响两下"改写成了楼梯 / 交互 / 双押脉冲。结果是——
  **谱面的形状好看了，但它不再是那段音乐**。

  **它同时解决三个问题**：
  ① 中强度段的密度可以不靠加音就降下来（同键重复比换键省手，知识 019：≤3 个可单手）；
  ② 不需要为了"有变化"去铺配置词汇（知识 073 / 102）；
  ③ 它是"舍音"的反面——重复音**不该被舍掉一半**。

- **理由**：子弹（知识 028）在本项目的知识库里一直被当成"一个配置名"，
  388 谱扫描里它也是"几乎每张谱都有"的三件之一（知识 073）。
  本轮的新认识是：**它不是一个偶尔用的配置，它是采音时"照着音写"的默认结果**。
- **来源**：`docs/research/test-01-vs-reference.md` §2.10 / §3.2 / §3.4；
  同曲官谱抄谱对照（note 069）。
- **置信度**：**经验**（对数与段数为直接统计）/ **存疑**（n=1；"音乐里是重复音"没有听审，
  只有 `song_analysis.json` 的候选池旁证）
- **关联**：**028**（子弹）、**019**（纵连：同键 ≤3 可单手）、**039–041**（2+1 / 3+1 / N+1）、
  **069**（采音跟着音乐走）、**073**（子弹是"几乎每张谱都有"的三件之一）、**097**（双押键对）。

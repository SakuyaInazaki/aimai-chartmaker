# 071 — 定数升档 = 加配置种类、加每类的时长，不换配方

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：388 个官方 ST 谱（定数 13.0–14.5），按"每张谱的定数 × BPM × 它实际用了哪些配置"对照（用户 2026-09-19 裁定的看法），键位版（17 类）与手序版（40 类）两套透镜都跑过。

- **日期**：2026-09-20
- **要点**：同一 BPM 档内，**定数每升一档，官方谱不更换主料配置**——变的是
  ① **用到的配置种类变多**；② **原有的每一类写得更久**（小节占比同步上升）；
  ③ 在常写的那几类之上**叠加**一两类几何配置。
  **升定数靠的是密度与细分音，不是多押与星星**（知识 070）。
- **详情**：

  1. **"种类变多"这条在两套透镜下是同一个数**：把可用配置名从 17 类换成 40 类（手序版），一张谱用到的配置种类中位从 10 涨到 15–16，但**"配置种类数随定数上升"的相关强度一点没变**——说明这不是透镜制造的假象。
  2. **每类写得更久**：普通交互、错位、跳拍等常写配置的小节占比随定数同步上升。
  3. **叠加的是几何族**：三角交互 / 楼梯交互 / 大宇宙 / 轴交互 / 散点 / 逆楼梯（方向盘）随定数上升最明显，是**随定数才被启用**的一族。
  4. **唯一反着走的是侧边双押**（其次是连续双押，贴天花板的抖动）——**低定数谱反而更常写侧边双押**。
  5. **星星族内部会换档**（手序版新发现，是对"配方不换"的一条限定）：低定数谱**不是不写星星**，写的是**接得顺**的那种（绕圈星星、连续拍滑）；高定数谱换成**要分手、要防蹭**的那种（二连扫、挥手段、三叉戟、拆弹、反手）。

  **证据注脚**：ρ(定数, 配置种类数) = +0.456（键位版）/ +0.456（手序版 v0.1）/ +0.450（手序版 v0.2）；ρ(定数, 各类出现率) 符号 17/17 三版一致；种类数中位 10（Q1 8 / Q3 12）→ 15（Q1 13 / Q3 18，范围 7–27）；小节占比 普通交互 11%→27%、错位 17%→28%、跳拍 8%→19%；侧边双押 ρ = −0.090 / −0.052 / −0.067（4 个 BPM 档一致为负）；星星族 二连扫 +0.264 / 拆弹 +0.193 / 挥手段 +0.185 / 三叉戟 +0.173 vs 绕圈星星 −0.133 / 连续拍滑 −0.077。

- **理由**：用户 2026-09-19 裁定难度只能按「每张谱的定数和它对应的 BPM 和它的配置这样对照着来看」，本条是该口径下 388 谱的实测方向；**不给配置打分、不预设某类配置必须出现**。

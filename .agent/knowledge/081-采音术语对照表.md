# 081 — 采音术语对照：采音≡踩音 / 全踩 / 舍音 / 留白 / 采空音（"空音"是反义词）

> ⚠️ **本条为 agent 调研结论，未经用户确认。** 口径：中文制谱社区**公开图文**语料——MMFC《谱面创作基础学 长篇指南》、萌娘百科《音乐游戏/用语》、B 站专栏 47 篇正文（含 maimai 与 Arcaea / CHUNITHM / Deemo / 舞立方 / 4K 圈旁证）。**QQ 群、贴吧、知乎未进语料**，日文原生术语（「音取り」）未纳入映射。

- **日期**：2026-09-20
- **要点**：说"目标音轨的音被踩了多少"时，社区的词是——**全踩**（＋音轨名）、**舍音**（只踩一部分）、**留白**（音乐有音而谱面故意不踩；失误版叫**漏音 / 漏采**）；谱面写了音轨里**没有**的音叫**采空音 / 插空音**。
  ⚠️ **最要紧的一条：「空音」在社区里指的是后者**（谱面**多**写了音），与"留白"**方向相反**——**继续用"空音"表示"不踩"，社区读者会把结论读反。**
- **详情**：

  | 概念（白话） | 社区用词 | 同义 / 近义 | 出处举例 |
  |---|---|---|---|
  | 把这条轨的音基本都踩上 | **全踩**（＋音轨名） | 全部采、所有的音都采 | MMFC 5.4「全踩人声」 |
  | 只踩其中一部分 | **舍音**（最接近的谱师用词，社区**无固定名词**） | 采音取舍、简 / 删到不能再删、省去、规律性减少点击 | B 站 cv20421237 / cv5509401 / cv11688050 |
  | 只踩显眼的音 | **主高** | — | Arcaea 圈 cv5509401 |
  | 音乐有音而谱面故意不踩 | **留白** | （失误版）漏音 / 漏采 | cv19169007 / cv50946813 |
  | 谱面写了音轨里没有的音 | **采空音 / 插空音** | dump、塞 / 塞爆、荡谱、补拍、玄学采音 | 萌娘百科 / cv14147817 / cv43894622 |

  1. **采音 ≡ 踩音**，两种写法社区并用（MMFC 第二章写"采音"、第五章写"踩音"），项目两种都可用。
  2. **被证伪的词**：`半采` `半踩` `全采` `满采` `采满` `隔一个采` `减采` `抽采` ——在 47 篇语料里**一处都没有**，是本项目/用户自造。`采全音 / 半采音 / 空音` 三词是用户随口起的（用户 2026-09-20 原话：「这些词是我编的」），**已停用**。
  3. **「加花」不是音游制谱词**：语料里仅有的一次是"加点花样／加点难度"的意思，**不是**"踩音轨里没有的音"；后者的社区词是采空音 / dump。
  4. **「空拍」是 simai 语法的空逗号**（MMFC 4.3），**不是采音术语**，不得借用。
  5. **方向陷阱**：4K 圈的「**严格采音 / Accurate**」说的是**谱面 → 音乐**方向（不许有找不到出处的 note），而「全踩」说的是**音乐 → 谱面**方向（音轨的音都被踩了），**两者不可互换**。
  6. **社区并不把这三个词当一组互斥分类用**：「全踩」描述一段跟定一条轨、「舍音」描述一张谱的取舍基调、「留白」描述某几小节；把"踩了几成"切成三档**是本项目的工具操作化**（知识 068），不是社区术语定义。
  7. **已确认无需改动的相邻社区词**：**切轨**（知识 002）、**混 fr / 混フレ**（知识 045）、**哪个响踩哪个**（知识 002）、**疏密**、**对音 / ZURE**。
  8. **一个已知缺口**：MMFC 5.3 的「**似踩非踩**」（铺满 8 分网格、不跟任何音轨）在本项目的三词口径里**归不进任何一档**，记此备查。

- **理由**：术语用错方向会让结论被读反（"空音"）；术语自造会让知识库与社区、与用户的沟通脱节。所以采音侧的词必须一个个对到概念上，不能整体套用。

- **置信度**：**经验（agent 社区调研，公开图文语料 47 篇 + MMFC + 萌娘百科，未经用户确认）**——其中「空音在社区是反义词」「采音≡踩音」「半采/全采/加花不是社区词」有**百科级或多来源**证据；**存疑**（①「全踩」只有 MMFC 一个来源，手册用语可靠但口头行话程度不确定；②「舍音」是**最接近的**谱师用词，不是公认的分类名；③ 谱师口语最集中的 QQ 群与贴吧/知乎未进语料）。

# 061 — 配置：三叉戟（含二叉戟）

- **日期**：2026-09-19
- **要点**：三叉戟 = **同起点星星的定型子类**——从**一个点放射三根星星**；狭义/常见的画面是"**在 1 号或 8 号键从上往下放射**，一只手负责滑这三根并防蹭，**另一只手同时处理其他音符**"的复合配置。只有两根时教程戏称"**二叉戟**"。
- **详情**：

  ### 教程说明（转述）
  - `[37:16]`「**同起点/同头星星的其中一种表现形式**，如果按形状来说，**从一个点放射三根星星都可以叫三叉戟**」「但说到三叉戟配置，**通常想到的画面是：在 1/8 号键从上往下放射的星星，一只手去滑星星还要注意防蹭，而另一只手去同时处理其他音符的复合型配置**」「**如果只有两根星星那就叫二叉戟吧**」。
  - 谱例：Hainuwele 14.3/157（**示例一：二叉戟**）、鮎右肩（OCR 缺）13.7/150、**Party 4U ”holy nite mix” 13.7/159**、emomomo 13.7/145、MAKE IT FUNKY NOW 13.7/146、**LANCE 13.8/156**、（缺名）13.8/181、**Caliburne 14.3/190（批注「补一个一笔画魔法阵」）**、Excalibur 14.8/200。

  **定位成功**：`resource/official-chart/374-Party 4U ”holy nite mix”-mas.txt`，**m051 / m053**（`{16}` @159BPM；教程 示例三 定数 13.7 / MASTER / BPM159 三项全对）：

  **四根星星全部以 1 为头**（终点 5→4→6→3），每根同刻还挂着**一个落在另一半边的 tap**（8、6、6、8）以及其间的散 tap——这正是教程说的"一只手滑星星、另一只手同时处理其他音符"。m053 是把头换到 8 的镜像版。

  **另一处**：`resource/official-chart/369-LANCE-mas.txt`，**m072–m075**（教程 示例六 定数 13.8 / MASTER / BPM156 三项全对）——`1-5/8, 1^3/7, 1-4` 与 `8-4, 8^6/2, 8-5` 交替，**头在 1 和 8 之间逐小节对调**。

  ### agent 理解
  - **形状判据（可机检，A 档）**：窗口内存在一个键 K，以 K 为 head 的 slide 数 **＝3**（二叉戟 ＝2，四根以上退回 060 发牌段），且这些 slide 的终点互不相同、时间上连续 → 打 `trident` 标记；若 **K ∈ {1,8}** 再加一条 `canonical` 标记（教程口径的"通常画面"）。Party 4U m051（K=1，4 根）与 LANCE m072（K=1，3 根）可作正负样本对照。
  - **手级定义（与 060 发牌段最关键的差别）**：
    - **拍头手 ＝ 划轨手 ＝ 同一只手**，**三根全包**（060 是两手轮流一人一根）；
    - **另一只手任务**：**完全独立的另一条线**——tap、扫键、夹键都有可能（Party 4U 里是对侧散 tap）；
    - **换手时机**：**段内不换手**；左右分工从段首定死。
    - 所以它在结构上是 **027 定拍 / 058 挥手段 / 033 死镰段的同族**——"一手专职一条线、另一手专职另一条线"的双任务段。
  - **为什么头偏爱 1 / 8（agent 推断，存疑）**：1 和 8 在屏幕顶部、恰好在左右半圈的分界缝上（006 的分页缝）。把头放在缝上，**滑轨手可以向任意一侧放射而不立刻构成出张**，同时把整个下半屏留给另一只手。这解释了教程说的"通常想到的画面"。
  - **"还要注意防蹭"的具体对象**：三根共头意味着**同一个 A 区被连续击打三次**，而前一根的轨道刚从那里出发 → 典型的 **010 外键无理**场景（星星头之后同侧还有 note）。Party 4U 里每根之间隔 4 个 16 分（BPM159 ⇒ 377 ms），**恰好越过 010 的 200 ms 线**，是"贴着红线写"的官方样本。
  - **Caliburne 的批注「补一个一笔画魔法阵」**：教程在三叉戟一节里把 Caliburne 的那段同时算作 **057 一笔画**——说明**三叉戟与一笔画可以叠加**（三根共头且首尾相连）。
- **理由**：定义、常见画面、二叉戟叫法为教程明文；两首谱例的"共头三根 + 另一手独立线"形态逐格核对，定数/难度/BPM 与教程逐项吻合。

# 083 — 两条星星夹出的缝里要打音时，官谱把那个音塞在**启动拍之前**

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：388 个官方 ST 谱；"两条星星夹出缝"按记法直接可读的两种形态检索——**收口**（同刻两条星星，两个头键在环上相邻、终点是同一个键）与**交叉**（同刻两条星星，两条轨道在内屏真交叉）。轨道几何是按语法文档做的折线近似（`p/q/s/z/V` 误差最大）。

- **日期**：2026-09-20
- **要点**：知识 052 的「菱形星星」只有教程一句评价（「一个字：**蹭**」）。回到官谱看，**"两条轨道夹出缝"这件事本身太常见，不足以当判据**；真正少见的是**缝里还要打音**。而只要缝里要打音，官谱的写法是一个固定的**三段式骨架**：**两头同落 → 轨道起步前打夹音 → 启动拍上一对 break/tap 把轨道放走**。
- **详情**：

  1. **写法骨架**（agent 归纳，官谱里高度一致）：

     ```
     （第 1 格）两条星星的头同时落下        → 两手各按一个头键
     （中间 1–2 格）被夹的那一个 / 那一对音  → 两手向外各扒一格，轨道还没开始动
     （启动拍这一格）一对 break 或一对 tap   → 轨道同时开始走，两手同时划
     ```
     **那对 break 就是启动拍的标记**（知识 014：启动拍 = `60/BPM` 一拍，与 `{x}` 分音无关）。

  2. **★ 夹音几乎全部落在轨道**开始移动之前****：这是本条最硬的一条。官谱是**用启动拍把夹音和轨道在时间上错开**的——夹音出现时轨道根本还没开始走，手掌无轨可蹭。**不是靠容错窗口硬吃。**

  3. **两手分工**（agent 观察）：
     - **两只手各领一条轨道，头与条不分家**——星星头由哪只手按，那条轨道就由哪只手划。知识 065 允许头与条分属两手，但官谱在这个形态上**基本不使用那个自由度**；
     - **被夹的音不是"某一只手顺手补"**：交叉族里绝大多数的夹音是**同刻成对的双押**，两个键分别落在两个头键的**外侧**，两手的动作完全镜像、同时向外各扒一格再收回来。**单音夹音是少数派**（收口族里多一些）；
     - **夹音离头键很近**：绝大多数距最近的头键只有 1 格，极少数 2 格，几乎没有 3 格。**官谱从来不把夹音扔到屏幕另一边**——手不用离开自己刚按下的头键太远。

  4. **"缝里带音"才是稀有的那一层**：两条轨道收口/交叉的形态在官谱里**极常见**（跨 260 张以上的谱），但其中**只有约一成**在缝里还写了音。所以识别这一族**不能只看"有没有夹出缝"**。

  **证据注脚**：收口族 197 处 / 59 谱、交叉族 746 处 / 230 谱；其中**带夹音**的收口 23 处、交叉 92 处（各约 12%）。带夹音的 115 处里，**113 处（98%）的夹音全部落在两条轨道开始移动之前**（收口族 23/23 = 100%，交叉族 90/92）。交叉族 92 处里 84 处（91%）夹音是**同刻成对**；交叉族 216 个夹音里 148 个距最近头键 1 格、66 个 2 格、只有 2 个 3 格；收口族 33 个夹音**全部** 1 格。官谱例：`434-日本の米は世界一-mas` m014–m015、`318-Scars of FAUNA-mas` m075、`393-Panopticon-remas` m054、`656-頓珍漢の宴-mas` m011、`459-Seyana.-mas` m054/m056、`443-FEEL the BEATS-remas` m036。

- **理由**：052 的结构判据与手级分工**全部是 agent 从两个谱例反推的**，其中三条推断与官谱写法冲突（见 052 的修订记录）。本条不认领"菱形/类菱形"这两个名字（教程没给定义），只描述"两条轨道收口/交叉 + 缝里带音"这个**形态**在官谱里长什么样。
- **来源**：`docs/research/config-gaps-survey.md` §1（方法、谱例、§1.4 启动拍发现、§1.5 与 052 的逐条对照、§1.6 局限、§1.7 草案 N-1）。
- **置信度**：**经验（agent 观察，n=388 谱全量计数，未经用户确认）**（三段式骨架、夹音在启动拍之前、两手镜像外扒）/ **存疑**（① **术语归属未定**——"菱形/类菱形"教程没给定义，本条描述的形态与这两个名字是否对应需用户或教程原文裁定；② 轨道几何是折线近似，`p/q/s/z/V` 误差最大，结论主要建立在直线与外弧上；③ "同屏"用的是可视窗口重叠，真机的显示提前量与消隐时机未取证）。
- **关联**：知识 **052**（菱形星星／类菱形星星——本条推翻了它三条 agent 推断，见 052 的修订记录）、**014**（启动拍：本条骨架的时间基础）、**011**（撞尾：052 说"把 tap 挪到启动之后就变成撞尾"这条推断**被官谱强支持**）、**065**（头与条可分属两手——官谱在这个形态上不用这个自由度）、**048**（容错窗口：官谱在这里**不靠**它）、**051**（CYCLES 型星星，相邻族）。

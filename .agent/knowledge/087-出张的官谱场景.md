# 087 — 出张的官谱场景：最大的一类是"纯单点"，不是"被长条钉住逼出来的"

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：388 个官方 ST 谱，出张按**知识 064 的用户口径**（右手落 6/7 或左手落 2/3；共享区 `{1,4,5,8}` 两手都不算），手的分工由 `hands.py` v0.4 给出。本条只补**场景**，出张的定义、边界与写谱要求一律以 **064** 为准。

- **日期**：2026-09-20
- **要点**：知识 079 已经数过"官谱写了多少出张、写在哪个段落"。本条补**出张的周围长什么样**：**四个落点完全对称**；**最大的一类（约三成）是"纯单点出张"——没有任何手被占，就是让那只手飞过去打一下**；"用长条/星星钉住一只手把音堆到一侧"这个经典写法**只占三分之一**。
- **详情**：

  1. **★ 四个落点对称写**：`R→6`、`R→7`、`L→2`、`L→3` 四者用量**几乎相等**——**没有哪一侧、哪一个键被偏爱**。
  2. **出张的上下文**（互斥分类，按优先级）：

     | 类 | 上下文 | 占比 |
     |---|---|---:|
     | 1 | 另一只手被**星星**钉住 | 20.8% |
     | 2 | 另一只手被**长条**钉住 | 15.4% |
     | 3 | 出张的就是**星星头/轨道本身** | 22.3% |
     | 4 | 出张落点在**同键纵连串**里 | 2.1% |
     | 5 | **同刻双押的另一半** | 9.1% |
     | 6 | **纯单点出张**（上面都不是） | **30.2%** |

     - **类 1+2 = 36.2%**：这正是知识 043 说的机制（长星星/长条占住一只手、把音堆到那一侧）。官谱确实这么用，**但它只占三分之一**；
     - **类 3 = 22.3%**：出张的是**划星星的那只手自己**——星星的几何本来就跨过去了，跟"被逼"无关；
     - **★ 类 6 是最大的一类**：既没有手被占，也不是双押、不是纵连，**就是把一个 tap/hold 交给了对侧的手**。说明 064 口径的出张**大部分时候只是"这一下由那只手更顺"**。
  3. **★ 出张几乎不与纵连同现（2.1%）**：**官谱不会让一只手跨过去以后在那儿连敲。**
  4. **★ 出张靠"这一下本来就要飞过去"，不靠"手已经在附近"**：出张落点离**本手上一次落键**通常**不近**（中位约三格）。这与侧边双押正好相反——侧边双押靠"手就在隔壁"成立（知识 082 的 E 型 98.4%）。
  5. **写出张时的"引导"长在两侧，不长在前面**（agent 定性判断，存疑）：官谱要么**让另一只手被钉住**（玩家没得选，反而好判断），要么把它做成**一个对称模板的一格**（`45,,45,,2,3,2` / `56,23,78,45,12` / `1,,78,,6,7,6`）——**玩家认的是模板，不是单个 note**。
  6. **★ 出张密度随定数下降**：13 字头的谱写得最多，14.5 档最少；而 `出张 / slide` 四个定数段几乎不变。差的那部分来自 **tap 侧**——**高定数谱把 tap 收在自己半边，难度改用别的手段加**。
  7. **段落**：**Bメロ 最多、ラスサビ 最少**（每 1000 note）——出张出现在**"过门/铺垫"段落多于"最后高潮"段落**。

  **证据注脚**：388 谱 **5 739 个出张落点 / 377 谱**（11 张谱一次都没有），中位 19.2 / 1000 任务、均值 23.2、最高 117.4。四落点 `R→7` 1 484 / `L→3` 1 426 / `L→2` 1 420 / `R→6` 1 409。按任务类型 tap 2 212（38.5%）/ slide 轨道 1 826（31.8%）/ hold 1 132（19.7%）/ 星星头 515（9.0%）/ wifi 54，带 BREAK 86（1.5%）。上下文六类 1 191 / 885 / 1 280 / 123 / 524 / 1 736。本手上一落键到出张落点的环距 0:403 / 1:777 / 2:1 578 / 3:1 816 / 4:1 142。按定数（每谱 `出张/1000 任务` 中位）13.0–13.4 **23.0** → 13.5–13.9 17.2 → 14.0–14.4 16.7 → 14.5+ **10.9**；`出张/slide` 四段 0.230 / 0.209 / 0.225 / 0.227。按谱内五等分 981 / 1 155 / 1 154 / **1 296** / 1 153。段落（每 1000 note）Bメロ **27.5** ＞ 落ちサビ 25.7 ＞ Aメロ 23.4 ＞ イントロ 22.4 ＞ サビ 21.3 ＞ ドロップ 19.9 ＞ 間奏 18.9 ＞ ラスサビ **14.5**。官谱例：`450-ダンスロボットダンス` m106（类 1）、`129-Sprintrances` m023（类 2）、`467-天火明命` m063（类 3）、`151-Rooftop Run＿ Act1-remas` m042（类 4）、`65-脳漿炸裂ガール` m017（类 5）、`493-セイクリッド ルイン` m064 / `325-ロストワンの号哭-remas` m069 / `74-maiム・maiム` m019（类 6）。

- **理由**：知识 043 里有两条 agent 推断（「几乎总是用一条长星星/长条占住一只手」「出张本身不贵，贵的是出张的密度与跨度」）没有官谱侧的核对。本条把出张的周围环境数清楚，结果两条推断**一条只覆盖三分之一、一条拿到反向证据**（见 043 的修订记录）。

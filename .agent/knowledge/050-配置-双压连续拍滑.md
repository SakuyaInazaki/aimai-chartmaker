# 050 — 配置：双压连续拍滑

- **日期**：2026-09-19
- **要点**：双压连续拍滑 = **两手固定在一对键上，每个四分音同时拍下一对星星头；这一对头同时又是上一对星星的启动拍**——于是"双押 → 两手一起滑 → 双押 → 一起滑"循环不断。与 049 的区别是**两手同相位**（一起拍、一起滑），不再交替。
- **详情**：

  ### 教程说明（转述）
  - `[04:50]`「**打完星星等一拍，接下来只需要双压然后滑滑滑滑滑滑滑，能写得费体力也能写得很蹭**」。
  - 教程谱例八首：乙女解剖 12.5 BPM134、（缺名）13.0 BPM184、**猫祭り 13.4 BPM160**、Knight Rider 13.8 BPM200、Halfway(><) 13.8 BPM175、Cosmic Magic Shooter 13.9 BPM163、Reach For The Stars 13.9 BPM203、**FFT 14.0 BPM180**。

  ### 谱例
  **定位成功**：`resource/official-chart/431-猫祭り-mas.txt`，**m034–m037**（`{4}` @160BPM；教程 示例三 定数 13.4 / MASTER / BPM160 与 manifest 三项全对）：

  ```
  m034| 4-2[8:1]/5-1[8:1],4-8[8:1]/5-7[8:1],4-2[8:1]/5-1[8:1],4b-8[8:1]/5b-7[8:1],
  m035| 4-2[8:1]/5-1[8:1],4/5,3b/8b,4b-2[8:1]/5b-1[8:1],
  ```
  同曲 **m076–m079** 是把直星换成弧星（`4^2/5p1`、`4q8/5^7`）的同骨架变体。
  另一处 ST 实证：`503-FFT-mas.txt` **m078–m079**（`…1-3[8:1]/5-7[8:1],,1-6[8:1]/5-2[8:1],` ＋ `,1-5[8:1]/5-1[8:1],,15,,3b/7b,`），双押键固定在 **1/5**、每次向不同方向放射，最后以 `15` 双押收尾。

  ### agent 理解
  - **手级定义**：两手各守一个键（猫祭り＝4 与 5，FFT＝1 与 5），**每个四分音同时按下**。这一次按压身兼二职：既是**新一对星星的头**，又是**上一对星星的启动拍**（因为键位没变）。所以打完立刻两手同时向外划，划完回到原键再按。
    - **拍星星头的手**：两只手（同刻）；
    - **划轨的手**：两只手（同刻，各划自己那条）；
    - **另一只手在做什么**：没有"另一只手"——**双手同相位**，这是它与 049 最本质的差别；
    - **换手时机**：**不换手**。手序是固定的，难度全部转移到"体力 + 防蹭"上。
  - **教程那句"能写得费体力也能写得很蹭"的拆解（agent 推断，存疑）**：
    - **费体力档**＝放射跨度大（`4-8`/`5-7` 要划过半个屏幕）、BPM 高 → 双臂每拍一次大幅往返，是纯耐力；
    - **很蹭档**＝放射终点或轨道压在**自己那对键附近**（`4-2`/`5-1` 的轨道要贴着按键圈走），下一拍手要回到 4/5 按键，**回程必然经过刚划过的判定区** → 010 外键无理 / 011 撞尾的高发区。
  - **写谱时的红线**：固定键对意味着**同键位的重复按压**，节奏是四分音 → 由 009 的 42 ms 下限换算，BPM 上限极宽松（BPM 203 的四分 ＝ 295 ms），**所以这个配置不会撞叠键红线，真正的上限是 030 的"侧边双押"铁律**——键对一旦取 {2,3} 或 {6,7} 这类同侧相邻，就是禁写形态。教程谱例的键对全是 **{4,5}（底部左右）或 {1,5}（对角）**，正好绕开侧边。
  - **和 049 的分界判据（可机检）**：同一格内的星星头数量——1 个＝049（两手异相位交替），2 个＝050（两手同相位）。
  - **和 030 连续双押的关系**：本条是"**双押的每一下都带星星**"的特例；030 的铁律（禁 23/67 侧边双押）在这里同样适用。
- **理由**：手序模型由猫祭り/FFT 谱面逐格核对得出（键位固定、头与启动拍同键）；"费体力/很蹭"两档是 agent 对教程一句话的拆解。

# 104 — 绝赞（break）是**单个标重音**，不是成对堆双押

> ⚠️ **本条为 agent 观察，未经用户确认。** 来源：同曲官谱抄谱对照（note 069）。n=1。

- **日期**：2026-09-20
- **要点**：参考谱 **61 个 break 散在 33 个小节**里，多数是**单个**跟着一个重音走
  （`2b`、`1b`、`6b`、`4b`），成对只用在**段落收口**（`4b/8b`、`3b/6b`、`2b/6b`）。
  我们 **24 个 break 挤在 11 个小节**里，**全部是成对的 `1b/8b` 或 `4b/5b`**——
  绝赞被我们当成了"重要双押"的装饰，不是重音标记。
- **详情**：

  | | 参考谱 | 我们 |
  |---|---:|---:|
  | break 个数 | 61 | 24 |
  | 落在多少个小节 | 33 | 11 |
  | 段落分布 | A 段 8 / B 段 5 / drop1 17 / drop2 25 / 其余零星 | A 段 4 / drop1 8 / drop2 6 / 起跑 2 / 尾奏 2 / 留白 2 |
  | **单个** break 的时间槽 | **25** | **0** |
  | **成对/多个** break 的时间槽 | 18 | 12 |

  两种被我们漏掉的用法：
  1. **整小节只放绝赞当报点**：`{1}3b/6b,`（最终 drop 前两小节，一对）、
     `{8},,1b,,,,,8b,`（build 里一小节只有两个**各自独立**的绝赞，前后全空）；
  2. **一串细分音里每隔几个放一个绝赞做重音**：尾杀的 `2b,3,4,5,8b,7,6,5,1b,2,3,4,5b`。

- **理由**：绝赞在判定上是"更严的 tap"（知识 016 年表：GreeN PLUS 起有分数增益），
  它的谱面语义是**这一下比周围重**。写成固定的顶/底双押，等于把"重音"变成了"章节标题"。
- **来源**：`docs/research/test-01-vs-reference.md` §2.3 / §2.6 / §2.11 / §3.3；
  同曲官谱抄谱对照（note 069）。
- **置信度**：**经验**（个数与落点为直接计数）/ **存疑**（n=1；"跟着重音"没有听审，
  只有 `song_analysis.json` 的候选池旁证）
- **关联**：**016**（ST 要素年表：BREAK）、**089**（舍音时留重音）、**095**（密度分布）、
  **097**（双押键对）、**101**（尾杀里的绝赞节奏）。

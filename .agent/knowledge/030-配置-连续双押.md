## 补充（2026-09-19，用户讲授：「突然」与「引导」的定义）

本条目铁律里的「**突然**」与「**充分引导**」，用户 2026-09-19 给出了定义与例子。**原话（逐字）**：

> 「突然指的是与谱面临近位置位移较大，或者是与上一个配置间隔过小等情况，这都会造成"突然出现"的侧边双押从而无法反应过来要去接，反之如果做好引导，比如像你之前说的双押带过来，或者18/87/76/65/54这样有引导意味，或者18/23/45/67这样有引导意味的是可以写的。」

**「突然」= 两种情形（用户明列）**

| # | 情形 | 后果（用户原话） |
|---|---|---|
| ① | **与谱面临近位置位移较大** | 造成「突然出现」的侧边双押，**无法反应过来要去接** |
| ② | **与上一个配置间隔过小** | 同上 |

**「引导」= 三个例子（用户明列）**

| # | 例子 | 用户原话中的定性 |
|---|---|---|
| A | **双押带过来** | 「像你之前说的双押带过来」 |
| B | **18/87/76/65/54** | 「这样有引导意味」 |
| C | **18/23/45/67** | 「这样有引导意味」 |

**主会话解读（形态；待用户确认）**

- **B 型** `1/8 → 8/7 → 7/6 → 6/5 → 5/4`：**相邻两组共享一个键，另一个键沿环逐格推进**——与本条目「类型与实例」表里 DRAGOON 的绕圈串同构。注意 **7/6 这一组本身就是侧边双押 67**，它因为被前后的 8/7、6/5 带着走而成立。
- **C 型** `1/8 → 2/3 → 4/5 → 6/7`：**每组都是一对相邻键，四组沿环等距轮转**（顶 → 右 → 底 → 左）；其中 **2/3 与 6/7 两组都是侧边双押**，同样因规则轮转而成立。
- 因此本条目铁律在用户此次讲授下读作「**禁止突然的**侧边双押」，而不是「禁止侧边双押」——**侧边双押本身不是禁区，「突然」才是**。
- **两条用户原话的交叉推论（agent 解读，待用户确认）**：按知识 **064** 的舒适区（共享 1/4/5/8、左手专属 6/7、右手专属 2/3），双押 `2/3` 必然有一只手落进 {2,3}、`6/7` 必然有一只手落进 {6,7}——**侧边双押恰好就是「必定产生出张」的那两组相邻双押**（1/8、4/5 两键都在共享区；1/2、3/4 等各有一键在共享区）。这可以解释为什么只有 23/67 被立成铁律。

# 082 — 侧边双押的引导形态：官谱有八种把手带过去的写法，按乐句看没有"真突然"

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：388 个官方 ST 谱（MASTER / Re:MASTER，定数 13.0–14.5），侧边双押 = 同刻两手的键集恰为 `{2,3}` 或 `{6,7}`（手序版判定，`hands.py` v0.4 分配器）。八型全部是**结构关系**（共享键 / 相邻键 / 同一对 / 镜像对 / slide 终点 / 被长条压住），**没有任何数值门槛、不分档**。

- **日期**：2026-09-20
- **要点**：官谱里的侧边双押**从来不是凭空出现的**——总有一种形状先把手放到旁边。用户讲过的三型是主力，但**不是全部**：官谱另有五种常用写法。把八型放进**乐句**这个阅读单位去看，**388 官谱里没有一次"真突然"的侧边双押**。
- **详情**：

  1. **用户讲过的三型**（知识 030 的 2026-09-19 补充 + 原表）：
     - **A/B 共享键步进**：与前面那一组双押**共享一个键**（「双押带过来」/ `18·87·76·65·54`）；
     - **C 等距轮转**：前后几组都是**相邻两键**的双押、锚沿环**等距轮转**（`18·23·45·67`）；
     - **D 同键已在手下**：临近位置**已经落在这两个键之一上**（知识 030 原表的「单点铺垫 → 双押串」，`846-+♂`）。
  2. **官谱还常用另外五型**（**agent 归纳，存疑**——用户没讲过这五个）：
     - **G 同对回访**：这一对**刚打过**，第二次出现时手是"回来"而不是"过去"；
     - **H 星星或长条把落点送过来**：前面有一条 slide 的**终点**落在这对键上，或这对键**被 hold 压过**——这是官谱**唯一**能把手从远处合法带到侧边对的办法；
     - **F1 镜像对带过来**：`2/3` 与 `6/7` 互为镜像，官谱最爱**先写一边、再写另一边**，玩家第一次就学会了这个形状；
     - **F2 同型相邻对带过来**：前面已经在打「相邻两键双押」这个**手型**（`4/5`、`7/8`、`1/2`…），侧边对只是换了个位置，手型不变；
     - **E 相邻键铺垫**：前面没有双押、没有星星送手，但**手就在隔壁键上**（环距 1）。
  3. **★「位移较大」这件事官谱基本不写**：**E 型在 685 次里命中 674 次**——事件前几拍内几乎总有一个与该对紧挨着的键。**官谱几乎从不把手从远处直接甩到侧边对上**。这正是用户说的「突然 = 位移大」在官谱上的反面证据。
  4. **越密的地方引导反而越足**：贴得最紧的那些（距上一组不到四分之一拍）**无一例外都有引导**——最极端的一处是共享键步进，另一串是「同键反复之后直接把两键合成双押」。**"间隔小"不构成独立的"突然"**。
  5. **同刻不可能有第三只手被占**：侧边双押本身就把两只手同时占满，任何长条/星星只能在它之前结束或之后开始。**所以引导只能来自前面**——"用长条钉住一只手逼出侧边双押"这条路在官谱里**根本不存在**。
  6. **要按"乐句"看，不要只看紧邻几拍**：官谱的引导常常**跨小节**。典型是一小节一个的固定细胞（`单点 → 双押 → 双押 → 三连单点`，双押只在 `18 / 45 / 23 / 67` 四个相邻对里轮换）——玩家打完第一小节就认得这个格子了，第二小节的侧边双押在紧邻几拍里看着"突然"，在乐句里一点也不突然。
  7. **这八型是"复核清单"不是判决**（沿用知识 080 第 3 条的态度）：覆盖率高**只说明官谱总能找到一种形状把手带过去**，不说明这八型就是玩家实际依赖的东西，更不说明"写了就一定坏"。

  **证据注脚**（口径 = `hands.py` v0.4，388 谱 685 次）：主形态 A/B 192 · D 141 · C 117 · H 64 · E 60 · F2 54 · F1 47 · G 9 · 判不出 1；**任一命中** E 674（98.4%）· F2 413 · D 348 · H 209 · A/B 192 · C 180 · F1 174 · G 74。用户三型主形态合计 450（65.7%）。按阅读窗口：紧邻几拍判出 677、放宽到乐句再判出 7、**仍判不出 1**——而那 1 次是 `37-千本桜-mas` 的**全谱第一组 note**（前面什么都没有，窗口为空）。旧的四型判据曾有 **307 次**判不出，那是归纳漏了形态，**不是官谱写了 307 次违例**。临近最小环距分布 0/1/2/3，**全库一次 4（对角）都没有**。

- **理由**：知识 030 的铁律是用户讲授的硬规则，但"引导"一侧只给了三个例子；知识 080 当时的结论是"agent 仍有近一半判不出引导，只能作复核清单"。本条把那个缺口补上——回到官方谱逐条看那 307 次到底靠什么成立，归纳出五种用户没讲过的形状，并给出"要按乐句看"这个阅读单位。**补的是归纳，不是规则**。

# 025 — 配置：散点

- **日期**：2026-09-10
- **要点**：散点 = **无特定表现形式**，通常指**排键上比较分散、或不容易看出规律的单点配置**（写法上无硬性结构约束）。
- **详情**：
  - **定义**：无特定表现形式；特征是"排键分散 / 规律难辨"。
  - **特征（据 GIGANTØMAKHIA 引文实测）**：
    - **用键范围**：跨全部 8 个键，**不收敛于固定的小键位集合**（L1 频次 3:5、4:5、5:5、6:4、7:3、2:3、8:3、1:2）；
    - **步进混合**：±1/±2/±3/−4 都有，**无统一方向、无固定对位关系**；
    - **不满足任何已讲配置的几何条件**：楼梯（只 ±1 且同向）、方向盘（严格 180° 对位）、大宇宙（4 键两对）都不适用——这正是"看不出规律"的量化体现；
    - **音符形态**：全为单点（无星星/长条），可零散带绝赞（`2b`/`3b`/`1b`/`7b`/`4b`/`6b`）。
  - **难度来源**：偏向**读谱与预判**（无法用固定手型套路化处理），而非单一手速或位移。
  - **实例**：**GIGANTØMAKHIA**（**DX 谱**，id 763，190BPM，MASTER 14.7，本地无谱）：
    - `{16} 2b/8b,,3,7,4,6,3,5,2b,8,4,6,3b,5,1b,8,4,6,3,5,2,7,4,5,2b,1,3,7b,8,6,4b,5,`
    - `2,6,1,8,3,7,5,6,3b,4,1,6b,5,8,1b,7,2,6,3b,5,4,7b,1,5,2b,8,4,6b,1,5,2b,4,`
    - 两行是相似写法的变体；开头 `2b/8b,,`（双押 + 休止）起手；190BPM `{16}` ≈ 12.7 键/秒。
- **理由**：散点没有固定手型规律，**无硬性结构约束**；其难度来自读谱与预判。
- **来源**：用户谱师讲授（2026-09-10 会话）；实例引文（GIGANTØMAKHIA 为 DX 谱且定数 14.7 超本项目抓取范围，本地无谱）。
- **置信度**：确信
- **关联**：知识 018（普通交互）、021（轴交互）、022（楼梯交互）、023（逆楼梯/方向盘）、024（大宇宙）——散点不满足以上任一配置的几何条件。

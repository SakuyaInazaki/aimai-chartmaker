# 001 — 谱面强度应贴合歌曲情绪走势

- **日期**：2026-09-10
- **要点**：谱面强度（note 密度与配置复杂度）必须随歌曲情绪起伏而变化，不能全程匀速、平铺直叙。
- **详情**：
  - 大多数歌曲的情绪呈"弱 → 较强 → 较弱 → 强 → 渐弱淡出"的走势，谱面强度也应遵循这一模式。
  - 强度表达手段：分音密度（{8}→{16}→{32}）、note 种类、位移、配置复杂度等（见条目 003）。
  - 段落意识：先按歌曲划分段落（前奏/主歌/build/副歌/间奏/尾声），再为每段定强度基调。
  - **量化模板候选**（管线参数，待标定）：T=[0.20, 0.45, 0.30, 1.00, 0.10] 对应"弱→较强→较弱→强→渐弱"，用于强度曲线 DTW 匹配（`docs/audio-analysis.md` §4；置信度存疑，需在目标曲库标定）。
- **理由**：情绪贴合是自制谱合理性的第一要求；在几乎所有自制谱环境中，谱面强度都应与歌曲情绪完全贴合。
- **来源**：MMFC《谱面创作基础学 长篇指南》5.2 强度理论；小小红白 B 站制谱教学合集（space.bilibili.com/397702，合集 sid=391415）。
- **置信度**：确信（社区共识）

# 001 — 谱面强度应贴合歌曲情绪走势

- **日期**：2026-09-10
- **要点**：谱面强度（note 密度与配置复杂度）必须随歌曲情绪起伏而变化，不能全程匀速、平铺直叙。
- **详情**：
  - 大多数歌曲的情绪呈"弱 → 较强 → 较弱 → 强 → 渐弱淡出"的走势，谱面强度也应遵循这一模式（MMFC 5.2 原文，说的是**歌曲情绪**）。
  - **结尾形态（用户谱师讲授，2026-09-11）**：「曲子结尾一般会有**尾杀**，当然**渐弱淡出**也是有的，这两个都有。」——即谱面收尾有两种形态并存：**尾杀**（末段强杀，通常是全曲最强）为常态，**渐弱淡出**也存在；写谱时按曲子实际结尾判断，不能默认"末段必渐弱"。
    - 官方谱实测佐证（知识 031）：388 谱中曲末 10% 密度高于全曲均值的约占 2/3（尾杀型为主）、低于的约 1/3（含渐弱型）；末段是结构对齐五段中最强的一段（s5 = 0.817），24.2% 的谱把高潮段放在最后 10%。
    - 前四段"弱 → 较强 → 较弱 → 强"的顺序被 388 谱完整验证。
  - 强度表达手段：分音密度（{8}→{16}→{32}）、note 种类、位移、配置复杂度等（见条目 003）。
  - 段落意识：先按歌曲划分段落（前奏/主歌/build/副歌/间奏/尾声），再为每段定强度基调。
  - **量化模板**：拆为两个量，**不可混用**（详见下方修订记录与知识 031）——
    - `T_audio`（**音频强度**曲线的形状先验）：**仍待标定**，需真实音频分析数据；原 T=[0.20, 0.45, 0.30, 1.00, 0.10] 只能作为定性描述的占位值。
    - `T_density`（**谱面密度**的形状先验）：**已由 388 个官方 ST 谱标定** = [0.62, 0.77, 0.72, 0.78, 0.82]（结构对齐五段口径），并须配合"密度地板"非线性使用。→ **见知识 031**。
  - **强度提升 ≠ 密度提升**：密度只是强度的一个维度。官方谱后半程副歌相对前半程的密度提升中位只有约 12%（SPICY SWINGY STYLE 仅 +5.1%），更大的强度差异由**配置复杂度**承担（见知识 003 的四大因素、知识 031）。
- **理由**：情绪贴合是自制谱合理性的第一要求；在几乎所有自制谱环境中，谱面强度都应与歌曲情绪完全贴合。
- **来源**：MMFC《谱面创作基础学 长篇指南》5.2 强度理论；小小红白 B 站制谱教学合集（space.bilibili.com/397702，合集 sid=391415）；结尾形态（尾杀/渐弱并存）为用户谱师讲授（2026-09-11）；实测数字见知识 031。
- **置信度**：确信（社区共识 + 用户谱师讲授 + 官方谱实测）；`T_audio` 待标定。
- **关联**：条目 002、003、**031**（官方谱密度曲线实测规律）；`docs/audio-analysis.md` §4.7；AGENT.md 验收标准第 4 条"情感循序渐进"。

## 修订记录

- **2026-09-11**：依据 388 个官方 ST 谱的逐小节密度实测（`docs/research/official-chart-density-curves.md`，已入库为知识 031）做三处修订：
  1. **量化模板 T 拆为 `T_audio` 与 `T_density`**。原条目把 T 同时描述为"歌曲**情绪**走势"又写成"用于**强度曲线** DTW 匹配"的参数，但本次测的是**谱面密度**、不是音频强度，两者必须分开：
     - `T_audio` = 音频强度形状先验，**仍待标定**；
     - `T_density` = 谱面密度形状先验，**已标定** = `[0.62, 0.77, 0.72, 0.78, 0.82]`（结构对齐五段，95% CI 见知识 031；等分五段口径为 `[0.81, 0.92, 0.91, 0.97, 1.00]`，两口径不可混用）。
     原 T=[0.20, 0.45, 0.30, 1.00, 0.10] 的**幅度被实测证明高估约 4.5 倍**（真实段间落差只有 0.62–0.82），**不再作为密度目标使用**——直接拿它驱动生成会给出官方谱里根本不存在的"空段"。另需补上"密度地板"非线性：`density_norm = floor + (1−floor)·intensity_norm`，段落尺度 floor ≈ 0.60、小节尺度 floor ≈ 0.25。
  2. **"渐弱淡出"一环与官方谱密度实测矛盾**（实测末段最强：s5 = 0.817 为五段最高、曲末 10% 密度 = 1.084 × 全曲均值、24.2% 的谱高潮段在最后 10%）。但该句出自**用户讲授的 MMFC 5.2**，按 AGENT.md 工作准则 9「用户讲授内容即边界」**不得擅自改写**，因此本次**只在正文标注"存疑，待用户确认"并指向知识 031，保留原文不删**。前四段"弱 → 较强 → 较弱 → 强"的顺序已被 388 谱完整验证。
  3. **补充"强度提升 ≠ 密度提升"**：密度只是强度的一个维度，更大的强度差异由配置复杂度承担（见知识 003/031）。
  - 另需注意（知识 031 §9）：40.7% 的官方谱属"全程高密平台型"，密度曲线几乎不动、靠配置制造强度变化 → 本条目"不能全程匀速"的原则仍成立，但**密度起伏不是唯一手段**。
- **2026-09-11（第二次）**：主会话追溯确认——"渐弱淡出"一句**出自 MMFC 5.2 原文（转述小小红白 2021 年视频结论），并非用户讲授**，此前按准则 9 保留并标存疑属于误判。随后用户讲授：「曲子结尾一般会有尾杀，当然渐弱淡出也是有的，这两个都有」。据此**解除存疑**，把结尾形态改写为"尾杀为常态、渐弱淡出并存、按曲子实际结尾判断"，并注明 MMFC 原句描述的是歌曲情绪而非谱面密度；官方谱实测比例引自知识 031。

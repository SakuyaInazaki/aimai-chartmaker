# 070 — 提高定数靠密度与细分音，跟着情绪走靠 note 种类

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：388 个官方 ST 谱（定数 13.0–14.5）的全谱统计 + 160 首配对曲包的曲内段落统计。**用户已撤回 agent 自造的 `(D+H)/2` 内在难度排序与三张配置清单**（2026-09-19「谁让你这么排的」），本条**不复活那套合成分**，只保留两条方向。

- **日期**：2026-09-20
- **要点**：官方谱把"**这张谱有多高定数**"和"**这一段在曲子里有多重**"当成**两个分开拧的旋钮**：
  **定数往上走靠的是密度与更细的分音**；**跟着音乐情绪走靠的是 note 种类**（双押系、错位）。
  最直接的证据是——**定数越高，each（多押）与 slide 的占比反而越低**。
- **详情**：

  1. **升定数 = 加密度 + 加细分音**：同一 BPM 档内定数每升一档，每小节 note 数与 16 分音占比大幅上升；而 **each 占比与 slide 占比是下降的**。所以"加多押、加星星"不是升定数的手段。
  2. **跟情绪走 = 换 note 种类**：曲内强度高的段落富集的是**双押系与错位**（单双/双单、连续双押、双押纵、错位），强度低的段落富集的是匀拍单点与纵连族。几何配置在"定数"这条轴上很强，在"曲内强度"这条轴上几乎不挑位置。
  3. **两条轴基本正交**：一类配置"该出现在多高定数的谱里"与"该放在曲内多强的位置"之间几乎没有相关。**所以不能用一个分数同时回答这两个问题**——这也是用户撤回合成分排序的原因。
  4. **对写谱的含义**：定数不够就加密度与细分音（几何配置、16 分以上），**不要靠堆多押和星星**；某一段要更重就换 note 种类（把单点写成双押、给星星加错位），**不要靠把这一段写得更密**（知识 031「强度 ≠ 密度」）。

  **证据注脚**：388 谱同 BPM 档内定数升档 each 59%→49%、slide 15%→11%，NPS 5.26→7.79、{16} 分音占比 9%→52%；配置级秩相关（n=17 类）密度 vs 平均定数 ρ=+0.80、vs 高强度富集 ρ=−0.03，note 种类/位移/无理 vs 平均定数 ρ=−0.15、vs 高强度富集 ρ=+0.58；曲内高强度富集前列 方向盘 1.41 / 侧边双押 1.26 / 单双双单 1.25 / 轴 1.25 / 错位 1.23。

- **理由**：388 谱的 each/slide 占比随定数下降，是**不依赖任何 agent 评分**的谱面事实；两条轴的正交则由配置级秩相关给出（该相关用的 D/H 两个分项仍是 agent 操作化，只作解释变量）。
- **来源**：`docs/research/chart-config-matrix.md` §5.1；`docs/research/config-difficulty-intensity.md` §2.3、§2.4。
- **置信度**：**经验（agent 观察，n=388 谱 / 32 840 小节 + 160 首，未经用户确认）** / **存疑**（① 秩相关建立在 agent 定义的两个分项上，只能当解释变量；② 平均定数与"密"之间存在同义反复，真正非平凡的是"note 种类多的配置并不更常出现在高定数谱里"；③ 配置识别的这一轮统计为键位版，手序版重跑后符号一致但数值会动）。

# 032 — 官方谱踩音归因实测（官方 note 落在哪条 stem 上）

- **日期**：2026-09-11
- **要点**：8 首官方 ST MASTER 谱与其官方音频配对实测——**官方谱的踩音形态是「鼓骨架 + 大量非鼓填充 + 约两成自由发挥」**：
  drums 命中率 0.607（各 stem 最高，lift 2.64），但 **36.2% 的 note 不落在鼓上**、**18.6% 什么 stem 都不落**；
  逐段"最高命中轨"85 段里 **70 段是 drums** —— **"永远答 drums"这个常数基线（82.4%）打败了按段落类型切轨的规则表（64.7%）**。
- **详情**：

  ### 1. 判据（**代理，不是事实**，引用时必须连判据一起引）

  ```
  官方 note 按时间去重成「时间槽」（同刻 each/双押算一个踩音事件）
  对每个时间槽，看 ±30 ms 内是否有 drums / bass / other / vocals 的 onset（量化前的原始秒数）
  recall     = 该 stem 能解释的官方时间槽比例
  precision  = 该 stem 的 onset 中被官方采用的比例
  chance     = 同数量 onset 均匀撒开的期望命中率 1 − exp(−λ·2τ)；lift = recall / chance
  ```

  ⚠️ **必须看 lift**：鼓轨 onset 天然最多（479–631 个 vs 人声 61–333 个），只比 recall 的话鼓永远赢。

  ### 2. 全曲层面（按时间槽数加权，8 曲汇总）

  | stem | recall | precision | 随机基线 | **lift** |
  |---|---:|---:|---:|---:|
  | `drums` | **0.607** | **0.670** | 0.232 | **2.64** |
  | `other` | 0.273 | 0.610 | 0.132 | 2.29 |
  | `bass` | 0.202 | 0.519 | 0.107 | 1.89 |
  | `vocals` | 0.167 | 0.539 | 0.080 | 1.94 |

  **归因分布（8 曲均值）**：至少被一条 stem 解释 **81.4%**；**什么都不落 18.6%**；
  落在 drums 上（含重合）63.8%；落在 vocals 上（含重合）17.4%；
  **只落 drums 28.1%**、**只落 vocals 3.2%**、同时落 drums 与 vocals 12.7%、**不落 drums 36.2%**。

  ### 3. 逐段落类型（recall / 关键 lift）

  | 段落类型 | 段数 | recall(drums) | recall(vocals) | prec(vocals) | 该类型最高 lift |
  |---|---:|---:|---:|---:|---|
  | `chorus` | 14 | 0.583 | 0.200 | 0.542 | drums 2.51 |
  | `verse` | 17 | 0.572 | 0.171 | 0.564 | **other 3.49** |
  | `interlude` | 19 | 0.574 | 0.137 | **0.715** | **vocals 3.18** |
  | `quiet_chorus` | 13 | 0.630 | 0.163 | 0.606 | **vocals 2.94** |
  | `final_chorus` | 4 | 0.678 | **0.065** | 0.294 | drums 2.52 |
  | `pre_chorus` | 8 | 0.549 | 0.190 | 0.429 | bass 3.28 / other 3.27 |
  | `intro` | 8 | 0.657 | 0.234 | 0.292 | **other 5.08** |

  - **间奏的人声 precision 0.715 / lift 3.18 是全表最亮的一条**：间奏里人声 onset 少，但一出现就几乎必被采用（支持知识 002 的"间奏踩人声采样"）。
  - **`final_chorus` 的 vocals lift 0.97 = 随机水平**：大副歌反而最不踩人声。
  - **intro 的最高 lift 是 `other` 而不是 drums** → "前奏哪个响踩哪个"的**能量判据选错了轨**。

  ### 4. 候选池有效率（支撑知识 005）

  管线量化落格后的候选池（平均 828 格/曲）：**recall 0.821 / precision 0.546**；
  逐曲 precision 0.234（最稀的谱）–0.695（最密的谱）→ **官方谱只从候选里挑走约一半**。

  ### 5. 与规则表的一致率（85 段）

  | 口径 | `stemplan.py` v0.2 规则表 | **常数基线（永远答 drums）** |
  |---|---:|---:|
  | 命中率最高轨 top-1 | **64.7%** | **82.4%** |
  | 命中率前二 top-2 | 81.2% | — |
  | lift 最高轨 top-1 | 32.9% | 38.8% |

  主要错配：`hook`(other) 建议 → 实测 drums（11 段）、**`vocal` 建议 → 实测 drums（9 段）**、
  bass 建议 → drums（4 段）、drum 建议 → other（3 段）。
  → **单值"主踩音轨"模型被证伪**，`tools/audio_analysis/stemplan.py` 已改为
  **骨架轨（默认 drums）+ 点缀轨 + 估计占比 + 依据**。

  ### 6. 人声侧的天花板（为什么 C1 只能"存疑"）

  逐曲"人声 onset 数 / 官方时间槽数"给出人声 recall 的上限：MYTHOS 0.104（器乐曲，低是正确的）、
  Xevel 0.179、麒麟 0.183、Signature 0.245、激唱 0.273、Mare Maris 0.440、幻想 0.616、Back 2 Back 1.089。
  **Back 2 Back（天花板 1.089，实测 0.221）与 幻想（0.616 / 0.331）说明：即使人声 onset 充足，
  官方 note 也没有主要踩在人声上。** 但反过来，人声 onset 检测本身不可靠，
  **这不是"谱师不踩人声"的证明**。

- **理由**：这是本项目**唯一一份同时握有官方音频与官方谱的配对证据**。
  复现实现：`tools/calibration/stemhit.py`（切轨匹配与 lift）+ `chartpair.py`；
  谱面侧解析 8/8 零错且 note 总数与 `resource/official-chart/` 转录版完全一致（两条数据来源互证）。
- **来源**：`docs/research/audio-chart-calibration.md` §5（2026-09-11，agent 实测报告）；
  音频来自用户提供的 8 首官方 ST 曲包（`official-mp3/`，**不入库**）。
- **置信度**：**存疑 / 经验**。三条硬限制：
  1. **n = 8**，分布不均（2 首偏器乐、1 首变速、BPM 128–230、定数只覆盖 13.5–14.5）；
  2. **ground truth 是代理**（"note 是否落在某 stem 的 librosa onset ±30 ms 内"），
     而 Demucs vocals 轨混 lead synth、鼓件分解是频带启发式 —— **人声侧结论尤其需要人工听审
     或 basic-pitch / RMVPE 拿到真正的人声 note 事件后复验**；
  3. **鼓与人声重合的 12.7% 无法区分归属**，且 18.6% 的残差里混着"谱师自由发挥"与"onset 漏检"，本实测无法分离二者。
  → 这些数字可以用来**设计规则与排先后**，**不得当作硬约束或验收判据**。

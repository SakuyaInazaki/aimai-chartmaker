# 090 — 星星族的段落用法：イントロ 最不写星星、落ちサビ 最爱写；"减压段"其实不减压

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：160 首带段落标签的配对语料（13 535 小节），
> 段落标签来自音频分析管线（三路投票 + 日式词表，**未经人工听审**），配置识别为
> `tools/chart_analysis/configs_hand.py`（手序版，AGENT.md 准则 12）。
> 星星族取知识 **049–063 系列 + 017 错位 + 033 死镰段** 共 16 个配置名。
> lift = 该配置在该段落的小节出现率 ÷ 它在全语料的出现率。**数字只作注脚。**

- **日期**：2026-09-20
- **要点**：知识 **074** 说了"谁住哪个段落"，但它把星星族只写了两句（サビ「接得顺的星星」、
  Bメロ「要分手的星星」、落ちサビ「绕圈星星/穿心」）。本条按段落把星星族摊开，结论有三条：
  1. **イントロ 是全表最不写星星的段落**——16 个星星配置里 14 个 lift < 1，整段"星星族一次都没命中"的比例最高；
  2. **落ちサビ / ラスサビ 才是星星族的主场**，サビ 次之；**間奏 略低于基线**（它是几何配置的地盘，与 074 一致）；
  3. **★ 管线标的"减压段"（`落ちサビ` + `rest=True`）在官谱里根本不减压**——
     密度与全曲均值持平，**星星反而比全曲多**。`rest` 这个字段**不能当"该写低密度"的证据**。
- **详情**：

  1. **イントロ 的星星族 lift 普遍在 0.4–0.6**：连续拍滑 0.42、绕圈星星 0.46、一笔画 0.48、
     三叉戟 0.51、CYCLES 型 0.54、挥手段 0.54、错位 0.55、鼓动段 0.65、拆弹 0.65；
     只有 夹键拍滑 0.98 与 井字星星 0.91 贴基线。整段口径下
     **イントロ 只有 12% 的小节命中任一星星族**（全曲 23%），**38% 的小节有星星**（全曲 54%）。
     ⇒ 与知识 **074**「イントロ 归纵连族」方向一致，本条给出它的反面证据：**前奏不是靠星星做的**。
     ⚠️ 但"归纵连族"是 lift 语句：**只有 33% 的曲子在前奏里真的写了纵连族**（见 **092**）。
  2. **落ちサビ 的星星族 lift 全面 >1**：双压连续拍滑 1.93、穿心 1.78、绕圈星星 1.68、
     连续拍滑 1.40、一笔画 1.38、井字星星 1.33、鼓动段 1.21、三叉戟 1.14。
     **ラスサビ** 更集中在 错位 1.68 / 连续拍滑 1.62 / 鼓动段 1.51 / 绕圈星星 1.49 / 一笔画 1.43。
     ⇒ 074 的「落ちサビ：绕圈星星 / 穿心」成立且可以扩写成**整个星星族**。
  3. **サビ**：挥手段 1.39、夹键拍滑 1.34、井字星星 1.32、一笔画 1.31、CYCLES 1.25、连续拍滑 1.24、穿心 1.19
     ——与 074「接得顺的星星」一致，但**井字星星与挥手段也在里面**，074 没写。
  4. **間奏**：一笔画 0.63、绕圈星星 0.72、井字星星 0.80、穿心 0.88、鼓动段 0.90、连续拍滑 0.96 都在基线以下，
     只有 三叉戟 1.23 / 错位 1.10 略高。⇒ **間奏 不是星星段**（与 074「几何配置集中地」一致）。
  5. **Bメロ**：样本小（360 小节），CYCLES 1.93、鼓动段 2.11、三叉戟 1.41 偏高，与 074「要分手的星星」一致；
     死镰段 6.71 只有 5 个小节，**不作依据**。
  6. **★ 减压段实况**（每小节 note 数，160 首）：

     | | 小节数 | note/小节 | 相对本曲均值（中位） | 滑轨/小节 | 有星星的小节 |
     |---|---:|---:|---:|---:|---:|
     | 全曲 | 13 535 | 8.57 | 1.000 | 1.18 | 54% |
     | **落ちサビ** | 1 782 | **8.49** | **0.997** | **1.41** | **63%** |
     | **`rest=True`** | 2 030 | **8.35** | **0.995** | **1.36** | **61%** |
     | サビ | 2 225 | 8.80 | 1.080 | 1.49 | 65% |
     | **イントロ** | 1 488 | **6.99** | **0.785** | **0.71** | **38%** |
     | 間奏 | 3 001 | 8.86 | 0.994 | 1.00 | 49% |

     **落ちサビ 的密度 ≥ 本曲均值的曲子占 49%**——掷硬币。
     而且 `rest=True` 的 2 030 个小节里 **1 782 个就是 落ちサビ**（其余 間奏 152、Aメロ 96），
     所以 `rest` 这个布尔字段**基本等价于"这一段被标成了落ちサビ"**，它**不携带密度信息**。
     **真正密度低的段落是 イントロ（0.785）**，不是落ちサビ。
  7. **★ `rest` 字段的正确读法**（对 `tools/audio_analysis` 的 `Segment.rest` 与 song sheet §1）：
     读作「**这一段在结构上是"最后一次副歌之前的那次副歌"**」，**不读作「这一段要写得稀」**。
     密度仍按定数 → NPS 锚（知识 031 §7）与段与段的相对高低走。
     ⚠️ 本条**只改读法，不改管线行为**。
  8. **落ちサビ / rest 段最常写的配置**（小节命中率）：连续双押 19% / 子弹 14% / 连续拍滑 12% /
     单双双单 10% / 一笔画 10% / 跳拍 10% / 绕圈星星 7% / 错位 5% / 出张 4%
     ——**主料仍是知识 073 的那三件（子弹 / 连续双押 / 跳拍）**，星星族是在它们之上加的一层。

  **证据注脚**：星星族全语料出现率 连续拍滑 8.6% / 一笔画 7.5% / 错位 5.2% / 绕圈星星 4.0% /
  井字星星 3.0% / 鼓动段 2.4% / 夹键拍滑 1.7% / 三叉戟 1.6% / CYCLES 0.9% / 挥手段 0.9% /
  穿心 0.6% / 同起点拍滑 0.5% / 双压连续拍滑 0.4% / 拆弹 0.3% / 死镰段 0.2% / 大风车 0.1%。
  段落小节数：間奏 3 001 / Aメロ 3 266 / サビ 2 225 / 落ちサビ 1 782 / イントロ 1 488 /
  ドロップ 784 / ラスサビ 560 / Bメロ 360 / アウトロ 51。

- **谱例**：
  - **落ちサビ 不减压的极端**：`Night Fly` MASTER（13.2）bars 35–44 —— 相对密度 **1.48**、
    每小节 **2.40** 条滑轨、**70%** 的小节命中星星族；
    `東方スイーツ！～鬼畜姉妹と受難メイド～`（13.2）bars 17–76 相对密度 1.39 / 2.28 条滑轨。
  - **落ちサビ 真减压的那一半**：`ローリンガール`（13.2）bars 29–40 相对密度 0.74；
    `しねばいいのに`（13.0）bars 29–40 相对密度 0.69。
    ⇒ **同一个标签下两种写法各占一半，标签本身给不出答案。**
  - **前奏不写星星**：见知识 **088** 的谱例（`ぽっぴっぽー` m001–m011 / `疾走あんさんぶる` m002–m007）。

- **理由**：160 首逐小节实测；星星族 lift 与 074 的既有数（绕圈星星 落ちサビ 1.67、穿心 1.76）
  在本轮重跑中复现，说明差别来自"074 只写了两句"而不是数据口径变化。
  减压段一条是**直接计数**（密度 ÷ 本曲均值），不依赖任何 agent 评分。

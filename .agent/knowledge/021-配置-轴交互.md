# 021 — 配置：轴交互

- **日期**：2026-09-10
- **要点**：轴交互 = **一只手固定在一个键位（轴键）上、另一只手不在固定键位**的交互配置；是交互配置的变种。
- **详情**：
  - **定义**：一只手固定在轴键上反复敲，另一只手承担全部变化。
  - **最常见形态 = 邻键摆动的 BABCB 五音小单位**：`B(轴) → A(邻) → B(轴) → C(邻) → B(轴)`——3 次轴音 + 2 次邻音，共 **5 个音**；A、C 是轴键两侧的邻居。（BABCB 指这个 5 音单位本身，不是"无限循环"的意思。）
  - **少见形态**（相对罕见）：**环绕扫键**（另一手几乎绕圈走）、**长度比较大的**轴交互、**跳位移动**（另一手有较大跳位）。
  - ⚠️ **与纵连的区分（重要）**：轴键虽然反复出现，但**每个轴音之间都隔着另一只手的音**——不存在连续同键、不需要"拆"，**与纵连无关**；纵连是同一键**连续**敲（中间没有别的音）、需要拆着打。
  - **实例**：
    - **Halcyon**（id 1212，standard，191BPM，MASTER 14.3，本地有）：`{16}3,4,3,2,3,4,3,2,3,4,3,2,3,4`（轴 3，邻键 4/2——BABCB 的连续铺开）；`{16}7/8,,6,5,6,7,6,5,6,7,6,5,6,7,`（轴 6，邻键 5/7）。191BPM `{16}` ≈ 12.7 键/秒。
    - **怒槌**（id 487，standard，200BPM，**MASTER 定数 14.8——超出本项目 13.0–14.5 抓取范围，本地无 txt**，据用户引文）：`{16}3,5,3,6,3,7,3,8,3,1,3,2,3,4,3,5,3,6,2,6,1,6,8,6,7,6,5,6,4,6,3,6,`（轴 3：另一手 5,6,7,8,1,2,4,5,6 **环绕**；轴 6：另一手 2,1,8,7,5,4,3 环绕）；`{16}6,4,6,3,6,2,6,1,6,8,6,7,6,5,6,4,6,3,7,3,8,3,1,3,2,3,4,3,5,3,6,3,`（轴 6 环绕 → 轴 3 环绕）——属"环绕 + 长度较大"的少见形态。
    - **Hainuwele**（**DX 谱**，175BPM，MASTER 14.3，仅作说明）：`{16}3bx,7,5,7,1,7,5,7,3,7,5,7,2,6,4,6,8,6,4,6,2,6,4,6,`（首音 3bx 带绝赞+EX；轴 7：另一手 5,1,5,3,5 → 轴 6：2,4,8,4,2,4）；`{16}6bx,2,4,2,8,2,4,2,6,2,4,2,7,3,5,3,1,3,5,3,7,3,5,3,`（轴 2：4,8,4,6,4 → 轴 3：7,5,1,5,7,5）——属**跳位移动**的少见形态。
  - **轴结构的识别方法**（agent 分析用，供后续核对）：轴音在**隔位**重复（B,A,B,C,B,…），可按"同一键在奇数位或偶数位反复出现"切分轴段，其余位置即另一手序列；引文中途可换轴（如 Hainuwele 两段各含 2 个轴段）。
- **理由**：轴交互用一只固定手降低变化量，是交互的变种；常见度与另一手的跨度/长度相关——**邻键的短小单位最常见，跨度大（环绕/跳位）或很长的最少见**。

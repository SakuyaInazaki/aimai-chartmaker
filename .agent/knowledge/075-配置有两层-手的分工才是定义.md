# 075 — 「配置」有两层：谱面形状只是必要条件，手的分工才是定义

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：388 个官方 ST 谱；把知识 017–063 的文字定义分别按"键位 + 时间几何"（键位版）与"左右手分工"（手序版）操作化后对照。

- **日期**：2026-09-20
- **要点**：同一串音符，**换一套手序就会变成另一个配置**。所以"配置"有两层——**谱面形状（键位与时间）只是必要条件，两只手各自在做什么才是定义**。写谱时**选配置 = 选两只手各自的角色**，不是选一个形状。这与用户准则「任何配置都按左右手定义」（2026-09-19）同向，本条是它的谱面侧证据。
- **详情**：

  1. 把 17 类共有配置从键位版换成手序版判据后，命中量降了约三分之一，而**降掉的不是漏检**：
     - 约六成旧「普通交互」段落，两只手**根本不在逐音交替**；
     - 约一半旧「错位」段落，那个错位音**落在另一只手上**（于是它不是错位）；
     - 另有约四分之一旧「错位」段落，**拍头与划轨已经分给两只手**（那是换手，知识 054）。
  2. **稳的是"分工"这一层，漂的是"手落在哪"这一层**：把可及性模型从分页二分换成用户的舒适区（知识 064）之后，**20 个配置名的命中数一个不差**；变化全部集中在判据里直接写了"哪只手落在哪半边"的那几类（出张 / 反手 / 侧边双押 / 散点 / 错位）。
  3. **对写谱的含义**：`docs/hand-sequencing.md` §6.1 的顺序——**先分手、再落 note**；先决定"这一段左手做什么、右手做什么"，形状是结果不是起点。
  4. **对读官方谱的含义**：任何"这段是什么配置"的判断，只有连同手序一起说才成立；同一段谱在不同手序下可以同时是两个配置名的合法读法（知识 065：同一段谱本来就有多套合法手序）。

  **证据注脚**：17 类共有配置命中量 −33%；旧 `普通交互` 消失段 5 128 小节（58% 两手不逐音交替）、旧 `错位` 消失段 5 202 小节（51% 错位音在另一只手、26% 拍头与划轨已分手）；`大宇宙` 159 谱 → 102 谱、`楼梯` 205 → 92、`方向盘` 68 → 39、`定拍` 86 → 38；换可及性模型后完全不变的 20 类（子弹 8 431 / 连续双押 6 479 / 跳拍 4 538 / 单双 3 577 / 一笔画 2 554 …）Δ = 0。

- **理由**：AGENT.md 准则 12（用户 2026-09-19：任何配置都按左右手定义）；本条给出它在 388 谱上的量级——**不是"稍微有点差别"，而是三分之一的命中量**。
- **来源**：`docs/research/configs-hand-rewrite.md` §4、§4.1、§4.2、§7、H5、H6；`docs/hand-sequencing.md` §5。
- **置信度**：**经验（agent 观察，n=388 谱 / 32 321 个有音小节，未经用户确认）** / **存疑**（① 手序版判据依赖 `hands.py` 给出的**一套**最优手序，而合法手序不止一套，召回受此影响；② 各类判据的细节口径仍有 agent 操作化成分）。

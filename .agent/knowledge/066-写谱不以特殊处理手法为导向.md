# 066 — 写谱不以特殊处理的手法为导向（用户裁定）

- **日期**：2026-09-19
- **要点**：「同时处理」「狗刨」这类词是**手法**的意思——**使用手法会变得更好打**；**不是说因为可以用这个手法就塞难打配置**。这两者不是一个意思，**写谱不以特殊处理的手法为导向**。
- **详情**：

  ### 用户原话（逐字）
  > 同时处理/狗刨这两个词语是手法的意思，使用手法会变得更好打，不是说因为可以用这个手法就塞难打配置，这两者不是一个意思，写谱也不是以特殊处理的手法为导向这么写的。

  ### 主会话解读
  - 用户把两件事分开：
    | 方向 | 内容 | 成立与否 |
    |---|---|---|
    | 玩家侧 | 会某个手法 → 这段**更好打** | ✅ 用户明说 |
    | 谱师侧 | 存在某个手法 → **因此可以塞难打的配置** | ❌ 用户明说"不是一个意思" |
  - 因此手法是**玩家的解法**，不是**谱师的许可**；写谱的导向不是"玩家可以用特殊手法处理"。

  ### 对手序模型的含义
  1. **`hands.py` "一手吃两个对象"默认关闭这一取舍，获得用户背书**（`docs/hand-sequencing.md` §7-1）。此前的理由是"实测前不得用来放宽 008/009 红线"（来自 ep3 §5.4-3，教程侧）；用户给的理由更根本：**写谱本来就不该以手法为导向**。因此这不只是"暂缓实现"，而是**规划期的口径**。
  2. **点名受影响的三条**：知识 **042** 狗刨、知识 **060** ② 同时处理（8 分 75BPM / 4 分 150BPM）、知识 **055** 穿心的同时处理。它们仍可用来**解释**官方谱为什么敢那样写、玩家怎么打得更省力；**不得**用来论证"这里可以写更难的配置"或"这里的无理可以放宽"。
  3. **与既有条目的关系**：知识 042 的 agent 推断 2（"只影响能不能写，不影响必须怎么写"）与知识 011 处理法②的提醒（"不得用来放宽红线"）方向一致，本条把它们从 agent 推断升级为**用户口径**。

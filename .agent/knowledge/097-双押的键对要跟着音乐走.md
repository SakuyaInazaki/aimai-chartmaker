# 097 — 双押的**键对**要跟着音乐走，不能只有顶双押 / 底双押两个把位

> ⚠️ **本条为 agent 观察，未经用户确认。** 来源：同曲官谱抄谱对照（note 069）。n=1。

- **日期**：2026-09-20
- **要点**：我们全谱 193 组两键双押里，`18`（顶）占 86 组、`45`（底）占 71 组，
  **两项合计 81%**；128 个有音小节里有 **57 个**是"第一拍一个 `18` 或 `45`"开场。
  参考谱 125 组双押里**最常用的一对只有 10 组**，主力是 `78` / `17` / `35` / `24` / `46`
  这种"旋律上挨着或隔一格的两个音"。**双押是采音的结果，不是段落的骨架。**
- **详情**：

  | | 参考谱 | 我们 |
  |---|---|---|
  | 两键双押组数 | 125 | 193 |
  | 前 5 对 | `78`×10 `17`×10 `35`×9 `24`×9 `46`×8 | **`18`×86 `45`×71** `23`×6 `67`×6 |
  | 键位分布 1→8 | 12/11/11/15/15/13/12/11 %（八键基本均分） | 17/9/8/15/14/8/12/17 %（1·4·5·8 占 63%） |
  | each（同刻 ≥2）时间槽 | 164 | 244 |
  | 最终 drop 的 each 槽 / note | 42 / 278 | **68 / 226** |

  **副作用**：`18`/`45` 当骨架会把键位分布挤歪（2/3/6 各只剩 8–9%），
  而且**最终 drop 的密度变成靠双押撑**（我们 each 槽比参考谱多 62%、note 却少 19%）。

- **理由**：顶 / 底双押好写（两手各守一侧、永远不无理），所以它会变成"没想法时的默认动作"。
  参考谱的双押分散在十几对键上，说明每一对都是**当时那两个音**决定的。
- **来源**：`docs/research/test-01-vs-reference.md` §3.2 / §2.12；同曲官谱抄谱对照（note 069）。
- **置信度**：**经验**（键对计数为直接统计）/ **存疑**（n=1；"跟着旋律"是 agent 的解释，无听审）

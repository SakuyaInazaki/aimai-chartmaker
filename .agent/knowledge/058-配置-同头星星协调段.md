# 058 — 配置：同头星星协调 / 挥手段（星星协调段）

- **日期**：2026-09-19
- **要点**：挥手段 = **一只手钉在一个键上、按四分音节拍从中间向两边轮流甩星星，另一只手同时处理别的音符**的复合段。教程点名它"**容易让人脑梗**"，难点是**左右手协调 + 抓节奏**，而不是手速。
- **详情**：

  ### 教程说明（转述）
  - `[28:38]`「**同头星星协调/挥手段：同头星星的其中一种表现形式**。**一只手按照四分音节拍从中间向两边滑星星，另一只手去处理别的音符**的一类**复合配置统称**」「可以是**匀拍的节奏**，也可以是**一个跳拍接一个匀拍**此类的复杂节奏，**还可以是扫键**」「**容易让人脑梗，需要一定左右手协调能力和抓节奏能力**」。
  - 教程按"另一只手在干什么"分了三档：**匀拍节奏**（示例一–二）、**复杂节奏**（示例三–六）、**扫键**（示例七）。
  - 谱例：（缺名）13.7 RE:MAS/180、**緋色のDance 13.7 RE:MASTER/155**、Starlight Disco【DX】13.1/128、Splash Dance!! 13.4/155、We Are Us 13.5/145、LOSE CONTROL 13.7/150、Neon Kingdom 13.8/130（扫键）。

  ### 谱例
  **定位成功**：`resource/official-chart/373-緋色のDance-remas.txt`，**m041–m046**（`{4}` @155BPM；教程 示例二 定数 13.7 / RE:MASTER / BPM155 三项全对）：

  ```
  m041| 2^4[8:1]/7^5[8:1],2^8[8:1],2^4[8:1]/5^7[8:1],2^8[8:1],
  m043| 2^4[8:1]/7^5[8:1],7^1[8:1],4^2[8:1]/7^5[8:1],7^1[8:1],
  m045| 2-4[8:1]/7-5[8:1],2-8[8:1],2-4[8:1]/5-7[8:1],,
  ```
  读法：**键 2 每个四分音发一根星星，方向在 `2^4`（往一边）和 `2^8`（往另一边）之间交替**——这就是"从中间向两边滑"；与此同时另一只手在 7/5 一侧打自己那条线（`7^5`、`5^7`）。m043 是左右角色对调版（钉在 7 上甩 `7^5`/`7^1`）。m045–m046 把弧线换成直线，骨架不变。

  ### agent 理解
  - **手级定义**：
    - **拍星星头的手**＝**固定手**，始终在同一个键（緋色＝2 或 7）上按下，然后向左/向右交替甩出；
    - **划轨的手**＝**同一只固定手**（头与轨道不分离）；
    - **另一只手任务**＝**自由手**，处理教程说的三档内容：匀拍 tap / 复杂节奏（跳拍＋匀拍）/ 扫键；
    - **换手时机**：**段内不换**。左右分工从段首定死，直到段落对调（緋色是 m041–m042 一组、m043–m044 换边）。
  - **它是 027 定拍的星星版（本条最有用的归类）**：027 定拍＝"一手固定打拍子、另一手处理别的配置"；本条＝"**一手固定甩星星打拍子**、另一手处理别的配置"。两者结构同构，差别只在固定手拿的是 tap 还是 slide。同理它也是 **033 死镰段的镜像**：死镰段是"稳定手走圈 tap、自由手划星"，本条是"**稳定手划星、自由手打别的**"。
  - **"脑梗"的机制（agent 推断，存疑）**：固定手的节奏是**规整的四分音**，自由手的节奏是**跳拍/扫键**，两条线在时间上**不对齐**——这正是 045 混 fr 说的"两只手处理不同的节奏"。**本条＝混 fr 的星星特例**：固定手那条线恰好用星星承担。
  - **"从中间向两边"的几何含义（推断，存疑）**：固定键必须**在两侧都有可甩的目标**，所以它落在 2 / 7（左右正中）这种位置最自然；若固定在 8 或 4（上下正中），甩出去的两个方向就是左右半圈，会直接构成 043 出张。緋色两段分别钉 2 和 7 正是这个道理。
  - **可机检判据草案（B 档）**：滑动窗口内，若存在一个键 K 满足"**以 K 为 head 的 slide 数 ≥3、按四分音等间隔、终点交替落在 K 的两侧**"，且窗口内另有**不与之同刻**的 note 序列 → 打 `wave_section` 标记。緋色 m041–m046 为阳性样本。
- **理由**：定义与三档分类为教程明文；緋色のDance 谱面逐格核对出"固定头键 + 左右交替终点"的结构；与 027/033/045 的关系为 agent 归类。

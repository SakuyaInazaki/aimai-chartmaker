# 074 — 配置的段落分区：谁住イントロ、谁住サビ、谁住ドロップ／間奏

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：160 首官方 ST 曲包，段落标签来自音频分析管线（三路投票 + 日式词表，**未经人工听审**）；配置识别为手序版（v0.2 分配器）。lift = 该配置在该段落的出现概率 ÷ 它的总体概率。

- **日期**：2026-09-20
- **要点**：配置在段落上的分布**不是均匀的**，官方谱大体给它们分了地盘：
  **イントロ 归纵连族**、**サビ 家族归双押系与"接得顺"的星星**、
  **ドロップ / 間奏 归几何配置**、**Bメロ 归侧边双押与"要分手"的星星**、
  **落ちサビ 是出张最集中的地方**。
- **详情**：

  1. **イントロ**：纵连、**长纵连**是这里的专属（长纵连 lift 3.1）；几何配置一律低于基线。长纵连本身很简单，却出现在高定数谱里、位置偏前——**它是高定数谱的前奏装置**。
  2. **ドロップ / 間奏**：几何配置的集中地——三角交互、楼梯交互、轴交互、散点、大宇宙、方向盘，外加匀拍单点的普通交互。**間奏 也是最敢"采空音"（写音轨里没有的音）的段落**。
  3. **サビ / ラスサビ**：富集的是**双押系与错位**（单双/双单、连续双押、双押纵、错位），以及**接得顺的星星族**（一笔画、连续拍滑、绕圈星星、穿心）；**普通交互反而被压到基线以下**——副歌不是"单点交互跑得更快"，是"换成双押与错位"。
  4. **Bメロ**：**侧边双押最偏爱的段落**（⚠️ 键位版曾说"副歌里最富集的是侧边双押"，**手序版下这条不成立**，三版重跑的共同点都是 **Bメロ ≥ サビ**）；同时是**要分手的星星族**（鼓动段、二连扫、CYCLES 型、反手、三叉戟）的地盘。
  5. **落ちサビ**：**出张最集中**的段落（那一段密度低、手更闲，正好塞一次跨界）；唯一在此富集的几何配置是方向盘。
  6. **アウトロ**：样本太少，只能当提示；它强度最低却是高硬度富集段（尾杀，与知识 001 / 031 §10 一致）。
  7. ⚠️ **存疑的一条（键位版观察，手序版待重跑）**：几何配置几乎总与匀拍单点段同小节或相邻小节出现——读作"**写几何配置之前先要有一段匀拍单点的底布**"。手序版下"普通交互"大幅缩水，这条**需要重跑才能保留**。

  **证据注脚**（手序版 v0.2 lift）：纵连 イントロ 2.09 / 长纵连 3.13；ドロップ 普通交互 2.10、三角 1.99、楼梯 2.04、散点 2.66；間奏 轴 1.88、三角 1.55、楼梯 1.45；一笔画 ラスサビ 1.41 / 落ちサビ 1.37 / サビ 1.30，连续拍滑 ラスサビ 1.61，绕圈星星 落ちサビ 1.67，穿心 落ちサビ 1.76；Bメロ 鼓动段 2.12、二连扫 2.30、CYCLES 1.95、反手 1.77、三叉戟 1.43，侧边双押 Bメロ 1.51 vs サビ 1.21；出张 落ちサビ 1.66 / Bメロ 1.43。

- **理由**：160 首配对语料的逐小节 lift；配置识别以知识 017–063 的定义按手操作化，正例 ground truth 41/43 命中。
- **来源**：`docs/research/sampling-mode-study.md` §8.3、§8.4、§9.3、§9.4；`docs/research/config-difficulty-intensity.md` §2.5、§7；`docs/research/configs-hand-rewrite.md` §5.3。
- **置信度**：**经验（agent 观察，n=160 首，未经用户确认）** / **存疑**（① 段落标签是音频管线产物，未经人工听审，段落级结论继承分段误差；② 方向盘 / 散点 / 长纵连 / 定拍 / アウトロ / Bメロ 样本偏小；③ 跳拍只有粗判，不作依据；④ 只覆盖 ST 谱、定数 13.0–14.5）。
- **关联**：知识 **001**（情绪走势）、**031**（结构模板与末段最强）、**019**（纵连）、**030**（连续双押/侧边双押）、**064**（出张口径）、**069**、**070**、**073**；条目 017–063。

## 修订记录

- **2026-09-20（补关联与读法，正文与证据注脚一字未改）**：
  1. **星星族部分被扩写**：本条只写了「サビ 接得顺的星星 / Bメロ 要分手的星星 / 落ちサビ 绕圈星星·穿心」三句，
     新条目 **090** 把 16 个星星配置在九个段落上全部摊开，并给出本条没有的一条：
     **イントロ 是全表最不写星星的段落**（星星族 lift 普遍 0.4–0.6，38% 的小节才有星星，全曲 54%）。
     本条第 1 条「イントロ 归纵连族」**不被推翻**，090 是它的反面证据。
  2. **「落ちサビ = 减压段」这个读法要改**（090 §6）：`落ちサビ` 与管线的 `rest=True` 字段
     **不携带密度信息**——落ちサビ 的密度与全曲均值持平（相对密度中位 0.997），
     密度 ≥ 本曲均值的曲子占 49%；`rest=True` 的 2 030 个小节里 1 782 个就是 落ちサビ。
     真正密度低的段落是 **イントロ（0.785）**。**本条不改管线行为，只改读法。**
  3. **本条是分布不是处方**（新条目 **092**）：イントロ 星星密度高于本曲均值的曲子占 21%、
     間奏 41%、落ちサビ 密度 ≥ 均值 49%；「イントロ 归纵连族」的 lift 2.09 对应的是
     **只有 33% 的曲子真的在前奏写了纵连族**——lift 高 ≠ 常见。
  4. 新增关联：**088**（段落 × note 种类配比）、**090**（星星族段落用法与减压段实况）、
     **092**（分布 ≠ 处方）、**093**（难度自检）。

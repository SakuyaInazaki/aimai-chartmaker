# 036 — 配置：二连扫（及其与大宇宙的分界）

- **日期**：2026-09-19
- **要点**：二连扫 = **由若干组"二连"接成的连续扫键，两只手轮流各扫一组**；与 024 大宇宙的分界在于——**大宇宙只在固定 4 个键里来回，二连扫是一路往前走的**。
- **详情**：

  ### 教程说明（转述）
  - `[01:27]` 这一节的标题就叫「**区分二连扫和大宇宙**」，给的是一组对照定义：
    - 「**大宇宙**是在 **4 个键位的范围内来回打的交互**，**能选择用单点或者扫键来处理**」；
    - 「而**二连扫**是**由若干组二连构成的连续扫键，两只手交替进行扫**」。
  - 教程用两段演示分别标注「这是大宇宙」`[01:38 前后]` 与「这是二连扫」`[01:59 前后]`；二连扫那段的曲目从画面曲绘可辨认为 **Aegleseeker**（ARCAEA 联动，DX 谱，MASTER 14.5，BPM 234），**说明栏没有给曲名**。

  ### 谱例
  - 教程演示的那一段：**未能定位**——Aegleseeker 是 DX 谱，不在 `resource/official-chart/` 的 388 首 ST 谱里。
  - **agent 另找的同形谱例**（不是教程的例子，仅供形状参照）：`resource/official-chart/149-Blew Moon-mas.txt` **m071**（`{12}` @180BPM）
    ```
    m071| 8,7,6,5,4,3,2,1,8,7,6,5,
    ```
    12 个音一路逆时针走满一圈半；按"每两个键一组"切开就是 (8,7)(6,5)(4,3)(2,1)(8,7)(6,5)——**六组二连、两手交替各扫一组**，正是教程描述的形态。

  ### agent 理解
  - **"二连"是切分单位，不是音符种类**：教程给的是"扫"的执行单位——一只手一次刷过两个**相邻**键。所以谱面上看到的是一条连续的相邻键走位串，只是玩家把它**按 2 个一组**分给两只手。
  - **⚠️ 存疑：二连在谱面上到底写成什么**。视频 `[01:59–02:09]` 的画面里，Aegleseeker 那段出现的是**成对连条的相邻双押**（Majdata 会把同刻的两个 note 画成一根连杆），而不是两个分开的单点。所以"二连"至少有两种可写法：
    1. **相邻两键的连点**（如上面 Blew Moon 的 `8,7,6,5,…`），玩家自己选择刷过去；
    2. **相邻两键的双押串**（`87,65,43,…` 之类），一只手必须刷两个键才打得下。
    教程没有把这一层讲明，**两种都先记下，别当定论**。
  - **和大宇宙的真正分界**（教程明说的那条）：**键位集合是否封闭**。大宇宙（024）严格 4 个键、两对相邻键、每手在自己那对里横跳，所以整段**原地不动**；二连扫**一直往一个方向推进**，键位集合不断更新。
  - **教程对大宇宙的补充**：「能选择用单点或者扫键来处理」——这是 024 里没有的一条信息，说明**大宇宙的谱面写法（单点）和玩家的执行手法（扫键）可以分离**；同理，二连扫的"扫"也是执行层的描述。写谱时要意识到：**你写下的是 note 序列，玩家可能用扫键一次吃掉两个**。
  - **与其它条目的边界**：二连扫的单点串形态和 **018 普通交互**、**022 楼梯交互**会重叠——楼梯是"成对推进、每步只走相邻键"，二连扫是"同方向连续走相邻键、按 2 个一组扫"。两者很可能描述的是同一批谱面的不同侧面（楼梯讲摆位，二连扫讲手法）。（agent 推断，存疑）

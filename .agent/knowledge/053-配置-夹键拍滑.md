# 053 — 配置：夹键拍滑（连续拍滑 + 同键位的夹键）

- **日期**：2026-09-19
- **要点**：夹键拍滑 = 在 049 连续拍滑的骨架上，**把星星头所在的那个键连按三下八分音（头 → 夹键 → 启动拍），第三下同时把星星划出去**；两手各自完成一组"同键三连＋划"，一拍一换。教程原话：「由拍滑变成了**八分音拍三下然后滑星星**」。
- **详情**：

  ### 教程说明（转述）
  - `[10:19]`「**连续拍滑+同键位的夹键**：把夹键放上去以后变得更抽象了，**由拍滑变成了八分音拍三下然后滑星星**，直接来看示例吧容易看懂一点」。
  - `[11:21]` 逆向说明：「**现在我们再来看这段节奏，然后把夹键移开，这不就是…**」——教程亲自演示"**去掉夹键就退化回 049 连续拍滑**"。
  - 谱例：四次元跳躍機関 13.4 BPM134、**ECHO 13.5 BPM140**、Caliburne 14.3 BPM190、Xevel 14.3 BPM176→185。

  ### 谱例
  **定位成功**：`resource/official-chart/400-ECHO-mas.txt`，**m022 / m026**（`{8}` @140BPM；教程 示例二 定数 13.5 / MASTER / BPM140 三项全对）：

  ```
  m022| 1/8-4[8:1],8,3-1[8:1]/8,3,3/5-7[8:1],5,1-5[8:1]/5,1,
  m026| 1-5[8:1]/8,1,1/6-8[8:1],6,4-2[8:1]/6,4,4/8-4[8:1],8,
  ```
  把 m022 按键位摊开：**8**(头)→**8**(夹键)→**8**(启动拍，同刻另一手起新头 3)→**3**(夹键)→**3**(启动拍，同刻新头 5)→**5**→**5**(启动拍，同刻新头 1)→**1**……即**每个键连吃三个八分音**，三连的第一下是星星头、第三下是启动拍。相邻两组**首尾同刻咬合**，于是屏幕上每个八分都有音。
  同曲 **m020 / m024** 是把夹键抽掉的对照组（`4/8-5[8:1],,2-7[8:1]/8,,…`），正好对应教程 `[11:21]` 那句"把夹键移开"。

  ### agent 理解
  - **手级定义**（以 ECHO m022 为例，L/R 只是记号）：
    - **拍头手**＝本组的手，它在键 K 上连打三个八分；
    - **划轨手**＝**同一只手**——第三下就是启动拍，打完顺势划出；
    - **另一只手同时在做什么**：在第三下的同刻**按下下一组的星星头**（新键 K'），随后开始自己的三连；
    - **换手时机**：**每个四分音换一次**（＝每两个八分），两手相位差一拍，与 049 完全同构，只是每只手在自己那一拍里多打了两下。
  - **它在"拍滑家族"里的位置（本轮最重要的结构发现）**：三个术语共用同一副骨架，**差别只在四分音之间插进来的那个八分音落在哪个键**：
    | 插入的八分音 | 术语 | 条目 |
    |---|---|---|
    | 不插 | 连续拍滑 | **049** |
    | 插在**星星头同一个键** | 夹键拍滑 | **053**（本条） |
    | 插在**别的键** | 错位 / 海底谭错位 | **017** |
    教程 `[11:29]` 正是顺着这条线把夹键拍滑过渡到海底谭错位的（「本质就是在四分音拍滑间插入了八分音符」）。
  - **为什么"更抽象"（agent 推断，存疑）**：视觉上星星头与两个夹键**叠在同一个键上**，玩家看不出"哪一下是头、哪一下该划"；节奏上又从四分变成连续八分，**读谱负担高于体力负担**。这与 019 纵连的难点（体力/个人差）不同——本条难在**识别**。
  - **红线检查**：同键三连八分，按 015 的 NPS 公式在 BPM190（Caliburne）下 ＝ 6.3 击/秒、同键间隔 158 ms，**远离 009 的 42 ms 叠键下限**；真正要盯的是 **010 外键无理**——星星头之后 150–200 ms 内同侧还有两个 tap，**正好踩在外无阈值上**。BPM ≥150 时八分间隔 ≤200 ms，`(60/BPM)/2 ≤ 0.2 s` ⇒ **BPM 150 以上的夹键拍滑，夹键天然处在外无危险区**，需要靠"夹键与星星头同键"这一点来豁免（同键＝划屏手本来就在那儿）（*推断，存疑*）。
- **理由**：结构由 ECHO 谱面逐格核对得出（同键连三个八分、第三下＝启动拍），并与教程"拍三下然后滑"逐字吻合；教程自己演示了"去掉夹键→退化为拍滑"，family 关系可确证。

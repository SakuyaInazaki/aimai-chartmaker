# 086 — 似踩非踩（MMFC 用词）：铺满但不跟音轨，**不是第四个采音档位**

> ⚠️ **术语与定义是 MMFC 明文**（`确信`）；**官谱里的用法分布是 agent 观察，未经用户确认**。分布口径：160 首带官方音频的 ST 曲目（`out/calib/`，定数 13.0–14.5）。

- **日期**：2026-09-20
- **要点**：**似踩非踩 = 谱面按匀速分音把小节铺满，而这些音并不对应音轨实际发出的音**；腾出来的表达位交给配置。它**不是"不踩"（留白），也不是"只踩一部分"（舍音）**——在本项目的三词口径里它**藏在「全踩」里**。
- **详情**：

  1. **出处与原文**（MMFC《谱面创作基础学》**5.3 踩音与配置**）：

     > 「海底谭的副歌采用了一种**似踩非踩**的写法，**全程铺满 8 分音符**」

     MMFC 把那一段的谱面拆成"踩音"与"配置"两层，踩音层写成 `{8}x,x,x,x,x,x,x,x,`，然后问「**他不选择踩最明显的人声是为了干什么呢？为了写配置**」——接着引出"海底谭星星"。
  2. **官谱原例（形态锚点）**：`336-ウミユリ海底譚-mas` **m030–m031**（`{8}` @120BPM；同形在 **m060–m062** 的第二次副歌再现，星星换成 `^` 弧）。一小节 8 个格子**一个不空**，穿心星星逐格换头。⚠️ 该曲**本地没有音频**，所以它只能作形态锚点，不能作度量样本。
  3. **★ 它的指纹是「coverage 高 + extra 高」，不是「coverage 低 + extra 高」**：铺满会把音轨那点音**顺手全都盖住**，所以"跟上了多少音轨的音"反而高；真正露馅的是**铺出来的格子里有一大批任何一条 stem 都对不上**（社区叫**采空音 / 插空音**）。早先在 `sampling-terminology-survey.md` 里猜的方向是反的，已由 160 首实测纠正。
  4. **官谱怎么用它**（agent 观察）：
     - **不是罕见写法**：160 首里**超过一半的曲子用过**；但**成段连用（≥3 小节）很少**——多数时候它是**一两小节的过渡填充**，不是整段的基调；
     - **段落偏好**：**落ちサビ ＞ Bメロ ＞ イントロ ＞ 間奏 ＞ Aメロ ≈ サビ ＞ ドロップ ＞ ラスサビ**——**最强的那两类段落（ラスサビ / ドロップ）反而最不用它**。它集中在"要有推进感但不该抢戏"的位置；
     - **★ 与段落强度无关**：候选小节的强度中位与全部"匀速铺满"小节几乎没有差别——**似踩非踩不是"低强度铺底"专用**，高强度段一样在用；
     - **骨架轨仍是鼓**：铺满时最像"在跟"的那条轨仍是 drums，与知识 032「鼓骨架 + 非鼓填充」一致，只是这里填充的比例被推到了极端；
     - **分音**：MMFC 说的"8 分"只是它举的那一例，官谱在 **8 / 12 / 16 分上都这么写**；定数上 13 档、14 档都有，**没有"只有低难度才这么写"的迹象**。
  5. **★ 不要把它做成第四个互斥档位**：社区**没有**把「全踩 / 舍音 / 留白 / 似踩非踩」当一组互斥分类在用；而且"铺满得多满算铺满"一旦定阈值，就又回到用户 2026-09-20 批评过的那条路上去了。工具里它只是一个**布尔诊断标记**（`sampling.BarSampling.pseudo_sample`，条件 = 匀速铺满 ∧ coverage 高 ∧ extra 高），**对外仍然只有三个词**。
  6. **和 005「采音要简」不冲突，是另一条轴**：005 说的是"从候选池里挑走多少"，似踩非踩是"在候选池之外还要不要**加**格子"。**官谱两件事同时做——删掉音轨里的音，同时加上音轨没有的格子。**
  7. **它是知识 002「踩音随情绪切轨」的边界情况**：这一小节谁也不跟，工具给它挑的那条"最像"的骨架轨**在这些小节上没有意义**。

  **证据注脚**：160 首 13 010 个可比小节里，"匀速铺满"的 1 377 个小节 coverage 中位 **0.92**、extra 中位 **0.12**（其余小节 0.67 / 0.00）；按 extra 取尾得 **314 个候选小节 / 84 首**（超过一半的曲子），其中 **266 个被三词口径判成「全踩」**（另 30「舍音」、14「—」、4「留白」）。成段连用 ≥3 小节只有 12 处、≥4 小节 7 处。段落上 extra 高的比例 落ちサビ 0.30 ＞ Bメロ 0.28 ＞ イントロ 0.27 ＞ 間奏 0.24 ＞ Aメロ 0.22 ≈ サビ 0.22 ＞ ドロップ 0.13 ＞ ラスサビ 0.11；候选强度中位 0.78 vs 全体 0.79；骨架轨 225/314 是 drums；分音 `{16}` 116 / `{8}` 107 / `{12}` 55；定数 13 档 89 / 14 档 225。官谱例：`初音ミクの激唱` m079–m089（落ちサビ，连续 11 小节）、`夜明けまであと３秒` m071–m074（間奏，本轮 extra 最高）、`秘神マターラ` m002–m007（イントロ，与海底譚形态最接近）、`初音ミクの消失` m082–m089、`ジングルベル` m019–m021（铺底 + 每拍压一个 hold）。

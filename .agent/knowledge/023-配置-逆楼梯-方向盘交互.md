# 023 — 配置：逆楼梯 / 方向盘交互

- **日期**：2026-09-10
- **要点**：逆楼梯（= 方向盘交互）——交互的一种：两手**必须 180° 对位**、**同方向同步移动**（像双手转方向盘）；**必须折返**（转不了整圈），折返点与时机自由控制。
- **详情**：
  - **三条硬性规则**：
    1. **必须 180° 对位**（是硬要求，不是典型形态）；
    2. **两手同方向同步移动**（都 +1 或都 −1）；
    3. **必须折返**——不折返胳膊会扭断（原因见下"可及范围"）。
  - **可及范围与 6 个合法位置**：右手最多往左够到 **5 号键** → 右手可及范围 = `{5,4,3,2,1,8}`；左手对称可及 = `{1,8,7,6,5,4}`。因此 180° 对位下**只有 6 个合法位置**：
    ```
    (8,4) → (1,5) → (2,6) → (3,7) → (4,8) → (5,1)
    ```
    超过任何一端（`(6,2)` / `(7,3)`）都会超出右手可及范围 → **转不了整圈，必须折返**。
  - **折返点与时机自由**：Calamity L1 一直转到 `(5,1)`（右手到极限 5）才折返；Calamity L2 与 REVIVER 在 `(4,8)` 就提前折返；L2 结尾还转到了另一端的 `(8,4)`——折返位置与步数完全可控。
  - **与楼梯交互的区分**：
    - **楼梯**：两手**反向**移动（+1 / −1），对是"相邻～张合"关系（`(1,8)→(2,7)→(3,6)`）；
    - **逆楼梯 / 方向盘**：两手**同向**移动（+1/+1 或 −1/−1），对**始终 180° 对位**（`(1,5)→(2,6)→(3,7)`）。
    - 命名含义："逆"= 楼梯的反相位；"方向盘"= 两手同向转动的手感。
  - **实例**（均在 `{16}`、200BPM ≈ 13.3 键/秒；本地 `resource/official-chart/` 已核对原文）：
    - **Calamity Fortune**（ST 版 id 633，MASTER 14.2；另有 DX 版 id 632）：`1,5,2,6,3,7,4,8,5,1,4,8,3,7,2,6,`；`1,5,2,6,3,7,4,8,3,7,2,6,1,5,8,4,`；第三行同第一行。
    - **REVIVER オルタンシア・サーガ -蒼の騎士団- オリジナルVer.**（id 815，MASTER 13.7）：`{16},,1,5,2,6,3,7,4,8,3,7,2,6,1,5,`（开头带休止——时机同样可调）。
- **理由**：该配置靠"对位 + 同向旋转"制造方向盘式手感；受右手可及范围限制只能在 6 个位置间往返，**折返是其固有特征**（区别于楼梯的"两手反向移动"）。

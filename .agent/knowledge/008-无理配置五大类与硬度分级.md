# 008 — 无理配置五大类与硬度分级

- **日期**：2026-09-10
- **要点**：社区把"无理配置"（人类正常手法无法处理的配置）分为五大类，并按规避难度分为软/硬/绝对三级；绝对无理=作谱失误，生成器必须做到零绝对无理、尽量零硬无理。
- **详情**（五大类定义）：
  1. **多押**：同一时刻需要 ≥3 只手才能处理；
  2. **内屏无理**：内屏正攻必蹭绿星星（slide 轨道）；
  3. **叠键**：同一时刻同一判定区出现 ≥2 个 note；
  4. **外键无理**：slide 启动后一定时间内出现同头（同侧）Tap/Hold，易被划屏手误蹭；
  5. **撞尾**：slide 划过 A 区时该区出现 Tap/Hold 被蹭。
  - 分级：软无理（不大改手法可规避）/ 硬无理（需换手法）/ 绝对无理（无法规避）。
  - 另有拓扑无理（手序引导失误/手碰撞体积）与超速无理（超出人类极限的速度）。
- **理由**：本项目验收标准"人类可玩"的判定需要无理规则作为硬约束；分类与阈值是社区检测工具（MaiMuriDX）与多位谱师的经验总结。
- **来源**：Maimai 无理综述（三）https://www.bilibili.com/opus/971624771839066129 ；**MiaCode MURI_DETECTION_SPEC（5 类 MuriKind 与之一致：SlideTooFast/SlideHeadTap/TapOnSlide/Overlap/MultiTouch）**
- **置信度**：经验（社区检测标准，非官方文档）
- **关联**：知识 009/010/011（各类阈值）、006（正规手法）。

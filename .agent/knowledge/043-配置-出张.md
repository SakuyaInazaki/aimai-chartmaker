# 043 — 配置：出张

- **日期**：2026-09-19
- **要点**：出张（日语"出差"）= **让某只手离开它习惯的那半圈，去打另一区域的按键**；教程的大白话是「**左手打右边，右手打左边**」。它同时是配置特征和难度来源，反手（037）是它的极端情形。
- **详情**：

  ### 教程说明（转述）
  - `[05:43]`「**出张：在日语是出差的意思，意指离开了舒适区。放在音游里代表着在游玩过程中离开常用的、习惯的、舒适的击打区域，去击打其他区域的按键。非常考验玩家的定位能力和协调能力**」；「**人话：左手打右边，右手打左边**」。
  - `[05:46]` 对 Alice in 冷凍庫 的批注：「**从这里开始就是大量的出张，练 tap 定位，滑星星不留尾，需要一定的身体协调**」。
  - 教程谱例四首：**Alice in 冷凍庫**（12.8 / Jack / Splash PLUS / BPM 176，DX）、**魔法少女とチョコレゐト**（13.5 / Redarrow / FESTiVAL PLUS / 150，DX）、**最終鬼畜妹・一部声**（13.9 / rioN / ORANGE PLUS / 200，**ST，本地有**）、**グッバイ宣言**（12.8 / はっぴー / UNiVERSE / 170，DX）。

  ### agent 理解
  - **判据（可机检的那一条）**：按 006 的分页处理，右手默认吃 1234、左手吃 5678。**当一只手被星星/长条钉在某一侧，同刻或紧邻的 tap 却全落在同一侧时，另一只手就必须跨界**——这就是出张。
    以 m060 为例：`8-5` 的头在 8、轨道走到 5，滑星的手被压在**左半圈**；紧接着的 `2,8,1` 里，**2 在右半圈、8 又回到左半圈**——右手要一路够到 8，左手在滑，这就是"右手打左边"。下半小节 `4-7` 把滑的手压到右下，随后的 `2,4,3` 全在右半圈，于是**左手必须跨到右边**去补 4 或 3。
  - **和反手（037）的界线**：出张只要求"某只手过界"；**反手要求两只手都过界且手臂交叉**。教程自己也说"出张包含反手"。
  - **强度来源**：教程点名"定位能力"——跨界以后手离开了熟悉的肌肉记忆位置，**tap 的命中率而不是速度**成为瓶颈。批注里"滑星星不留尾"补了第二条：跨界的那一手往往正在滑星，**尾巴留在屏幕上就会撞到接下来的 tap**（011 撞尾）。所以出张段对 010/011 的阈值格外敏感。
  - **写谱时怎么制造**：几乎总是"**用一条长星星/长条占住一只手，把音符堆到那只手那一侧**"。m060 那种"对穿星星 + 同侧三连点"是最经济的写法：一条 slide 就能把整小节变成出张。
  - **强度可缩放**：教程的四个例子从 12.8 到 13.9 都有，说明**出张本身不贵，贵的是出张的密度与跨度**。12.8 的曲子也能"从这里开始就是大量的出张"。
- **理由**：定义与"左手打右边"的判据是教程明文；谱例由帧达成率反查定位；机制拆解为 agent 在引文范围内的分析。

## 修订记录

- **2026-09-19（用户讲授）**：**出张的边界以用户定义为准，见知识 064**——左手舒适区 = 左半屏 8765 + 上方 1 + 下方 4，右手 = 右半屏 1234 + 8 + 5；**只有右手拍 6/7、左手拍 2/3 才算出张**，右手打 5/8、左手打 1/4 不算。本条目原引的教程大白话「左手打右边，右手打左边」是同一件事按中线二分的**粗口径**，统计与机检一律改用 064 的键位定义。用户同时给出写谱要求：「**轻易不要写出张**……判断这是否是容易游玩的还是故意设置的难点，**就算是难点也要做好引导**」。教程原文与谱例未改。
- **2026-09-20**：按用户 2026-09-19 讲授的舒适区定义（知识 064：出张 = 右手落 6/7 或左手落 2/3，共享键 1/4/5/8 两手皆可），分配器 v0.2 重跑后本条教程谱例 `403-最終鬼畜妹・一部声-mas` m060–m063 的跨界全部落在共享键上，**出张落点为 0**——即教程口径的"出张"（离开舒适击打区/跨半圈）比用户口径宽。本条保留教程原意，机检以 064 为准；谱例的归类待用户裁定（note 055）。
- **2026-09-20（官谱普查，agent 观察）**：本条「agent 理解」里的两条推断**被官谱证据挑战**，原文保留不改；另补一条两口径差距的量级。
  1. 「**强度可缩放**：出张本身不贵，贵的是出张的密度与跨度」——**拿到的是反向证据**：388 谱上出张密度**随定数下降**（13 字头段每千个手任务约 23 个 → 14.5 档约 11 个），而 `出张 / slide` 四个定数段几乎不变。**越难的谱越不靠出张堆难度**——差的那部分来自 tap 侧，高定数谱把 tap 收在自己半边、难度改用别的手段加。本条这一句**建议读作存疑**。（agent 观察，**存疑**：定数由整谱决定，这里只是相关不是因果。）
  2. 「**写谱时怎么制造**：几乎总是用一条长星星/长条占住一只手，把音符堆到那只手那一侧」——**只覆盖官谱的三分之一**（另一只手被星星钉住 20.8% + 被长条钉住 15.4% = 36.2%）。**最大的一类是"纯单点出张"（30.2%）**：没有任何占手，就是把一个 tap/hold 交给了对侧的手。本条这一句**建议读作"一种常见写法"而不是"几乎总是"**。
  3. **两口径的差距是系统性的，不是 `403` 那一段的特例**：教程口径（离开舒适击打区 / 跨中线）在 388 谱上标出的出张段是 064 口径的十几倍，逐落点看也是十倍量级，差集覆盖几乎全部 388 张谱。**「左手打右边」这句话在机检上没有区分度**——它是教学语汇，**机检一律以 064 为准**（本条 2026-09-19 的修订记录已经这么规定）。

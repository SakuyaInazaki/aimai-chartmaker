# 042 — 手法：狗刨（外键起手直接滑进内屏）

- **日期**：2026-09-19
- **要点**：狗刨 = **打外键的同时直接把手滑进内屏，一次处理两个音符**，两手交替；是玩家侧的熟练度手法，常用在纵连场合。**它不是一个配置，但会改变"一只手能吃下几个音"的账**。
- **详情**：

  ### 教程说明（转述）
  - `[05:32]`「**狗刨：需要吃熟练度的手法，打外键的同时直接滑向内屏，一次处理两个音符，两手交替，常用于纵连场合**」。
  - 教程这一节**没有谱例**——画面是真机手元录像（致谢 @Rspiritpit 友情演出），只演示手怎么动。

  ### 谱例
  **无**（教程未给谱面，本条不做谱例检索）。

  ### agent 理解
  - **机制**：外键（按键圈）和内屏（触摸屏）在物理上是相邻的两层；手掌拍到外键之后不抬起、顺势往内一推就触发内屏的 touch。所以"**外键 note + 紧随其后的内屏 note**"可以由**同一只手在一次动作里**吃掉。
  - **对制谱的含义**（agent 推断，存疑）：
    1. 006 收录的 MaiMuriDX「正规手法」模型里**没有这一条**——按那套定义，外键 Tap 与内屏 Touch 是两次独立按压，会各占一只手。狗刨的存在说明**该模型在"外键→内屏"这一对上是保守的**：模型判定需要两只手的场合，实际可能一只手就够。
    2. 因此**它只影响"能不能写"，不影响"必须怎么写"**：可以用它解释某些官方谱为什么敢在纵连旁边压 touch，但**不能反过来拿它当放宽 008/009 无理红线的理由**——它明确是"吃熟练度"的，不是所有玩家都会。
    3. 对**本项目当前的输出没有直接作用**：016 已确定 ST 谱不含 touch，没有内屏音符就谈不上狗刨。只有将来扩到 DX 谱才需要把它纳入手序成本核算。
  - **和纵连的关系**：教程说"常用于纵连场合"——019 里记的"绝大多数玩家把长纵连拆成一手外键、一手内屏"正是同一件事的配置侧描述，狗刨是它的手法侧名字。

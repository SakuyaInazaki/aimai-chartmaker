# 047 — 基础：乐理术语（BPM / 音符 / 小节 / 拍号）与音游的"X 分音符"

- **日期**：2026-09-19
- **要点**：星星篇的全部配置都按"**第几个四分音 / 第几个八分音**"来描述，因此先把 BPM、音符时值、小节、拍号这套口径钉死；**音游口语里的「三分音符/六分音符/十二分音符…」在乐理中不存在**，指的是三连音族，对应 simai 的 `{12}` `{24}` 一类分音。
- **详情**：

  ### 教程说明（转述）
  - `[00:10]` **BPM**：Beat Per Minute，全曲速度标记，一般以一个四分音符为一拍；**每拍秒数 = 60/BPM**；BPM 越高节奏越激烈；曲绘右下角标 BPM。
  - `[00:19]` **音符**：4 个四分音符合成全音符；把全音符等分 8 份＝八分音符（＝四分音符二等分）、等分 16 份＝十六分音符。乐理常见：全/二分/四分/八分/十六分/三十二分。
  - `[00:19]` **音游专有叫法**：「在音游交流中，把**三连音也称作 X 分音符，在乐理中没有这样的叫法**」——三分/六分/十二分/二十四分/四十八分/九十六分。
  - `[00:36]` **小节**：「从一个强拍到下一个强拍之间的部分」；人话＝一个小节由一定数量的拍子组成，结构由**拍号**标明。
  - `[00:36]` **拍号** `Y/X`：读法先读分母后读分子；**分母表示用几分音符当一拍**（一般四分音符），**分子表示每小节有多少拍**。4/4 拍＝一小节 4 个四分音符，多数乐曲如此；3/4（圣剑开头三声）、5/4、7/4（第七感开头七声）。
  - `[00:59]` **BPM 与拍号都不是恒定的**：谱面标注值只是初始值，游玩中会随乐曲变化。举例 **LastSamurai 标 BPM 57**，四分音与哒哒声对不上，「其实这里是 **BPM 171 的 3/4 拍**」。

  ### 谱例
  不适用（纯乐理讲解，无谱面演示）。

  ### agent 理解
  - **对本项目的直接口径**：`docs/audio-analysis.md` 的"每小节单一分音"量化、知识 015 的 `NPS = (分音分母/4) × BPM/60`、知识 031 的逐小节密度，全部建立在"**一小节＝4 个四分音符**"这个默认 4/4 假设上。教程点破的 **LastSamurai 案例说明该假设会失效**：标注 BPM 与真实拍感可以差 3 倍（57 × 3 = 171）。管线里 offset 反向校验若在某曲上稳定报"相位偏移 1/3 小节"，应先怀疑拍号不是 4/4，而不是先怀疑 BPM。（agent 推断，存疑）
  - **simai 侧的对应**：`{4}/{8}/{16}` 是乐理意义上的分音；`{12}/{24}` 是教程说的"音游口语三连族"。写谱时同一小节内换分音要显式写 `{x}`，这与教程"**一小节由拍号决定有几拍**"是同一件事的记法侧。
  - **为什么星星篇要先讲这个**：星星的**启动拍固定是 1 个四分音符**（知识 014），所以"四分音拍滑"和"八分音拍滑"是两种完全不同的手感——前者头与启动拍严丝合缝、后者启动拍落在下一个头之后。整期的术语（连续拍滑 049 / 夹键拍滑 053 / 海底谭错位 017）都靠"插在四分音之间的是几分音"来区分。
- **理由**：教程原文；与本项目既有的分音/NPS/密度口径一致，只补上"拍号可变、标注 BPM 可能是真实 BPM 的整数分之一"这一条新信息。

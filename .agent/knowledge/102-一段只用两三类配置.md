# 102 — **一段只用两三类**配置；侧边双押不是"万能转场"

> ⚠️ **本条为 agent 观察，未经用户确认。** 来源：同曲官谱抄谱对照（note 069）。n=1。

- **日期**：2026-09-20
- **要点**：知识 **073**「一张谱只用一部分配置、主料只有四五类」说的是**全谱**。
  我们把它执行成了"**每一段都把四五类摆齐**"——参考谱一段识别出 **2–4 类**，
  我们一段 **8–11 类**。另外：**侧边双押参考谱全谱 2 段、我们 12 段**，
  而且全是同一个 C 型等距轮转 `18/23/45/67`，被我们当成了段落转场的万能件。
- **详情**：

  | 段落 | 参考谱类数 | 我们类数 |
  |---|---:|---:|
  | A 段 | 4 | 4 |
  | hat/bass 推进段 | **2** | **11** |
  | B 段 / build | 3 | **7** |
  | ドロップ1 | 6 | **12** |
  | 薄 build | 3 | **9** |
  | ドロップ2 | 13 | 10 |

  **唯一一处参考谱类数更多的是最终 drop**——它把种类留给了最该"炸"的地方（知识 100）。

  **侧边双押**：知识 **030** 的铁律是"禁突然的侧边双押"，**不是"有引导就随便写"**。
  C 型等距轮转（`18/23/45/67`）自带引导，所以它在检查器里永远是干净的，
  于是它成了"写不出别的就摆一组"的默认动作。参考谱这一首只用了 2 段。

- **理由**：配置种类多 ≠ 内容丰富。一段里塞 11 类，意味着**每一类只出现一两小节**，
  听不出"这一段在做什么"；参考谱一段 2–3 类、每类占满整段，段落之间才有对比。
- **来源**：`docs/research/test-01-vs-reference.md` §3.4；同曲官谱抄谱对照（note 069）。
- **置信度**：**经验**（类数来自 `configs_hand` 逐段统计）/
  **存疑**（n=1；类数量的是检测器认得出名字的那些，不是谱师主动铺的手分工，见知识 075）
- **关联**：**073**（一张谱只用一部分配置）、**075**（配置有两层）、**074**（配置的段落分区）、
  **092**（分布不是处方）、**030**/**080**/**082**（侧边双押与引导）、**100**（段落升级换族）。

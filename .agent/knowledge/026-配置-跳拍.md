# 026 — 配置：跳拍（概念记录，待补充）

- **日期**：2026-09-10
- **要点**：跳拍 = **音符之间的空拍（逗号）不规则**的写法。正常交互是每个数字之间只有一个逗号；跳拍类似 `A，，B，C，，D，E，，F，` 这样。
- **详情**：
  - **基础形态（用户给的例子）**：
    - 正常交互：`A,B,C,D,E,F,`（每音之间一个逗号）；
    - 跳拍：`A，，B，C，，D，E，，F，`（空拍/逗号不规则分布）。
  - **不等同于小切分**：类似效果还可以来自——
    - **三连音空第二个音**；
    - **8 分附点接 16**。
  - **用户点名的实例**（仅点名，细节待补充）：
    - **Altale**（id 751，standard，BPM 90，MASTER 13.7，本地有谱）：**前十六后八**；
    - **羅刹骨骸**（結ンデ開イテ羅刹ト骸，id 986，standard，BPM 169，Re:MASTER 13.3 / MASTER 12.0，本地有 Re:MASTER 谱）：**三连音 + 休止**，又叫 **shuffle**。
  - **特征**：**比较难抓节奏**。

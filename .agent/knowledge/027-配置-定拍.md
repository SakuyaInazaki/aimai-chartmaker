# 027 — 配置：定拍

- **日期**：2026-09-10
- **要点**：定拍 = **一只手固定打拍子（节拍器），另一只手去处理别的配置**；表现形式广泛。
- **详情**：
  - **结构**：
    - **定拍手**：在同一个键上敲出**稳定的拍子**（常为连续的 8 分等），作用是节拍器/伴奏；
    - **另一只手**：在同一时间轴上处理**别的配置**——滑条、双押的另一半、变化音等，**可以带空拍（会歇）**。
  - **与轴交互的区别**（用户确认）：
    - **轴交互（BABCB）**：固定手是**交互结构本身的一部分**（每两音敲一次，与另一只手构成"成对推进"的 trill）；
    - **定拍**：固定手是**节拍器/伴奏**，另一只手处理的是**另一套配置**；密度上定拍手甚至可以是另一只手的两倍。
  - **实例**（* 为本地 `resource/official-chart/` 已核对）：
    - **カゲロウデイズ Re:MASTER***（id 141，200BPM，14.1）：定拍手 = **5，全程连续 8 分（≈6.67 次/秒），前后两部分速度相同**（前半 `{8}` 直接就是 8 分；后半 `{16}` 下 5 落在每隔一个 16 分上 = 仍是 8 分，只是分音标记变化，绝对速度不变）。另一只手：前半处理滑条 `4>1` 与 `{16}` 段里的 `4`；后半在 5 之间补 `6`（凑成 16 分交互）**但会歇**（有空拍）——**定拍手的 5 从不歇**。
      - 引文：`4>1[4:3]/5,5,5,5,...,{16}5,4,5,4,{8}5,5,`；`5,,5,6,5,6,5,6,5,,5,,5,,5,,5,6,5,6,5,,5,6,5,,5,6,5,,5,,`
    - **初音ミクの消失***（standard 版 id 1048，240BPM，MASTER 13.9；另有 DX 版 id 1049）：定拍手 = **2，每个 slot 都敲**（`{8}` @240 ≈ **8 次/秒单手持续输出**——该段强度点）；另一只手 `6`×4 后换 `8`×4；第二段同理（7 定拍，另一只手 `3`×4 → `1`×4）。
      - 引文：`26,2,26,2,26,2,26,2,28,2,28,2,28,2,2b/8b,,`；`37,7,37,7,37,7,37,7,17,7,17,7,17,7,1b/7b,,`
    - **群青シグナル**（**DX 谱**，id 975，206BPM，MASTER 13.8，本地无谱）：定拍手 = **2（每个 slot）**；另一只手处理滑条（`3-6`、`3q6`、`3q7`、`3q5^8`）与 `23` 双押的另一半。
      - 引文：`2/3-6[8:1],2,23,2,2/3-6[8:1],2,23,2,2/3q6[8:3],2,23,2,2,,`；`2/3-6[8:1],2,23,2,2/3q7[8:1],2,23,2,2/3q5^8[2:1],2,23,2,2,,`
- **理由**：定拍用一只手稳定输出节拍（支撑另一只手的复杂配置），是"把节奏交给一只手、把内容交给另一只手"的分工写法。

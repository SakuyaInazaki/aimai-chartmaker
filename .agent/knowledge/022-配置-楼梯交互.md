# 022 — 配置：楼梯交互

- **日期**：2026-09-10
- **要点**：楼梯交互 = **沿着同一个方向、每次位移只移到相邻键位**的交互配置（沿轴爬升或下降）；表现为**成对推进的"走向"**。
- **详情**：
  - **定义**：交互的一种；移动特征 = 方向一致 + 每步只走相邻键位。
  - **结构（按"走向"分组，不拆手）**：一组走向内**成对推进**——每一对（两手各一个音）整体只前进一个**相邻**位置，方向一致。走向内每对**可以重复**也可以不重复：
    - ERINNNNNN：每对重复两次才走一步（`1b,8,1,8` → `2,7,2,7` → …）；
    - LAMIA：每对不重复、直接走（`2,1` → `3,8` → `4,7` → `5,6`）。
  - **走向之间的衔接**：靠**"正常交互顺序下轮到的那只手"飞向下一组走向的起始位置**——能不能飞到，决定衔接是否成立。
    - LAMIA：走向 1 停在 6（轮到下一只手）→ 那只手从 5 **飞 3 格**到 8 开始走向 2；
    - ERINNNNNN：走向 1 停在 5 → 轮到的手从 4 到 3（相邻）开始走向 2。
  - **"同一方向"的范围**：指**走向内部**每对沿轴爬升或下降；不同走向之间方向可以相反——ERINNNNNN 走向 1 从 `{1,8}` 收到 `{4,5}`（下行），走向 2 从 `{3,4}` 张到 `{8,7}`（上行）。
  - **实例**：
    - **Help me, ERINNNNNN!!**（**DX 谱**，185BPM，MASTER 13.3，本地无谱）：走向 1 `1b,8,1,8,2,7,2,7,3,6,3,6,4,5,4,5,`；走向 2 `3b,4,3,4,2,5,2,5,1,6,1,6,8,7,8,7`；走向 3 `4b,5,4,5,3,6,3,6,2,7,2,7,1,8,1,8`。185BPM `{16}` ≈ 12.3 键/秒。（`1b`、`3b`、`2b`、`4b` 为走向开头的绝赞修饰。）
    - **LAMIA**（**DX 谱**，199BPM，MASTER 14.7，本地无谱）：走向 1 `2,1,3,8,4,7,5,6,`；走向 2 `8,7,1,6,2,5,3,4,`（引文后续 `3,4,2,5,1,6,8,7,1,8,2,1,3,8,4,7,5,6,` 未分组）。199BPM `{16}` ≈ 13.3 键/秒。
  - **区分点（用户预告，待补）**：本配置每一步都是"沿同一方向"爬升或下降——**与稍后要讲的配置相区分**，待该配置讲完后对照补记。
- **理由**：楼梯交互用"成对相邻推进"制造沿轴的连续位移感；走向内的重复次数与走向长度是自由变量，走向之间靠另一只手"飞"过去衔接。

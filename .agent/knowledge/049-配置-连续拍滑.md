# 049 — 配置：连续拍滑

- **日期**：2026-09-19
- **要点**：连续拍滑 = **匀拍的星星链**——每个四分音上落一个"**双押＝上一根星星的启动拍 tap + 下一根星星的头**"，打完这个双押的人里，**打 tap（○）的那只手立刻把上一根星星划掉**；两手一拍一换，交替"拍头 / 拍启动拍并滑"。教程称其为"**基础中基础配置**"。
- **详情**：

  ### agent 理解
  - **手级定义（四分音版）**：设第 n 个四分音的星星头在键 K_n。
    - **拍头手**＝本格打 ★（K_n）的那只手；
    - **划轨手**＝本格打 ○（tap K_{n-1}，即上一根的启动拍）的那只手，**打完立刻划上一根**；
    - **另一只手同时在做什么**：它就是拍头手，正在把下一根的头按下去；
    - **换手时机**：**每一个四分音换一次**——同一只手的循环是「拍头 → （一拍后）拍启动拍＋划 → 拍头 → …」，两手相位差 1 拍，所以宏观上看是"左右轮流滑星星"。
    - **特例**：当新头与上一根的启动拍**落在同一个键**时（Contrapasso m091 的 `1-3/8-4`），"打 ○"和"打 ★"合并成一次按压，该手**一次动作吃掉启动＋起新头**，链条不换手也能继续（agent 推断，存疑）。
  - **八分音版为什么更难（agent 推断，存疑）**：启动拍恒为 1 个四分音符（知识 014），头间距缩到八分后，**启动拍不再与下一个头对齐、而是与下下个头对齐**，于是同时在飞的星星从 1 根变成 2–3 根；玩家得记住"我现在该划的是两格之前那根"。这正是教程把八分音拍滑单独标号的原因。
  - **变速版"减速拍滑"（视频简介补充）**：UP 主在简介里点名「**ハウリング 为减速拍滑，BPM 158→154→146→131→181**」——即**同一串拍滑骨架下 BPM 逐级下降再猛然拉回**。含义（*agent 推断，存疑*）：启动拍 ＝ `60/BPM`，BPM 一变，**"头→启动"的等待时间也跟着变**，玩家背下来的节奏感会失效；最后那一跳 131→181 更是把等待时间砍掉 28%。**这是 049 骨架上唯一与"变速"耦合的强度钮**，也印证知识 047「BPM 不是恒定的」。
    ⚠️ **未能对应到具体示例**：本地 manifest 里唯一的 ハウリング 是 **DX MASTER 13.1 / BPM184**，与简介给的 BPM 串对不上；本片 OCR 丢名的示例里也没有 BPM158 的那首。**该曲未能定位**。

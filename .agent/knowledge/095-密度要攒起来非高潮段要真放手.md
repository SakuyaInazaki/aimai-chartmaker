# 095 — 密度要攒起来：非高潮段**真放手**，空小节与 ≤3 音的小节是正常写法

> ⚠️ **本条为 agent 观察，未经用户确认。** 来源：同曲官谱抄谱对照（note 069）。
> **n=1（一首曲子、一对谱）**，与 388 谱 / 160 首的跨谱分布冲突时以跨谱分布为准。

- **日期**：2026-09-20
- **要点**：note **总数**相同不等于密度曲线相同。同一首曲子、同一张小节网格上，
  参考谱 909 note / 我们 916 note，但参考谱把它们**攒成 13 个空小节 + 24 个 ≥12 音的小节**，
  我们摊成一条平线（3 个空小节 / 11 个 ≥12 音）。
  **高潮的冲击力是前面空出来的**，不是高潮里堆出来的。
- **详情**：

  | | 参考谱 | 我们 |
  |---|---:|---:|
  | note 总数 | 909（ST 可比视图） | 916 |
  | 逐小节峰值 / 有音小节均值 | 21 / 7.70 = **2.73** | 16 / 7.16 = 2.24 |
  | 空小节 | **13** | 3 |
  | 主段（205 段）里 ≤3 音的小节 | **11** | 2 |
  | 主段里 ≥12 音的小节 | **24** | 11 |

  **最极端的一处**：最终 drop 之前的六小节（m094–m099），音乐里鼓还在响——
  参考谱写了 **10 个 note**（m94/95/96 **三小节全空**，m97 只在**最后一拍**放一对双星 + 两个双押，
  m98 一对绝赞报点，m99 又空），我们写了 **37 个**（其中 5 条星星）。
  这一段的鼓候选有 17 个，参考谱踩了 **1** 个。

  **"留白"是有音也不写**，不是"没音才留"。我们上一轮把"留白"理解成
  "音频强度低的那两小节少写几个"，所以只留出 m098–m099、还各写了 2–3 个 note。

- **理由**：两张谱在**同一条时间轴、同一份音频**上，总数只差 7 个，
  所以差别只能来自分布。分布的差异直接对应用户的评价（"太烂了"）里最直观的一项。
- **来源**：`docs/research/test-01-vs-reference.md` §1 / §2.11 / §3.5；
  同曲官谱抄谱对照（note 069）。
- **置信度**：**经验**（数字为逐小节直接计数，可复算）/ **存疑**（n=1；参考谱是别处获取的抄谱
  不是官方数据；定数 DX 14 vs 我们 ST 13.6）
- **关联**：**031**（密度曲线：末段最强 / 休息小节只占 2.43%——本条是"休息靠低密段"的一个反例：
  这一首官谱确实写了 13 个空小节）、**001**（情绪走势）、**090**（真正低密的是 イントロ）、
  **092**（分布不是处方）、**093**（note 总数进区间 ≠ 难度到位——本条是同曲实证）。

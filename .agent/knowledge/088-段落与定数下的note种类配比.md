# 088 — 段落 × 定数下的 note 种类配比：官谱每一段大概有多少星星、多少长条

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径两套：① **388 个官方 ST 谱**（定数 13.0–14.5），按**曲内相对位置等分五段**与**变点五段**（`density.changepoint_segments`，`min_len_frac=0.10`）切；② **160 首**带段落标签的配对语料（标签来自音频管线，**未经人工听审**），按日式标签切。计数口径同 `chart_analysis.density.MeasureStat`：`slide` = 滑轨条数、`星头` = slide 起手的那个 tap（已含在 tap/break 里）、`each` = 参与同刻多押的 note 数。**数字只作注脚，不作判据。**

- **日期**：2026-09-20
- **要点**：知识 070/071 回答的是"升定数该动哪根旋钮"，**没有回答"这一段的 note 里该有多大比例是 slide / hold"**（`docs/research/e2e-trial-01.md` 的缺口 G1）。本条补上这块：官谱里
  ① **星星是副歌家族的东西**——サビ / 落ちサビ / ラスサビ 的 slide 占比最高、**イントロ 最低**，间奏居中；
  ② **hold 在副歌家族里最稀**，而且**四成以上的段落一根 hold 都没有**——长条不是"每段都要有"的东西；
  ③ **升定数时 slide 与 each 的占比一起往下走**，hold 基本不动，往上走的只有"每小节多少个 note"。
- **详情**：

  1. **星星的段落地盘**（160 首，段落级 slide 轨占 note 比，中位）：
     **サビ 0.167 ＞ ラスサビ 0.165 ＞ 落ちサビ 0.154 ＞ Bメロ 0.144 ＞ Aメロ 0.122 ＞ ドロップ 0.102 ≈ 間奏 0.101 ＞ イントロ 0.075 ＞ アウトロ 0.000**。
     换成"每小节几条滑轨"是 サビ 1.33 / 落ちサビ 1.27 / 間奏 0.88 / **イントロ 0.50 / アウトロ 0.00**。
  2. **★「前奏是星星最密的地方」不成立，正好相反**：イントロ 是全曲星星最稀的段落——
     **25% 的前奏一根星星都没有**（アウトロ 53%），而且**只有 21% 的曲子**其前奏的"每小节滑轨数"高于本曲均值。
     `e2e-trial-01` 那一首（ロストワンの号哭）官谱前奏 26 根星星，属于那 21% 里的个例，**不能当通则**。
     **間奏 也不是星星段**：只有 41% 的曲子其间奏星星密度高于本曲均值。
  3. **★ hold 在副歌家族里最稀，且"整段没有 hold"是常态**：段落级 hold 占比中位
     サビ 0.017 / 落ちサビ 0.015 / ラスサビ 0.022，明显低于 イントロ 0.038 与 Aメロ 0.035；
     **"这一段一根 hold 都没有"的段落占 26%–47%**（サビ 42%、Aメロ 36%、ラスサビ 26%）。
     副歌里 **slide 条数 ÷ hold 数 ≈ 4.4 : 1**（ラスサビ 3.1、落ちサビ 4.1），而 イントロ 只有 1.6 : 1、Aメロ 2.4 : 1。
     **读法**：副歌该多的是星星不是长条；长条更像前奏 / Aメロ 的东西。
  4. **★ 升定数：slide 与 each 一起降，hold 不动，只有密度升**（388 谱，谱级中位）：
     定数 13.0 档 → 14.2 档，note/小节 **7.3 → 10.7**；slide 占比 **0.146 → 0.106**；
     each note 占比 **0.591 → 0.486**；hold 占比 0.075 → 0.053（无单调趋势，13.6 档最低 0.044）。
     这与知识 **070** 的方向一致，本条给出它的**段落分解**：降得最狠的是 **サビ（0.161 → 0.061）**
     与 **間奏（0.162 → 0.074）**；**ドロップ 反着走（0.078 → 0.122）**——高定数谱把星星挪进了 drop。
  5. **曲内五段形状**（388 谱等分五段）：note/小节 单调上升（s1 → s5），**slide 占比在 s1 最低**
     （13.6–13.8 档 s1 0.075 vs s3–s5 0.131–0.141），**hold 占比在 s5 最低**（0.023）。
     即：**开头少星星多长条、结尾多星星少长条**。
  6. **写谱端怎么用**：段落规划的第 5 项（`docs/workflow-sop.md` §4）先定
     "这一段每小节几条滑轨、要不要 hold"，再铺 note；**不要把"星星占几成"当全曲一个数**——
     它在段落之间差两倍以上。

  **证据注脚（数字只作注脚）**：定数档 = `chart_matrix.LEVEL_BANDS` 的五档
  （13.0–13.2 / 13.3–13.5 / 13.6–13.8 / 13.9–14.1 / 14.2–14.5，n = 51 / 127 / 98 / 61 / 51）。
  ⚠️ `tools/chart_check/densitylayer.py` 的 `LEVEL_NOTEMIX` 用的是**另一种分档**
  （`floor(定数×2)/2` 的四档，n = 168 / 135 / 73 / 12），方向一致、数值略有出入，
  **两张表不要混着引**。388 谱谱级中位 slide 占比 0.146 / 0.142 / 0.127 / 0.103 / 0.106，
  hold 0.075 / 0.049 / 0.044 / 0.046 / 0.053，each 0.591 / 0.591 / 0.550 / 0.510 / 0.486，
  note/小节 7.32 / 8.21 / 8.80 / 10.16 / 10.65。160 首段落级样本量：間奏 362 / Aメロ 355 / サビ 215 /
  落ちサビ 183 / イントロ 155 / ドロップ 81 / Bメロ 58 / ラスサビ 46 / アウトロ 32 段。
  "整段没有星星"比例 イントロ 25.2% / 間奏 18.0% / ドロップ 18.5% / サビ 7.0% / 落ちサビ 7.7% / アウトロ 53.1%。

- **谱例**：
  - **前奏没有星星、靠纵连族撑**：`ぽっぴっぽー` MASTER（13.3）m001–m011，配置命中只有 子弹 / 纵连 / 跳拍，
    slide 0 条；`疾走あんさんぶる` MASTER（13.7）m002–m007 同形（纵连 5 小节、slide 0）。
  - **副歌星星多、长条为零**：`Mysterious Destiny` MASTER（13.3）サビ（bars 9–44）slide 113 条 / hold **0**，
    slide 占 note 的 50%；`Believe the Rainbow`（13.4）bars 37–54 slide 70 / hold 0。
  - **高定数把星星挪进 drop**：见 §4 的 ドロップ 反向趋势（14.2 档 0.122 vs 13.3 档 0.078）。

# 080 — 侧边双押在官方谱里并不罕见；铁律的主语是"突然"

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：388 个官方 ST 谱，侧边双押 = 两手的键集恰为 `{2,3}` 或 `{6,7}`（手序版判定，v0.3 分配器）。

- **日期**：2026-09-20
- **要点**：官方谱里**侧边双押一点都不罕见**（388 谱里数百次、出现在四成以上的谱面中）。所以知识 030 的铁律要读成「**禁止突然的侧边双押**」——**侧边双押本身不是禁区，"突然"才是**。
- **详情**：

  1. **用户给的三类引导**（知识 030 的 2026-09-19 补充）：**双押带过来**；**18/87/76/65/54**（相邻两组共享一个键、另一个键沿环逐格推进）；**18/23/45/67**（每组都是一对相邻键、沿环等距轮转）。
  2. **官方谱里还有一种常见形态（agent 观察，存疑）**：**手本来就已经在这两个键上**——临近位置出现过同键的音，手没走开，于是落到 `{2,3}`/`{6,7}` 上并不突兀。这是 agent 归纳出的引导型里命中最多的一种，**但它不在用户给的三个例子里，必须标存疑**。
  3. **"引导"的认知还不够，不足以变成机检规则**：按 agent 归纳的四种引导型去扫，**仍有将近一半的官方侧边双押判不出引导**。把它们当自动硬无理，等于宣称官方谱写了几百次铁律违例——**那不是谱面的问题，是 agent 归纳的引导形态覆盖不全**。因此工具里它已从"判决"降为**复核清单**（`side_double` / `side_double_unguided` 两个计数，由人来看）。
  4. **"突然"不要再去量化**（用户 2026-09-20：「正常写谱谁去特意算这些事情」）：早先用"位移 ≥N 格 / 间隔 ≤N ms"给"突然"标线的做法**已撤回**；那条线上的"388 官谱 0 次触发"也不再是独立证据——它是把阈值调到"官谱不触发"换来的。
  5. **配套事实**：侧边双押是**手序难度榜第二**（知识 078），也是**唯一随定数下降**的配置（知识 071）——**低定数谱反而更常写它**；段落上它**最偏爱 Bメロ**（知识 074）。

  **证据注脚**：388 谱 685 次 / 162 张谱（`{6,7}` 与 `{2,3}` 数量接近）；agent 归纳的引导型 A/B（共享键步进）155 · C（等距轮转）37 · D（临近同键）186，**判不出引导 307 次**；平均手序难度 0.551（全表第二）；ρ(定数, 出现率) = −0.067（4 个 BPM 档一致为负）；段落 lift Bメロ 1.51 > サビ 1.21。

- **理由**：知识 030 的铁律是用户讲授的硬规则；本条只是数清楚官方谱到底写了多少、以及 agent 目前能识别出多少引导——结论是**引导这一侧的认知还不足以写成规则**。

- **置信度**：**经验（agent 观察，n=388 谱，未经用户确认）**（"侧边双押不罕见"这条）/ **存疑**（① 四种引导型均为 agent 归纳，覆盖率未知——判不出的占近一半就是直接证据；② "临近位置已在这两键上"这一型不在用户给的例子里；③ 侧边双押的命中量依赖分配器给出的那套手序）。

# 044 — 手法：分页（把一个配置拆给两只手）

- **日期**：2026-09-19
- **要点**：分页 = **把一个配置（扫键、转圈、touch 群等）拆分成两只手来处理的手法**；通常由玩家自己决定用不用，**但部分谱面的谱师意图就是逼玩家必须分页**。

  ### agent 理解
  - **和 006 的"分页处理"是同一个词**：006 记的是**静态约定**——右手负责右半圈 1234、左手负责左半圈 5678，屏幕被分成两"页"。本条记的是**动态用法**——当**一个连续的形状横跨两页**（一整圈的扫键、一条绕过中线的长 slide、一大片 touch）时，就把它**在中线处切开**，两手各吃自己那一页。两者是同一概念的静态面与动态面。
  - **对制谱的约束意义**（这是它值得入库的原因，agent 推断，存疑）：
    1. **分割点必须落在两手都够得到的键上**。按 023 的可及范围，右手能到 `{5,4,3,2,1,8}`、左手能到 `{1,8,7,6,5,4}`，**交集是 1、8（顶）与 4、5（底）**。所以一个要求分页的形状，**切口应当落在 8↔1 或 4↔5 这两条缝上**；切在 2/3 或 6/7 一侧就会逼出出张甚至反手（043/037）。
    2. **"强制分页"是可以被设计出来的**：只要把一个连续形状写得跨度超过单手可及（>6 个键位，或整圈），玩家就没有不分页的选项。教程说"有让人强制使用的嫌疑"，说明社区把这当作**谱师意图的信号**，不是意外。
    3. **反过来，不该强制的地方不要强制**：分页会把一个形状的"一笔画"感觉打断（对照 007 的一笔画原则），在低难度段落里强制分页会显得突兀。
  - **与本项目的关系**：ST 谱不含 touch（016），所以"touch 群分页"用不上；但"扫键 / 转圈"这两类仍然适用——写整圈走位（如 033 死镰段的 tap 圈）时要意识到玩家一定在中线处换手，**换手点附近别塞需要同一只手连续处理的音**。

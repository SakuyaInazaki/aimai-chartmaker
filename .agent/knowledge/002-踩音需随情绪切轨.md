# 002 — 踩音需随情绪切轨，而非只踩最响音轨

- **日期**：2026-09-10（2026-09-11 修订）
- **要点**：谱面不能整曲只盯着一条音轨（如最响的鼓或人声）踩音；应根据歌曲情绪变化在不同音轨之间切换。
  ⚠️ **2026-09-11 修订**：8 首官方音频×官方谱的配对实测显示，"切轨"在**踩音重心**层面成立，
  在**骨架**层面不成立——官方谱的形态是**"鼓骨架 + 大量非鼓填充"**，不是"整段切到某一条非鼓轨"。
- **详情**：
  - 新手误区："哪个最响就一直踩哪个"。持续单音轨会让谱面死板、审美疲劳、无法体现强度变化。
  - 切轨模式示例（SPICY SWINGY STYLE Master 13 案例）：前奏"哪个响踩哪个"→ 主歌几乎不踩人声、跟小号/电吉他，小节尾偶混人声 → build 末尾切回人声为副歌铺垫 → **第一副歌全踩人声**（⚠️ 见下方修订：n=8 实测显示这条只在**人声主导型曲目**上成立，且判据是代理，**存疑待人工听审**）→ 间奏踩人声采样（强度靠位移提升）（✅ 被实测正面支持，见修订）→ 安排踩小号的休息段减压（⚠️ 实测样本不足，不支持也不反对）→ 第二副歌与第一副歌踩音相同但配置升级（单星星 → 双手星星）。
  - 休息段原则：高强度段落之间插入低强度音轨的休息段，稍微缓解玩家压力。
  - ⚠️ **官方谱的实际踩音重心分布（2026-09-11 实测，n=8，代理判据）**：
    逐段"命中率最高轨"= drums 70 段 / other 10 / vocals 3 / bass 2（共 85 段）——
    **鼓几乎永远是骨架**；但 **36.2% 的官方 note 不落在鼓上**、**18.6% 什么 stem 都不落**，
    所以"只踩鼓"同样是错的。正确的心智模型是 **骨架（鼓）+ 点缀（人声/器乐/贝斯）+ 自由发挥**。
- **理由**：歌曲情绪多变，切轨才能让谱面强度对上情绪变化；同时避免谱面僵化。
- **来源**：MMFC《谱面创作基础学 长篇指南》5.4 简易踩音解析；
  修订依据 = `docs/research/audio-chart-calibration.md` §5（8 首官方 mp3 × 官方谱配对实测）。
- **置信度**：**确信（教程共识）**：切轨的方向性主张（不要整曲只踩一条轨）；
  **存疑（"副歌全踩人声"，n=8 代理实测）**：该条只在人声主导型曲目上被观察到，待人工听审复核。
- **关联**：条目 001、003、**005**（候选池只用一半）、**031**、**032（官方谱踩音归因实测）**；
  `docs/audio-analysis.md` §5.2、`tools/audio_analysis/stemplan.py`。

## 修订记录

- **2026-09-11**：依据 8 首官方 ST 曲包（官方 mp3 + 官方 `&inote_5`）的配对标定
  （`docs/research/audio-chart-calibration.md` §5；工具 `tools/calibration/`），对本条目作如下修订
  （**原文一律保留，只加 ⚠️ 标注**）：

  1. **官方谱的形态 = "鼓骨架 + 大量非鼓填充"**：drums 命中率 **0.607**（lift 2.64，各 stem 最高）；
     **不落鼓的 note 占 36.2%**、**只落鼓的仅 28.1%**、**只落人声的仅 3.2%**、
     **18.6% 什么 stem 都不落**（谱师自由发挥 / 装饰音 / onset 漏检，三者无法区分）。
     → **"切轨"在踩音重心层面成立，在骨架层面不成立**；把"主踩音轨"做成一段一个单值是模型错误
     （`stemplan.py` 已于 2026-09-11 改为"骨架轨 + 点缀轨 + 估计占比"）。
  2. **「副歌全踩人声」降为条件性 + 存疑**：14 个副歌段里**只有 2 段** vocals 命中最高（12 段是 drums）；
     副歌整体 drums recall 0.583 vs vocals 0.200；`final_chorus` 的 vocals lift 0.97（= 随机水平）。
     **唯一正例是 幻想のサテライト**（东方人声 arrange，副歌 vocals 0.544 > drums 0.392）。
     → 规则改为**条件触发**：仅在**人声主导型曲目**（人声 onset 密度接近或超过鼓、voiced 高）上成立。
     ⚠️ **存疑，待人工听审复核**：本结论的 ground truth 不是谱师访谈，而是"官方 note 是否落在
     Demucs vocals 轨的 librosa onset ±30 ms 内"这个**代理**；人声 onset 检测是全管线最弱环节之一
     （vocals 轨混 lead synth、鼓与人声重合无法区分、人声 onset 数本身构成命中率天花板）。
     **不得据此认为 MMFC 5.4-4 是错的**——只能说"n=8 的代理实测没有支持它作为无条件规则"。
  3. **「间奏踩人声采样」被正面支持**：`interlude` 是 vocals **precision 最高（0.715）**、
     **lift 最高（3.18，超过 drums 的 3.11）**的段落类型——间奏里人声 onset 虽少，
     **一旦出现就几乎必被官方采用**。→ 该规则成立且已在工具里加强。
  4. **「休息段踩次响轨」数据不支持也不反对**：`quiet_chorus` 一致率 0.62、样本仅 13 段 → **维持原文，标存疑**。
  5. **「前奏哪个响踩哪个」的判据要换**：intro 段一致率 0.75 看似高，但**它对的原因是"最响的恰好也是鼓"**；
     lift 口径下 intro 的最高 lift 是 `other`(5.08) 而非 drums(4.39) → 判据应从**能量占比**换成
     **onset 匹配倾向/落格率**（工具已改）。
  - ⚠️ **口径边界**：全部数字来自 **n=8**（定数 13.5–14.5、BPM 128–230、全 ST MASTER），
    且为代理判据。与 388 谱全量统计（知识 031）冲突时以 388 谱为准；本次修订不改变
    "踩音要随情绪变化、不要整曲只踩一条轨"这一主张本身。

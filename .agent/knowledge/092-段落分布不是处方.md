# 092 — 段落级的分布（lift / 平均）**不是处方**：单曲整段与它相反是常态

> ⚠️ **本条为 agent 观察，未经用户确认。** 来源：160 首配对语料的逐曲复核 +
> `docs/research/e2e-trial-01.md` 的端到端试写。

- **日期**：2026-09-20
- **要点**：知识 **074**（段落 × 配置 lift）、**088**（段落 × note 种类配比）、**090**（星星族段落用法）
  给的都是 **160 首的平均分布**。它们回答的是"官谱在这类段落**写过**什么"，
  **不回答"这一首的这一段**该写什么"。**单曲整段与平均相反是常态，不是例外。**
- **详情**：

  1. **逐曲复核的三个数**（160 首）：
     - **イントロ** 的"每小节滑轨数"高于本曲均值的曲子占 **21%**——也就是说，
       "前奏星星最稀"（知识 088）说的是七成八的曲子，剩下两成一整段反着来；
     - **間奏** 高于本曲均值的占 **41%**——几乎是掷硬币；
     - **落ちサビ** 的密度 ≥ 本曲均值的占 **49%**——**完全是掷硬币**（知识 090 §6）。
  2. **lift 高 ≠ 常见**：知识 074 说「イントロ 归纵连族」（纵连 lift 2.09 / 长纵连 3.13），
     但**只有 33% 的曲子在前奏里真的写了纵连族**。
     lift 说的是"比别处更容易出现"，**不是"这里通常有"**——两件事差很远。
  3. **试写踩到的坑**（n=1）：`e2e-trial-01` 按 074 把前奏写成纵连族、把間奏写成几何配置，
     而那一首官谱的前奏与間奏写的**都是星星族**，且間奏**一类几何都没有**。
     同一轮里管线把 43–68 小节标成 `落ちサビ` + `rest=True`，试写照着写成减压段（6.7 note/小节），
     官谱那里是 **11.1 note/小节**（和副歌一样密）。
  4. **正确用法**：把 074 / 088 / 090 当**候选清单与先验**——
     "官谱在这类段落写过这些，先从这几样里挑"；
     **实际写什么由这一首的音乐决定**（知识 002/069：采音跟着音乐走）。
     段与段的**相对高低**跟强度曲线走，**绝对值**跟定数走（知识 031 §7）。
  5. **对报告与工具的要求**：任何引用段落 lift 的地方都要带上"这是分布"的口径说明；
     检查器的段落对照一律是**提示**，"一个都没命中"**不是错误**（`tools/chart_check/configlayer.py` 已如此）。

- **理由**：三个逐曲比例（21% / 41% / 49%）是直接计数，不依赖任何 agent 评分；
  试写那一首提供了"整段相反"的可复现个案。
- **来源**：`docs/research/e2e-trial-01.md` §3.5 / §4（G2）/ §6 草案 089；本轮 160 首逐曲复核。
- **置信度**：**经验（agent 观察，n=160 首逐曲比例）** / **存疑**
  （① 段落标签是音频管线产物、未经听审，"整段相反"里有一部分可能是**标签标错**而不是谱师反着写；
  ② 试写个案 n=1）。
- **关联**：知识 **074**（段落分区）、**088**、**090**、**069**（采音跟着音乐走）、
  **031 §7**（定数 → NPS 锚）、**073**（挑一小撮）；`docs/workflow-sop.md` §3/§4。

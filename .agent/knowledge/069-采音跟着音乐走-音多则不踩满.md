# 069 — 采音跟着音乐走：音轨给的音越多，谱面越不踩满

> ⚠️ **本条为 agent 观察，未经用户确认。** 口径：160 首官方 ST 曲包 13 535 个小节；"这一小节音轨给了几个音""这一小节曲内强度在哪一档"两个分档都是 **agent 操作化**（按曲内分位切），**不是谱师会去算的量**——本条只取它们给出的**定性方向**。

- **日期**：2026-09-20
- **要点**：采音是**跟着音乐走**的：同样的情绪强度下，**目标音轨这一小节给的音越多，官方谱越倾向于换成手型预定的几何配置、只踩其中一部分**；**音给得少而情绪已经到顶时，官方谱反而把每一下都写成双押并全部踩掉**。谱面密度跟着强度走，但**跟不上音乐事件密度**——音一密，谱面立刻从"踩满"切到"只踩一部分"。
- **详情**：

  1. **音多 × 情绪高** → 官方谱换**几何手型**（逆楼梯/方向盘、散点、三角交互一类），并**只踩一部分**。即"音多"不是"把音都写进去"的理由。
  2. **音少 × 情绪高** → 官方谱把**每一下都写成双押**（侧边双押、连续双押、双押纵），并且**基本全踩**——这一格是全表踩得最满的。**情绪靠 note 种类顶上去，不靠多写音。**
  3. **音中等 × 情绪低**（前奏、间奏一类） → 官方谱放**手不用动的东西**（长纵连、散点、普通交互），采音也随之松。
  4. **音多 × 情绪低** → 轴交互、楼梯交互、大宇宙，并且是全表**踩得最省**的一格。
  5. **横跨全表的一条**：音轨给的音从少到多，官方谱"用掉的音 ÷ 可用的音"是**单调下降**的。
  6. 与知识 002 的关系：002 管**踩哪条轨**（随情绪切轨），本条管**踩多少**；两者互不替代。与知识 005 的关系：005 说"采音要简"，本条给出"简在什么时候最明显"——音越密越简。

  **证据注脚**：密×高强度格 方向盘 lift 4.52 / 散点 2.98 / 三角 2.91，coverage 0.597；稀×高强度格 侧边双押 1.50 / 连续双押 1.19，coverage 0.760（全矩阵最高）；中×低强度格 长纵连 2.43 / 散点 1.38 / 普通交互 1.27；密×低强度格 轴 2.39 / 楼梯 2.18 / 大宇宙 1.88，coverage 0.515（全矩阵最低）；官方时间槽 ÷ 候选池 从稀档 1.55–1.62 降到密档 0.67–0.84；每格 n = 315–2 582。

- **理由**：用户裁定「**采音肯定是根据音乐来踩的啊，不能光根据 bpm 来**」（2026-09-19）之后，采音判据改成只看**目标音轨这一小节实际发出的音**，本条是该判据下 160 首官方谱的实测方向。
- **来源**：`docs/research/config-difficulty-intensity.md` §4（密度 × 强度矩阵）、§1.9；`docs/research/sampling-mode-study.md` §10.4b。
- **置信度**：**经验（agent 观察，n=160 首 / 13 535 小节，未经用户确认）** / **存疑**（① "稀/中/密"与"低/中/高强度"的分档是 agent 按曲内分位切的，格与格的边界没有谱师依据；② "密 × 低强度"格样本最小；③ 强度曲线与段落标签都是音频管线产物，未经人工听审；④ 配置识别按手序版重跑过，但该矩阵本身跑的是键位版检测器，方向可引用、数值待重跑）。

# 028 — 配置：子弹

- **日期**：2026-09-10
- **要点**：子弹 = **同一个键在短时间内被打两次**（两个音符叠在同一个键上）。
- **详情**：
  - **两种载体**：
    1. **直接写法**：同键相邻两音（`8,8`、`7,7`）——ATLAS RUSH 里"塞进星星头与启动拍之间间隙的两个快速 tap"即此类；
    2. **等价效果**：**短双押串**（`12,12`、`78,78`、`13,13`、`68,68`）——每个键在 2 个 slot 内各出现两遍（如 `12,12`：键 1 在槽 1、3；键 2 在槽 2、4）。
  - **实测**（**id 666 Revive The Rave MAS**，standard，165BPM，MASTER 13.8，本地有谱）：
    - **短双押串**：每个键都在 2 个 slot 内出现两遍 ✅；
    - **长双押串**（`24,35,46,57`）：只有**部分**键重复（4、5 各两遍，间隔 3 个 slot），2/3/6/7 只出现一次——**不是每键两遍**；
    - **全谱统计**（936 次键出现）：同键"下一次出现"的间隔分布——间隔 1：15%、间隔 2：16%、间隔 3：9%、间隔 4：8%，**间隔 ≤4 合计 48%**——"同键短时间重复"是该谱的底色。
  - **与纵连的关系**：纵连（知识 019）的门槛是**同键 ≥3 音**；正好 **2 音**就是子弹——填在纵连门槛之下的空位。
  - **使用注意**（早前 ATLAS RUSH 实例）：把子弹塞进**错位**的间隙（星星头与启动拍之间）会造成**手感很差、被玩家诟病**——此类用法需谨慎。
- **理由**：子弹的本质是"同一键短时间两次"，两种记谱方式（同键相邻两音 / 短双押串）都能制造这个效果。

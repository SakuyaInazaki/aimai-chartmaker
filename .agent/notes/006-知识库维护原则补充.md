# 006 — 知识库维护原则补充：历史认知可被推翻

- **日期**：2026-09-10
- **变更**：
  1. `.agent/knowledge/README.md` 顶部新增警示段："知识条目不是金科玉律"，并新增**推翻规则**（与旧条目冲突时以新证据为准，修订/废弃并写依据）；使用规则重排为 7 条，新增"批判性读取""允许推翻"两条。
  2. `AGENT.md` 工作准则第 8 条补充对应要求。
- **理由**：用户指出——"在长期维护知识库的过程中，时常可能会出现推翻之前想法的情况，请注意不能以全部历史认知作为金科玉律"。即：知识库是活文档，历史条目只是"当前最佳认知"，需带置信度、可被证据推翻；否则知识库会退化为固化错误的教条。
- **来源**：用户指令（2026-09-10 会话）。
- **关联**：`.agent/knowledge/README.md`；`AGENT.md` 准则 8；笔记 003（知识库建立）。

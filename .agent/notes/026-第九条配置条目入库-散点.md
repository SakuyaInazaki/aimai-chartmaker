# 026 — 制谱经验记录：第九条配置条目（散点）

- **日期**：2026-09-10
- **变更**：
  1. 新增知识条目 **025（配置：散点）**。
  2. 知识库索引更新（025 入库）。
- **理由**：用户讲授散点（无特定表现形式、分散/难读的单点配置）并确认后记录。

## 条目要点备忘

- 定义：无特定表现形式；排键分散或规律难辨的单点配置；**写法上无硬性结构约束**。
- 实测画像（GIGANTØMAKHIA 引文）：跨全部 8 键、步进混合（±1/±2/±3/−4）、无固定对位、全为单点、零散带绝赞。
- 与其他配置的关系：不满足楼梯/方向盘/大宇宙的任何几何条件——"看不出规律"即其量化特征。
- 难度来源：读谱与预判（无法套路化）。
- 实例：GIGANTØMAKHIA（DX 谱，id 763，190BPM，MASTER 14.7，本地无谱）。
- 备注：如需该谱原文，可单曲补抓（站点有数据，但其定数 14.7 超出 13.0–14.5 的批抓范围）。

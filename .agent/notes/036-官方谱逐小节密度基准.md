## 理由

音频分析管线（`docs/audio-analysis.md` L3/L4）要把"强度曲线"映射成"谱面密度"，
但这个映射此前**没有任何 ground truth**——知识 001 的量化模板 `T=[0.20,0.45,0.30,1.00,0.10]`
自己就标着"待标定"。本任务用 388 个官方 ST 谱把密度侧标定出来，同时给解析器建立
可复现的计数校验基线。

## 主要结果

- **解析覆盖率 387/388 = 99.74%**；唯一失败者 `66-ワールズエンド・ダンスホール-mas`
  是抓取污染（正文混入 `ページ名またはURL`），建议重抓。
- **与 manifest 官方计数对账：note 总数完全一致 376/387 = 97.16%，\|Δ\| ≤ 3 占 100%**；
  `touch` 分项 387/387 全为 0，**实证 ST 谱确实不含 touch**。
- **知识 004 独立复核通过**：四个定数档的 note 总数均值误差 ≤ 4%，p10–p90 高度重合。
- **新增绝对量级基准**：note/小节 全库均值 8.96（13.0 档 8.03 / 13.5 档 9.15 / 14.0 档 10.54）；
  峰值小节 / 全曲均值 ≈ 2.06 倍；小节数中位 85。
- **知识 001 的五段模板检验结论（本任务核心）**：
  - **定性形状前四段被验证**：结构对齐五段的段序是 `s1 < s3 < s2 < s4`，与 T 的
    「弱 → 较强 → 较弱 → 强」完全一致（s3 的"回落"真实存在，但等分切法会抹平它）；
  - **第五段"渐弱淡出"被推翻**：实测 s5 = 0.817 是五段最高，曲末 10% 密度是全曲均值的
    1.084 倍，24.2% 的谱把高潮段放在最后 10%；
  - **幅度被严重高估**：实测 `T_density = [0.62, 0.77, 0.72, 0.78, 0.82]`（结构对齐口径，
    95% CI 见报告），动态范围只有 T 的约 1/4.5；
  - **需要补"密度地板"**：归一密度 p10 = 0.264、p50 = 0.514，段落尺度地板 ≈ 0.62。
- **高潮位置**：4 小节滑动均值口径下中位 0.720，74.7% 在后半程，最大众数是 [0.9,1.0) 占 24.2%。
- **第二副歌**：79.6% 的谱后半程高密段强于前半程，中位提升约 12%（**只是密度维度**）。
- **休息段**：64.9% 的谱有休息小节但只占全曲 2.43%；"高密-低密-高密"三明治结构 61.9% 的谱至少出现一次；
  每谱约 7 个密度台阶 ≈ 平均每 12 小节换一次密度基调。
- **SPICY SWINGY STYLE 个案**：变点检测自动找出的 4 个边界（小节 33/49/82/98）
  精确对应知识 002 描述的「间奏 / 第一副歌 / 过渡 / 第二副歌」；M48 是全曲唯一 0-note 空小节，
  紧接 M49 全曲峰值。第二副歌密度只比第一副歌高 5.1%，**印证知识 002 的"踩音相同、配置升级"**。
- **方法学坑（已写进工具与报告）**：变点检测不加最小段长约束时，37.4% 的谱第 5 段会短于全曲 5%，
  会凭空造出"尾部渐弱"的假象。全部结构对齐结果均带 `min_len_frac=0.10`。

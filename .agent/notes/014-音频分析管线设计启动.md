# 014 — 音频分析管线设计启动：攻克"AI 理解歌曲结构"问题

- **日期**：2026-09-10
- **变更**：
  1. 新增 `docs/audio-analysis.md` v0.1 设计初稿：把"听歌判断副歌/高潮/采什么音"拆成四层管线（L1 节拍层 → L2 音轨层 → L3 结构层 → L4 规划层）。
  2. 启动 SOTA 调研子代理（节拍检测/声源分离/结构分段/高潮检测/prior art 五个方向）。
- **理由**：用户提出核心攻坚目标——"如何让 ai 也能通过分析 mp3 来了解哪里是副歌、哪里是高潮、要采什么音采鼓点还是采人声"，并指出这与 MMFC 教程第五章强度/踩音/配置理论相吻合。设计原则：① LLM 不"听"原始音频，只消费结构化特征（延续准则 8 的上下文可靠性顾虑）；② 用户提供的 BPM/offset/变速点优先于自动检测；③ 每层输出可人工复核。
- **来源**：用户指令（2026-09-10 会话）。
- **关联**：`docs/audio-analysis.md`；知识库 001/002/003/004/005/012-016；`resource/official-chart/`（388 谱可作对照数据）。

## 管线要点备忘

- **L1 节拍层**：BPM/拍点/下拍（小节对齐）→ 谱面时间轴；用户提供 BPM+offset 为最高优先级覆盖；`&first = offset/1000`。
- **L2 音轨层**：声源分离（鼓/人声/贝斯/其他 4 stems）→ 各 stem onset 流 → 踩音候选池（鼓点=鼓 stem onset、人声=人声 stem onset/音高）。
- **L3 结构层**：SSM/深度学习分段（intro/verse/pre-chorus/chorus/bridge/outro）+ 重复段=副歌 + 能量强度曲线 → 高潮定位（chorus ∩ 能量峰值）。
- **L4 规划层**：结构×强度×音轨 → 逐段踩音计划（charting_plan.json），规则来自知识 001/002/003（强度走势模板、切轨模板、密度/配置升级），输出样例与知识 002 的 SPICY SWINGY STYLE 模板对应。
- **待调研合并**：各层工具选型对比表、prior art（MaiChartGen 等）、变速检测方案。

- **理由 / 关键发现**：

  1. **「空音」在社区里是反义词，这是必须换的硬理由（不只是"换个好听的说法"）。**
     萌娘百科《音乐游戏/用语》词条 **采空音**：「指原本音乐中并没有音的地方却在谱面的
     对应位置塞入了音符的情况」；Deemo 谱评也写「明显 zure/空音就直接乘以 70%」。
     即：**社区的空音 = 谱面多写了音；用户的空音 = 谱面少写了音。**
     继续用它，本项目报告在社区读者眼里结论正好反过来。
     （顺带：本工具的 `extra` 字段量的才是社区说的采空音。）

  2. **"只踩一部分"社区没有固定名词。**`半采 / 全采 / 满采 / 采满 / 减采 / 抽采 /
     隔一个采 / 采一半` 在 47 篇语料里**逐词 grep 全 0 命中**。谱师描述这件事用的是
     **动作**：舍音、采音取舍、简、删到不能再删、省去、规律性减少点击。
     选「舍音」是**取最接近的谱师用词**，不是"社区管这个叫舍音"——报告 §4.3/§5.1 已写明，
     退路是直接用描述性说法「只踩一部分」。

  3. **「全踩」只在 MMFC 手册里出现（2 处），B 站 47 篇语料 0 命中。**
     它可靠但属**手册用语**，口头行话程度不确定，报告 §5.2 已标注。

  4. **「加花」不是音游制谱社区词。**语料里只出现 1 次（Malody 谱评 cv45820623），
     且意思是"加点有难度的花样"，不是"踩音轨里没有的音"。对应的社区词是
     **采空音 / 插空音 / dump / 塞 / 荡谱**。

  5. **顺带确认本项目已有的几个词都是社区词，无需改**：`采音 ≡ 踩音`（两种写法并用）、
     `切轨`（MMFC 5.4，知识 002）、`混 fr / 混フレ`（萌娘百科，知识 045）、
     `哪个响踩哪个`（MMFC 5.4，知识 002）。
     `空拍` 是 **simai 语法**的空逗号（MMFC 4.3），**不是采音术语**，不得借用。

  6. **换词没有把量化问题重新变成可问的问题。** 切点仍是
     `sampling.THRESHOLDS`（`full_lo=0.65` / `empty_hi=0.35`）的**工具内部诊断口径**，
     不向用户索取、不列为待裁定项、不写进知识库（note 056 的总口径不变）。
     而且社区**并不把这三个词当互斥分类用**——三分类本身是 agent 的操作化，
     这一条已写进 `sampling.py` 的 docstring、`classify()` 注释、报告 §4.3 与 §11.3。

## 知识条目草案（**不写入** `.agent/knowledge/`，等用户裁定）

### 草案 NNN — 采音方式的社区用词：全踩 / 舍音 / 留白；「空音」是反义词

- **日期**：2026-09-20
- **要点**：描述"目标音轨的音被踩了多少"时，中文制谱社区的说法是——
  **全踩**（＋音轨名，把这条轨的音基本都踩上）、**舍音**（只踩一部分、舍掉另一部分）、
  **留白**（音乐有音而谱面故意不踩；失误版叫**漏音 / 漏采**）。
  谱面写了音轨里没有的音叫 **采空音 / 插空音**（4K 圈：dump / 塞 / 荡谱 / 补拍）。
  ⚠️ **「空音」在社区里指的是后者**（谱面多写了音），与"留白"**方向相反**，不可混用。
- **详情**：
  - **采音 ≡ 踩音**，两种写法社区并用（MMFC 第二章写"采音"、第五章写"踩音"）。
  - **「只踩一部分」没有固定名词**：社区说的是动作——舍音、采音取舍、"简"、
    "删到不能再删"、省去、规律性减少点击；Arcaea 圈把"只采显眼的音"叫**主高**。
    `半采 / 全采 / 满采 / 减采 / 抽采` 等**都不是社区词**。
  - **「加花」不是音游制谱词**（民乐/爵士术语）；社区对应词是采空音 / dump / 塞。
  - **「空拍」是 simai 语法的空逗号**（MMFC 4.3），不是采音术语。
  - 「严格采音 / Accurate」（4K 圈）说的是**谱面→音乐**方向（不许有找不到出处的 note），
    与「全踩」（音乐→谱面）方向相反，**不可互换**。
- **理由**：社区不是按"三档互斥分类"在说这件事，所以术语只能一个个对到概念上，
  不能整体套用；用错方向的词（空音）会让结论被读反。
- **来源**：`docs/research/sampling-terminology-survey.md`（MMFC 5.3/5.4；
  萌娘百科《音乐游戏/用语》；B 站 cv20314862 / cv20421237 / cv19169007 / cv50946813 /
  cv29114784 / cv5509401 / cv42785575 / cv11688050 / cv14147817 / cv43894622 /
  cv16401536 / cv51689272 / cv52716162 / cv45820623）。
- **置信度**：**确信**（「空音」是反义词、「采音≡踩音」、「加花/半采/全采不是社区词」——
  均有百科级或多来源证据）/
  **经验**（「全踩」只有 MMFC 一个来源；「舍音」是最接近的用词而非公认的分类名）。
- **关联**：知识 002（切轨）、005（采音要简）、045（混 fr）；
  工具 `tools/calibration/sampling.py`。

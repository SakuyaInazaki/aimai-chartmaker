# 050 — 左右手分配器与手序合理性

- **日期**：2026-09-19
- **来源**：**用户原话（两条）**——
  ① 「你应该还要有左右手的意识啊，针对一张谱面要设计的谱面，左右手分别怎么打，
  这会涉及到谱面的合理性这是个很严重的问题。」
  ② 「不可能只有定拍、错位、大宇宙是按手定义的啊，**任何配置都应该按手定义**吧。」
- **关联**：知识 **006**（分页处理与正规手法）、**007**（换手定式与一笔画）、**008–012**（无理五类与阈值）、
  **014**（启动拍）、**015**（速度红线）、**023**（可及范围）、**017–030**（配置定义）、
  **043**（出张）、**047–063**（星星篇，另一条线同日入库）；
  note **047**（配置识别器与配置硬度分）、note **048**（配置术语第二期）、note **049**（采音定义修正）；
  `docs/research/config-terms-ep3.md` §4 / §6（星星篇给本线的手级定义总表与 5 条建议）。

## 理由

在此之前，项目里**没有"手"这个对象**：`configs.py` 的配置识别、硬度分、无理代理检测全部只看
**键位序列**。这直接导致 AGENT.md 的两条硬性验收标准无法计算——

- 标准 2「人类可玩」：多押/占用冲突这类"需要三只手"的形态无从判定；
- 标准 3「手序合理」：左右手交替、可及范围、换手定式全都没有模型。

用户第二条话进一步指出：17–30 这些配置**本质上都是手的模式**
（交互＝左右交替、纵连＝同键连打的手法、轴/楼梯/方向盘/大宇宙＝两手各自的键序与配合、
子弹/单双/连续双押＝双手时序），只按键位序列识别是错的。因此本轮的交付被定位成
**手序基础设施**：先做分配器，再让配置识别在它的输出之上重写。

### 主要结论（全部写进报告，**未经用户确认**）

1. **官方谱基线达标**：388 谱 272 207 个手任务，绝对无理 146（**0.54‰**）、硬无理 120。
   其中 136 次"占用冲突"是**模型缺口**（重叠/汇流轨道一手兼划未实现），
   真正指向谱面的只有 5 次多押 + 5 次绝对撞尾（后者疑似作谱失误，已逐条列出待用户裁定）。
2. **★ 六轮阈值校准，首轮 6 569 → 最终 146**。每轮都是"先怀疑模型"：
   ① 星链里**星星头也要并入拍划**（4 455 冲突 + 1 735 多押 → 136 + 5）；
   ② 相邻键快串是**扫键**（知识 015/036），硬下界与距离无关；
   ③ **一笔画续划不吃 1 帧松手延迟**（知识 007）；
   ④ 同头多 slide（`*`）视作一次划动（agent 推断，存疑）；
   ⑤ Hold 尾放宽 1 帧 + 另立 `Hold尾多押` 硬标记（知识 012 原话）；
   ⑥ 三处阈值按官谱校准。
3. **★ 知识 010 的"同头（同侧）"应读作"同一个判定键"、窗口锚在启动拍**。
   四种读法全量 A/B：832 / 279 / 243 / **13** 次硬外键。官方谱不会系统性写硬无理 → 取最后一种
   （与 MiaCode 规则名 `SlideHeadTap` 一致）。**已列为知识 010 的修订建议。**
4. **定式复现 15/18**：017 错位（逐音全对）、019 纵连"拆"、021 轴、023 方向盘、024 大宇宙
   （与条目表格逐字一致）、027 定拍、028/029/030、007 定式 3 死镰段；
   星星篇 **057 一笔画 3/3**、049 连续拍滑、053 夹键拍滑、060 同起点拍滑、061 三叉戟 4/4、
   050 双压连续拍滑、058 挥手段全部复现。
   ⚠️ **035 如龙段部分**、**036 二连扫不符**（条目自承"扫"是执行层）、
   **062 鼓动段不一致**——知识 007「末尾半边定手」与知识 062「划轨手＝拍头手」在此冲突，
   模型按 007 选了换手，**这两条规则的优先级需用户裁定**。
5. **扰动对照分离度充分**：镜像 10% note → 绝对无理 ×14.4；each 改叠键 → ×6.3；
   slide 全反向 → ×74.7（Cohen d 1.40）。
6. **★ 手序难度与配置硬度基本正交**：逐小节 ρ = 0.103、逐谱 ρ = 0.180；
   与定数 ρ 仅 0.078（配置硬度与定数是 0.369），与密度 −0.054。
   **两个分数量的是不同的轴**——配置硬度量体力/精度负担，手序难度量手的调度余量，应并存。
7. **★ 几何越规整的配置手序越省心**：最费手序的是 **侧边双押 0.515**（独立复现了知识 030 的铁律）
   与 **错位 0.444**（呼应知识 003"错位最强"）；最省手序的是 **方向盘 0.205 / 大宇宙 0.227**——
   而现有 `CONFIG_WEIGHT` 给大宇宙 1.00（最高）。**两个榜几乎相反**。
8. 起手奇偶：整谱层面几乎自由（两种起手的难度差中位数 0.4%，无理数 100% 相同）；
   知识 060 说的**段内**起手枚举**尚未实现**。

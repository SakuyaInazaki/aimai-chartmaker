## 方法上的一个收获（值得后续复用）

Majdata 录像顶栏的**达成率**可以当"进度条"用：按 maimai 分项权重（tap/touch 1、hold 2、slide 3、break 5）
对谱面做累计，就能把"某一帧的达成率"**反查成小节号**。本轮靠它把死镰段、如龙段、出张三段**精确定位到小节**，
并交叉验证了反手段（屏幕引文 + 79% 帧反查指向同一小节）。
读数用 PIL 裁切顶栏放大即可；**顶栏底色＝段位色（D 粉 / C 绿 / B 蓝 / A 橙 / S 金）可用来给个位数纠错**
（本轮就靠它发现把 `94.58%` 误读成 `54.58%`）。脚本没入库，写法记在这里。

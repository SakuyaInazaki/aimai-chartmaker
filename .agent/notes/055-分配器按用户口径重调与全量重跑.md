## 理由

note 050 的 `hands.py` 把知识 006/007/023 操作化成了代价函数，其中**权重与阈值全是 agent 设定**
（验证报告 §8 局限 6 明写"这两个数现在是拍的"）。用户 2026-09-19 就手序给了一段讲授，
直接覆盖了其中五处：分页二分、末尾半边、星头换手、纵连拆手判据、段首起手，
外加把"侧边双押铁律"的主语从"侧边双押"改成"突然"。
**用户口径 > 教程口径 > agent 操作化**，所以这五处必须按原话重做，
且凡依赖它们的结论（388 谱基线、出张统计、定式复现、扰动、三张表）**全部要重算**。

## 变更

### `tools/chart_analysis/hands.py`（v0.1 → v0.2）

1. **舒适区模型取代分页二分**（知识 064）：新增 `COMFORT` / `SHARED_KEYS` / `CHUZHANG_KEYS`
   与 `is_chuzhang()` / `reach_cost()`。共享区 `{1,4,5,8}` 两手 0 代价；
   **出张 = 左手落 {2,3} 或右手落 {6,7}**，单档 `w_chuzhang = 0.90`（agent 设定）；
   "跨半圈深度"整档取消。`page_depth()` 保留作诊断量与 `PARAMS_LEGACY` 用。
2. **撤销 `w_star_switch`（0.25 → 0）、`w_slide_end_side` 降为 tie-breaker（0.35 → 0.02）**（知识 065）。
3. **纵连长度优先**（知识 019 补充）：`build_tasks` 给每个任务算 `vrun_len`（同键连续 tap 串长度）；
   长度 ≤3 时免速度项、免交替代价、`w_same_key_extra` 全额给（`t_hard_same = 33.3 ms` 仍是硬下界）。
4. **段首位置连续**（知识 067）：新增 `_is_seg_start()` 与 `w_seg_start_far = 0.30`；
   段首按环距额外计价（离得近的手起手）并关掉交替先验。
   `w_chuzhang` 明显大于它，所以**"就近起手"若造成出张则避免出张优先**。
5. **"一手吃两个对象"保持关闭**（知识 066），新增 `one_hand_two_objects = False` 并在注释里引条目；
   同刻相邻两键的 `w_sweep_pair` 0.90 → **1.20**，使它不能被用来绕开出张。
6. **侧边双押红线 = 突然 ∧ ¬引导**（知识 030 补充）：新增 `side_double_events()`，
   实现引导 A/B（共享键步进）/ C（相邻键对等距轮转）/ D\*（临近位置已在这两键上，
   依据是 030 原表的"单点铺垫 → 双押串"），红线记为 `muri` 硬级标记 `突然侧边双押`。
7. **出张统计改口径**：`BarHand.chuzhang` 改成 064 的键位定义，新增
   `chuzhang_slide` 与 `chuzhang_end_side`（v0.1 旧口径并列输出）；`chart_summary` 同步。
8. **`PARAMS_LEGACY`**：v0.1 参数集整体保留，可一键切回做新旧对照。

**两处被迫重标定的 agent 参数**（都在文档里写明了原因）：
`w_same_key_extra` −0.12 → **−0.22**（不然知识 027 的定拍段会被拆成左右交替）；

## 结果要点

- **388 谱基线：绝对无理 146 一个不差**（0.54‰），硬无理 120 → 118，不可行 141 不变。
  **重调动的是"难不难"，没有动"能不能打"。**
- **★ 出张落点 10 891 → 5 714（−47.5%）**（同一套 064 计数口径、只换分配器）。
  v0.1 的分页模型让右手打 5/8 付 0.30 代价，模型会为了躲这一档而把手推进真正的出张区。
- **"突然侧边双押"红线在 388 官谱上 0 次触发**——阈值即由官谱标定：
  无引导侧边双押的最小间隔 **142.9 ms**（= 210 BPM 的一个八分，与知识 011 撞在同一个 BPM）；
  位移腿标不出线（官谱最大 3，而 4 对侧边双押结构上不可达）。
  官谱把位移与间隔当**可互换的两个预算**：位移 1/2/3 格时最小间隔 142.9/162.2/163.0 ms。
- **定式复现 16/18**（与 v0.1 同档），且**多复现一条**：知识 **062 鼓动段**在 v0.1 是 ⚠️ 不一致
  （`w_slide_end_side` 压过 `w_star_switch`），065 撤销两项后自动复现。
- **扰动分离度不降反升**：三种扰动 Cohen d 0.75/0.79/1.12 → **0.92/0.94/1.30**。
- **两个 ep2 谱例在 064 下翻转**（同一个机制）：`403-最終鬼畜妹` m060–063（043 出张）与
  `314-FLOWER`(remas) m071–072（037 反手）**出张落点都是 0**——它们跨的全是共享键。
  → configs_hand 的 ground truth 43 段变 **41/43**，两处缺口都是口径翻转不是漏检。
- **三张表**：ρ(定数, 词汇量) **+0.450**（前两版 +0.456）、17 类符号 **17/17** 一致 → **站住**；
  采音 §8.1 核心表逐项复现、§8.5 的两条新结论站住（强度 × 手序难度 +0.046；
  **手序难度 × 出张数 +0.334 → +0.461**）；
  **翻转**：底色六件套在 v0.2 下**没有任何配置达 95% 出现率**（`出张`/`反手` 是靠旧口径撑起来的），
  主料中位 5 → 4。

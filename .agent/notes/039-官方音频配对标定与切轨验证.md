- **理由**：用户提供官方音频，解锁了 `docs/audio-analysis.md` §4.8 标定协议里一直挂起的 **(E) 项**
  ——"唯一能把权重从初值变成标定值的路径"，以及此前无法验证的"官方谱师到底踩了哪条音轨"。

- **核心结果**（详见报告）：
  1. **8/8 跑通**。谱面解析 0 error，note 总数与 `resource/official-chart/` 的 mai-notes
     转录版 8/8 一致；谱面小节起点与音频网格最大对齐误差 **0.000 ms**。
     **官方 `&first = 0` 被音频侧独立确认**：用官方 note 反查各 stem onset 的全局相位
     φ\* 全部 |φ\*| ≤ 20 ms（中位 +5 ms，与 MP3 容器 `start_time` 23 ms 同量级）。
     **管线 §2.4 的 offset 校验在 Signature 报 −229 ms、麒麟 报 −129.8 ms 都是假警报**
     —— 根因是搜索窗半径恰好 = ±半拍，窗口两端的"反拍"并列夺峰（128 BPM 半拍 234 ms、
     220 BPM 半拍 136 ms，与报出值吻合）。已作为 R1 写进修订建议。
  2. **强度 × 密度只有中等相关**：逐小节 Spearman Fisher 汇总 **0.454**（raw 0.468、
     Pearson 0.498），逐段 **0.523**；知识 003 的 note 种类加权变体无差别（0.467）。
     单特征里 **`flux` 最强（0.524）、`voiced` 为 0（0.016）**，融合式反而低于最强单项。
     **峰值位置误差中位 33 小节**（音频峰落在谱面密度前 20% 小节只有 4/8，五票 climax 5/8）；
     结构边界 ±1 小节命中 **53%**、±2 小节 72%（但音频侧平均给 9.6 个边界去命中 4 个变点，
     召回口径对音频有利，精确率只有约 22%）。
  3. **权重标定：不更换 `intensity.py` 默认值。** LOSO 8 折 CV Spearman
     **标定值 0.515（中位 0.537）vs 初值 0.488（中位 0.518）**，仅 **5/8 折胜出**、
     符号检验 p ≈ 0.36、输掉的那折 −0.186 → 不满足"明显优于"。
     保留 `[0.25, 0.30, 0.20, 0.15, 0.10]`。留两条待验假设：`voiced` → 0、`flux` 0.10 → 0.25
     （该手写预设 `voiced_to_flux` 的中位 ρ 0.559 为全部候选最高）。
  4. **密度地板**：小节尺度 `floor=0.25` 站得住（池化最优 0.020，0.25 的 SSE 只差 2.4%）；
     **段落尺度 `floor=0.60` 偏高**（池化最优 0.125，0.60 差 10.3%）。
     绝对量级 MAE 2.07–4.69 note/小节；**「定数 → note/小节」在 BPM ≥ 200 的三首上
     系统性高估 3.1–3.7**，改用 NPS 锚 MAPE 从 21.0% 降到 16.5%。
  5. **切轨验证（最有价值）**：全曲加权 recall drums 0.607 / other 0.273 / bass 0.202 /
     vocals 0.167；precision drums 0.670 / other 0.610 / vocals 0.539 / bass 0.519；
     随机基线校正后的 lift drums 2.64 / other 2.29 / vocals 1.94 / bass 1.89。
     官方 note 归因：**81.4% 至少被一条 stem 解释、18.6% 什么都不落、
     只落 drums 28.1%、只落 vocals 3.2%、不落 drums 36.2%**。
     量化候选池 recall 0.821 / precision 0.546（**官方谱只从候选池里挑一半，佐证知识 005**）。
     **`stemplan.py` 逐段主踩一致率 64.7%（top2 81.2%、lift 口径 32.9%），
     而"永远答 drums"的常数基线是 82.4%（lift 口径 38.8%）——规则表两个口径都输给常数基线。**
     **MMFC 5.4-4「副歌全踩人声」在 14 个副歌段里只有 2 段成立**，唯一正面案例是
     幻想のサテライト（人声主导型曲目）；`final_chorus` 的 vocals lift 0.97 = 随机水平。
     唯一被正面支持的规则是 **5（间奏踩人声采样）**：interlude 的 vocals precision 0.715、
     lift 3.18 均为该类型最高。
  6. **结尾形态（387 谱）**：末 8 小节口径 **尾杀 65.1% / 渐弱 1.0% / 其他 33.9%**；
     换 6/12 小节 → 62.3%/2.3%/35.4% 与 71.6%/1.6%/26.9%，**定性稳定**。
     用户讲授的「尾杀为主、渐弱也有」被完整支持，且渐弱确为少数派。
     8 首音频对照：**7/8 曲谱面末段相对强度高于音频末段**，但音频真淡出时谱面密度**也降**
     （幻想 0.62、麒麟 0.80）→ 正确表述是"谱面收尾减压幅度系统性小于音频"，
     不是"谱面不淡出"。

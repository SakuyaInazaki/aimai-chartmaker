## 技术要点备忘

1. **数据源机制**：站点为 SPA；`/data/manifest.json` 含全量歌曲+谱面元数据（1563 歌 / 6390 谱），谱面数据在 `/data/charts/{chart_uuid}.txt`（纯 simai 正文，无 `&` meta 头）。
2. **谱面タイプ ST** = 站点 JS 中 `song.type == "standard"`（standard→"ST"、deluxe→"DX"）。
3. **`has_chart_data=false` 的谱面**：请求返回 SPA HTML 兜底页（200）而非数据——该标记可靠，脚本据此跳过并记录。
4. **定数边界**：按用户原话 13.0–14.5 过滤（含 13/13+/14 全部 + 定数 ≤14.5 的 14+；不含 14.6–14.9 的 14+），待用户确认。
5. **文件名 id**：采用站点 manifest 自带的 `simai_id`（数字编号，全部候选非空）；曲名做文件系统非法字符清洗（`/ \ : * ? " < > |` → ＿）。
6. 候选规模：432 个谱面（367 MAS + 65 ReMAS，361 首歌曲，27 首 MAS/ReMAS 双谱在区间内）；约 44 个无数据。

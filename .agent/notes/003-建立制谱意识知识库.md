# 003 — 建立 .agent/knowledge 制谱意识知识库

- **日期**：2026-09-10
- **变更**：
  1. 新建 `.agent/knowledge/` 目录：`README.md`（约定）+ 3 条种子知识条目（001 谱面强度贴合情绪走势 / 002 踩音切轨 / 003 配置强度四大因素）。
  2. `AGENT.md` 工作准则新增第 8 条"制谱意识知识库（跨上下文记忆）"；仓库结构约定补充 `.agent/knowledge/` 与 `resource/`。
  3. `.agent/notes/README.md` 补充本目录与 knowledge 目录的分工说明。
- **理由**：用户指出——"由于模型的上下文长度是很短的，跨上下文区间来进行对谱面设计的理解与认识肯定是不合理不可靠并且可能出现幻觉的。所以我们需要维护一个对制谱意识理解的类似于一个笔记性质的文件夹，专门存储或大或小、或多或少的这样的一些小点并且可以长期维护并理解"。因此：
  - 建立 `.agent/knowledge/` 作为制谱意识知识库：原子条目、带来源与置信度、可修订、写谱前必读、学到必写；
  - 与 `.agent/notes/`（变更过程）明确分工，并在 AGENT.md 中强制约定。
- **来源**：用户指令（2026-09-10 会话）。
- **关联**：`.agent/knowledge/README.md` 及条目 001-003；`AGENT.md` 工作准则第 8 条。

## 2. 第七层怎么来的：**复用，不是重推**

- **规格**：MiaCode `docs/specs/muri/MURI_DETECTION_SPEC.md`（336 行）。
- **实现**：逐条译自上游 **Starrah/MaiMuriDX**（Python）
  `judge.py::StaticMuriChecker.check` **46–197 行**；常量取其 `core.py` 38–98 行 + `config.json`
  默认值（判定时基 180 TPS、撞尾/外键阈值 36 tick = 200 ms、叠键 6 tick = 33.3 ms、
  区间左端冗余 9 tick = 50 ms、启动拍容错 ≈1 tick = 5.6 ms）。
- **几何**：`data/slide_geometry.json` 由它的 `slides.py::SlideInfo`（`init()` 后的 `_entries`）
  **直接导出**——不是我们自己推的轨道几何。
- **MiaCode 与 MaiMuriDX 同源**：spec §11 自述「`MaiMuriDX` 的 slide 判定里也有同款双分支实现」。

**对齐验证**：`out/calib` **160 首官谱 + test-01 修正前后**，逐首与 MaiMuriDX `cli.py` 的
静态输出比对 —— **命中种类与条数完全一致**。
（途中抓到一个自己的 bug：秒域比较遇上"gap 恰好 = 200 ms"（150 BPM 八分）会因浮点误差漏报，
MaiMuriDX 在 tick 域不会。已改成 `N/180` 定义常量 + 1 µs 边界容差，并写进注释。）

**覆盖边界（必须记住）**：只做**静态三类**。`SlideTooFast`（内屏）与 `MultiTouch`（多押）
在 spec §3 里**只有运行时分析、没有静态参考**，本层不复现那套 180 TPS 手势模拟
→ **「第七层 0 命中」≠「MiaCode 面板 0 条」**。多押另由第二层 `hands.py` 覆盖。

## 3. 病根：**接力写成两拍，头就掉到轨道后面去了**

24 条**全部是撞尾**（外键 0、叠键 0）——说明拍滑的**启动拍时机是对的**
（启动拍 tap 落在 shoot 时刻、gap = 0，在 5.6 ms 阈值之下，不触发）。

205 BPM `{8}`：一个八分 = 146.3 ms、一拍 = 292.7 ms。
`X^Y[8:1]` 的头在 t₀，启动拍 t₀+292.7，**轨道 t₀+424.7 才进终点区 Y**，
危险区 **[进区−50, +200] = [374.7, 624.7]**。
我把接力的下一根头放在**第 5 个八分（t₀+585.4）**——**正好掉进去**（gap −161 ms）。

知识 **057** 早就写了：「**头永远比轨道领先一拍**」。官谱实证两条：

- `133-BREAK YOU!!-mas.txt` BPM167 `{16}`：`2-5[8:1],2,5-1[8:1],5,`
  → 两根头隔 **0.5 拍**，头比轨道**提前 335 ms**；
- `112-Mysterious Destiny-mas.txt` BPM140 `{4}`：`8^3[4:1],3^6[4:1],,,`
  → 两根头隔 **1 拍**，提前 385 ms。

**结论（新认识，可入知识库候选）：一笔画 / 绕圈接力的头间距必须 ≤1 拍。
两拍接力是结构性撞尾，与键位无关。**

## 4. 改法（17 小节，删 0 个 note）

- **①「接力头搬到启动拍那一格」**（10 处）：下一根的头从第 5 个八分提到**第 3 个八分**，
  与上一根的启动拍 tap 合成一个双押 → 头落在危险区**之前**，**头尾相连原样保留**。
  这就是知识 **049 连续拍滑**的标准相位（Contrapasso m090 同形）。
- **②「把撞上的那个双押挪开半圈」**（7 处）：小节开头的 `45` 与结尾的 `18` 对调。
  轨道尾在 A8/A1 就用底双押收，在 A4/A5 就用顶双押收。**节奏、note 数、配置族全不动。**

逐处「原文 → 改后 → 依据」表见 `docs/research/test-01-writeup.md` §9.4（17 行）。

**⚠️ 走过一次弯路，记下来**：第一版改法是「把接力键沿圈错开一格」（`2^5` → `2^4`），
命中同样归零、节奏一字不动——但 `configs_hand.detect_circling` 要求**严格头尾相连**
（`b.key != a.end` 直接 break），**绕圈星星从主料里整个掉了出去**。
教训：**改无理的时候要回头跑一遍配置层**，不能只看命中数归零。

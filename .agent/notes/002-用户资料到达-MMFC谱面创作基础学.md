## 资料要点摘要（供后续 agent 快速了解）

- **书名**：《MAIMAI 谱面创作基础学 长篇指南》，MMFC Charting Team（主编：小小红白），2024-07-22。
- **结构**：第一章 谱面要素历程（初代→GreeN PLUS→PiNK→DX→Festival 各版本新增要素）；第二章 乐理基础与常用工具；第三章 谱面创作工具（simai/2simai/3simai、Visual Maimai、majdata）；**第四章 simai 创作语言（语法核心）**；**第五章 谱面理解（强度理论、踩音与配置）**；第六、七章 杂项与结语。
- **第四章关键语法**：meta 指令（&title=&artist=&first=&des=&wholebpm= 等）；BPM 标记 `(170)`；分音标记 `{8}`；逗号为时间单位；连续分音标记不兼容；**最细分音为 384 分（分音须为 384 的约数）**；Tap 1-8；Touch A/B/C/D/E 区（C 简写 C）；Each 用 `/`（纯双 Tap 可省略）；伪双押用反引号；Hold=`4h[4:1]`；Touch-Hold 仅 C 区；Slide=起-形-终[分音:长度]，形状 `-`（直线）、`<` `>` `^`（贴边曲线）、`v`（折线）、`V`（大折线）、`q` `p`（绕 C 圈）、`pp` `qq`（绕 B 圈）、`s` `z`（二重折线）、`w`（扇形/WiFi，占双手）；组合星星（`1-4^6`）；同头星星用 `*`（禁用 `/` 会重头）；修饰符 `b`(Break)、`x`(EX 保护)、`f`(Touch 烟花)。
- **第五章理论**：谱面强度须贴合歌曲情绪（常见走势：弱→较强→较弱→强→渐弱）；踩音=选择音轨与节奏，配置=形态载体，须随情绪切轨；强度四因素：note 种类（tap<hold<each<slide）、错位（星星启动拍加 tap 为最强）、位移距离、BPM（快则更难；慢则星星启动时机迷惑性强）。

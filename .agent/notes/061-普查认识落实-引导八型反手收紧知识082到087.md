- **仍不可靠的环节**（写在这里免得下一轮把它当结论）：

     不说明这八型就是玩家实际依赖的东西；本轮的主形态再分配就是直接证据
     （A/B 与 C 一放宽就从 D/G 手里抢走上百次）。

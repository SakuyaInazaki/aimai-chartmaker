# 012 — 谱面预览方案探查：mai-notes player 已本地化，仅本机预览

- **日期**：2026-09-10
- **变更**：
  1. **探查结论**：https://mai-notes.com/player 左侧谱面预览是 **Canvas 2D**（`canvas#chartCanvas` 500×500，无 WebGL）的轻量方案，数据源仅为两个静态文件：`/data/manifest.json`（歌曲+谱面元数据）+ `/data/charts/{uuid}.txt`（simai 正文）。用 `?chart={uuid}` 参数选谱。无任何硬编码绝对地址、无后端渲染依赖（Supabase 仅用于登录/榜单，预览不依赖）。
  2. **本地化实现**（`resource/player-preview/`，**已 gitignore 不入库**）：
     - 下载静态资源：player 页面 HTML（→index.html）、`player-dae06844.js`、`player-ce1021b5.css`、`sensor.png`、`logo-square.png`、`manifest.json`（4MB）、supabase-js（CDN 依赖改为本地）。
     - `run.py`：① `mirror`——把 `official-chart/` 已抓谱面按 chart uuid 镜像到 `data/charts/` 并生成 `list.html` 本地谱面库；② `serve`——本地 HTTP 服务（127.0.0.1:8099）。
     - 验证：所有资源 200，服务常驻运行中；浏览器打开 http://127.0.0.1:8099/list.html 即可点谱预览。
- **理由**：用户判断正确——"左侧的谱面预览是轻量化的谱面预览方案"，希望抓下来自用（**仅本机预览、不入库**）。本地化后可离线预览任意已抓谱面，且不依赖站点后端。
- **来源**：用户指令（2026-09-10 会话）。
- **关联**：`resource/player-preview/`（本机）；`.gitignore`；笔记 011（谱面抓取）。

## 使用方式备忘

```bash
cd resource/player-preview
python3 run.py serve   # 启动后打开 http://127.0.0.1:8099/list.html
python3 run.py mirror  # 抓取新谱面后重新镜像+刷新列表
```

注意：① 预览为静态谱面视图，音频播放功能需自行提供音源（Web Audio 解码，无音频不影响左侧静态预览）；② 页面中登录/榜单等 Supabase 功能在本地不可用（预期行为）；③ 每抓一批新谱面需重跑 mirror。

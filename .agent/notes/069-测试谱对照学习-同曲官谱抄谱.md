## 3. 本轮发现的一条待用户裁定的疑点

**两份谱的小节线相对音乐差约一拍。** 两份谱的**谱面内部**小节网格逐微秒相同
（17 个 `(bpm)` 落在同一批拍位），但折到我们的 `track.wav` 上：
参考谱（`&first=0`）的最佳偏移量在 **0.14–0.16 s**，我们（`&first=0.4279`）在 **0.43–0.44 s**，
差 0.28 s ≈ 205 BPM 的 0.95 拍。也就是「**每小节的第一拍在音乐的哪里**」两份谱不一致。

- note 068 §6 其实已经把这件事挂成待核项（"205 段到底从第几秒开始。现谱是 24.764 s；旁证推出来约 24.3 s"）；
- 我们把音频硬切入（1.3478 s）读成了**弱起**（落在 bar 1 第 4 拍），参考谱把它读成 **bar 2 的第 1 拍**；
- **这只能听音乐裁定**（AGENT 准则 14：拍相位只能用音乐证据）。本轮不下结论，
  文档里凡是依赖"第几拍"的观察都换成了**与相位无关**的写法
  （分音占比、八分位分布、键对分布、note 数、种类计数全部不受影响）。
- **如果判定我们要挪一拍**，`tempo_map.json` 与整份谱都要重排。

## 4. 没做 / 边界

   要恢复完整采音层对照得按新 tempo map 重跑音频分析。

   尾奏部分它自己标了 `|| not sure`），所以"官谱怎么写"这句话要打一点折扣。
4. **定数与谱种都不同**（DX 14 vs 我们目标 ST 13.6）——绝对数字不可照搬。
5. **没有听审**，全部结论来自谱面文本与既有分析产物。**n=1**，与跨谱分布冲突时信跨谱分布。

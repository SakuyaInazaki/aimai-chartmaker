- **做了什么（结论要点）**：

  1. **基线对得上**：侧边双押 **685**、现判据"无引导" **307**、出张落点 **5 739**，
     与 `hand-assignment-validation.md` §V9.1 逐项一致。

  2. **A：引导形态八型**（全部是**形状**判定，无阈值、无分档）。
     用户讲过的三型 = 共享键步进 155 / 等距轮转 37 / 同键已在手下 186，合计 **55.2%**；
     官谱还常用另外五型，**原来判不出的 307 次被它们全部吃下**：
     镜像对带过来 86、同型相邻对带过来 85、星星·长条落点送手 57、相邻键铺垫 56、同对回访 17。
     **相邻键铺垫（手就在隔壁）在 685 次里命中 667 次（97.4%）。**

  3. **A：官谱里没有"真突然"的侧边双押**。八型在拍级窗口全不命中的只有 **6 次（0.9%）**，
     分布在 3 张谱（`477-Ragnarok` m041、`66-ワールズエンド・ダンスホール` m019/m020/m023/m024、
     `72-みんなのマイマイマー` m042）；把窗口放宽到**乐句级**（本小节此前 + 前一小节）
     逐条复核，**6 次全部有引导**（同对回访 / 共享键双押 / 相邻对双押链）。
     另外两条负面证据：`临近最小环距` 全库最大 **3**（一次 4 都没有）；
     贴得最紧的 31 次（≤0.25 拍）**全部有引导**。

  4. **B1：出张（064 口径）是常规操作但不是难度手段**。5 739 落点 / 377 谱，
     中位 **19.2 / 1000 任务**；四个落点（L→2/3、R→6/7）用量几乎相等；
     **密度随定数下降**（13.0–13.4 段 23.0/1k → 14.5+ 段 10.9/1k），`出张/slide` 四段不变。
     上下文：另一手被星星钉 20.8% + 被长条钉 15.4%、出张的是星星自己 22.3%、
     **纯单点出张 30.2%（最大一类）**、同刻双押另一半 9.1%、纵连里 2.1%。
     段落上 **Bメロ 最多（27.5/1000 note）、ラスサビ 最少（14.5）**。

  5. **B2：两口径差集是系统性的**。教程口径（离开舒适击打区 / 两手挤进同一半圈）
     在 388 谱上标出 **11 902 段出张 / 4 902 段反手**，064 口径只剩 **971 / 266**；
     差集覆盖 386 / 374 张谱。差集里 **4 167 个"交叉步"中 94.8% 两手都站在共享键 `{1,4,5,8}` 上**
     （`(L4,R5)` 1 929、`(L1,R8)` 1 473），即扫键/楼梯在 8–4 轴上的正常换手。
     两个教程谱例都在差集里：`403-最終鬼畜妹・一部声` m058/m060–062（出张）、
     `314-FLOWER` Re:MAS m071–m072（反手）。
     **出张差集随定数下降、反手差集随定数上升**（反手差集上升看起来只是"高定数谱扫键更密"）。

  6. **★ 顺带查出一处实现不一致**：`configs_hand.detect_backhand` 的 064 收紧
     **只打在"同半圈"那一支**，`crossed` 支仍按 006 中线 → 现行判据报出的 **266 段反手里
     217 段（81.6%）一个出张落点都没有**，全是 `4,5,4,5` / `1,8,1,8` 这类两手在轴两侧交替
     （`61-天国と地獄` m018/m052、`491-極圏` m097、`345-Oshama Scramble!` m006…）。
     真正在 064 口径下站得住的只有 **49 段**。改法写进报告 §6.2，**本轮未动代码**。

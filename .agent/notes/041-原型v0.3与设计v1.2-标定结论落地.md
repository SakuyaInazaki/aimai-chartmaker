## 变更

### A. `tools/audio_analysis` v0.2 → **v0.3**

1. **`grid.py`：修掉 offset 的 ±半拍「反拍」假警报（R1/R2）**
   - 根因：onset-fit 打分函数以**一拍为周期**，而搜索半径设成 ±1 拍 → 窗口里含 φ*±半拍的反拍峰；
     正反拍等强时反拍略高就会夺峰（Signature −229.0 ms ≈ −半拍 234.4；麒麟 −129.8 ≈ −半拍 136.4）。
   - 修法：搜索半径收到 **±0.4 拍**（硬上限 0.45，超出会被夹紧并在结果里注明
     `search_beats_clamped`）；同级峰仍取离用户值最近者；新增 `offbeat_ambiguous` /
     `tied_symmetric` 标志与 **`ratio ≥ 1.15` 显著性门**；判词改四档
     （一致 / **疑似 MP3 解码延迟 15–30 ms** / 反拍歧义·显著性不足 → **不报警** / 报警）。
   - 回归测试：合成"反拍略强的 8 分 hi-hat" click 序列，用 `search_beats=1.0,
     allow_offbeat_window=True` **复现**假警报，默认窗口下修复。
2. **`stemplan.py` 重写：骨架轨 + 点缀轨（C2 / R9）**
   - 输出 `skeleton_stem`（默认 drums，判据=鼓 onset 密度与落格率）+ `accent_stems[]`
     + `accent_share{}`（含 `free = 0.19`，即实测"什么 stem 都不落"的 18.6%）+ `plan_evidence[]`（纯音频依据）；
     `primary_stem` / `secondary_stem` 降级为**已弃用的兼容字段**（`tools/calibration/cli.py` 仍读它，本次未改那边）。
   - 规则调整：规则 1（前奏）判据 **能量占比 → onset 匹配倾向**（C3）；规则 4（副歌）**条件触发**
     （`voiced ≥ 0.45` 且 `vocals/drums onset 密度比 ≥ 0.65`）**并输出存疑标注**（C1）；
     规则 5（间奏人声采样）**加强**（C4，precision 0.715）；规则 6（休息段）**标存疑**（C5）；
     保留降级与单轨警告（警告口径改为"骨架 ∪ 点缀只有一条轨"）。
   - **推理期没有谱面**：所有判据都是纯音频特征，标定里的命中率只作为规则设计依据写进注释。
3. **`intensity.py` / `cli.py`：密度锚与地板（R5/R6 + MYTHOS 裁定）**
   - 绝对量级主锚 **note/小节 → NPS**（`NPS(定数) × 每小节秒数`，变速曲逐小节算），旧锚保留为对照列；
   - `--section-floor`（默认仍 **0.60**，Header 注明 n=8 池化最优 **0.125** 未采纳）、`--bar-floor`、
     `--intro-outro-cap`（默认 0.60 × 全曲建议均值，**intro/outro 结构封顶，只封不抬**）；
   - **融合权重一字未改**（裁定 4），只在注释里补上标定结论与 H1/H2 两条待验假设。
4. **`climax` 正名（R4）**：JSON 增 `audio_climax_bar` / `climax_kind` / `climax_note`，
   song sheet 显式写"**音乐最激烈处 ≠ 谱面最密处**（中位误差 33 小节）"；旧字段名保留兼容。
5. **song sheet**：Sections 表列改为 **骨架 / 点缀 / 估计占比**，逐段附"踩音依据（纯音频特征）"；
   Header 增候选池参考量级（**官方谱只采用约 55%**，precision 0.546 / recall 0.821）、
   密度锚主/对照两行、密度地板与结构封顶说明；§3 的限制条目同步更新。

## 理由

- 标定报告 §8 的 R1–R11 是**建议**，需由主会话裁定后才落地；本次按裁定逐条执行，
  **不改权重**（R3 的结论就是"不换"）、**不把 C1 写成推翻**（证据是代理、样本 n=8）。
- 真 bug（offset 反拍）必须修：它会让"用户 offset 错了"这种最严重的误报出现在完全正常的曲子上。
- 单值 `primary_stem` 被实测证伪（输给常数基线），继续保留会把 LLM 推向"整段只踩一条轨"，
  正是知识 002/005 批评的新手做法。
- MYTHOS 个案说明**结构约束优先于能量曲线**的场景真实存在，前奏尤其明显。

## 仍不可靠 / 待办

1. **C1 待人工听审**：人声侧 ground truth 只有 onset 代理，basic-pitch/RMVPE 仍未装上；
2. **新阈值样本极小**：人声主导 0.45/0.65 是在这 8 首上分出来的，结构封顶 0.60 来自 MYTHOS 一首；
3. **NPS 锚不是每首都更准**（MYTHOS、Signature 反而变差），只是总体 MAPE 更低；
4. 段落 floor 的 0.60 ↔ 0.125 分歧未解决（388 谱 vs 8 首），默认按大样本走；
5. H1/H2 权重假设、§4.8(B) 分位映射、(D) 人工听审仍未做；
6. `tools/calibration/` 未改（本次禁改），其 `plan_primary` 仍读兼容字段。

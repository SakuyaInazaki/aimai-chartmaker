- **理由**：

  1. **用户 2026-09-20 指示**：「你先继续去实现与完善认识，你先别问我了」——因此本轮由 agent
     **自主裁定**哪些草案进知识库，不再把裁定项抛给用户（AGENT.md 待办第 ④ 项「知识草案入库裁定」据此关闭）。
  2. **AGENT.md 准则 8「学到必写」**：这批认知此前只存在于报告末尾的草案节里，
     跨上下文读不到；不入库等于没有。
  3. **裁定尺度（本轮自定，写在这里备查）**：
     - 只收**定性的、能被官方谱事实直接支撑**的认知；
     - 凡以 agent 自造的**阈值 / 分档 / 合成分 / 自造分类**为要点的，**一律不收或改写成定性**
       （数字降为"证据注脚"，如"越难的地方踩得越省"可收、"全采 30% vs 37%"只作注脚）；
     - **不自造术语**：只用社区词（全踩 / 舍音 / 留白 / 采空音、切轨、出张、引导、一笔画……）
       与条目已有词（note 056 / 057 的口径延续）；
     - 与用户讲授（001–030、064–067）冲突的不收，相邻的写清关系；
     - 置信度一律写 **经验（agent 观察，n=…，口径…）** 或 **存疑**，正文首句标注
       "agent 观察，未经用户确认"。

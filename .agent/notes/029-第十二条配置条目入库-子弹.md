# 029 — 制谱经验记录：第十二条配置条目（子弹）

- **日期**：2026-09-10
- **变更**：
  1. 新增知识条目 **028（配置：子弹）**。
  2. 知识库索引更新（028 入库）。
- **理由**：用户讲授"子弹"并经过一轮辨识后确认定义——**同一个键在短时间内被打两次**。

## 辨识过程（记录在案）

1. 用户提示："子弹：两个音符叠在一起的配置。id666 的 mas 里面有很多，你可以自己看"。
2. agent 在 666 谱面中找出两类候选：
   - **A. 同一 slot 的双押**（连写两位数字 `24`/`35`/`46`/`57`…，132 个 token、占全谱 18%）；
   - **B. 同键相邻快速两音**（`8,8`、`5,5,4,4,3,3…`，43 处）。
3. 用户追问："A 里面双押的每个键是不是短时间各自也都出现了两遍？"——agent 实测：短双押串（`12,12` 等）**每个键 2 个 slot 内两遍** ✅；长串只有部分键重复；全谱同键间隔 ≤4 的比例为 **48%**。
4. 用户确认（"你说对了"）：**子弹 = 同一个键短时间内两次**，A 的短双押串与 B 是同一种效果的不同写法。

## 条目要点备忘

- 定义：同一个键短时间内两次（两个音符叠在同一个键上）。
- 两种载体：① 同键相邻两音（`8,8`）；② 短双押串（`12,12`、`78,78` 等，每键 2 slot 内两遍）。
- 与纵连的分界：纵连 ≥3 音；正好 2 音 = 子弹。
- 使用注意：塞进错位间隙会造成手感差（ATLAS RUSH 实例）。

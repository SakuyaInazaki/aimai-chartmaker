## 核心结论备忘

1. **astrodx 主仓库已不含解析器**，官方开源解析库为 SimaiSharp（最严格的词法+语法解析器）。
2. **Majdata 无数字错误码**，报错为本地化字符串 + 异常消息；MajdataEdit SyntaxCheck.cs 约 40 类判定、MajdataView JsonDataLoader 12 条报错消息、SimaiSharp 5 类异常（均带行列定位）。
3. **MajdataView README 自述语法宽松**："零报错"应以 SimaiSharp 为交集基准。
4. **零报错生成格式依据**：SimaiSharp Serializer 规范序列化（`(bpm){拍号}` 开头、每拍 `,`、`E` 结尾、slide 统一 `[delay##duration]` 秒制）。
5. 10 条三方语法分歧（hold `[##秒]`、touch C2、slide x、`@`/`m` 装饰符等）为生成器必须避开的陷阱。

# .agent/notes — 项目变更记录

本目录由 coding agent 维护，记录**项目建立与演变全过程的变更及其理由**，供后续开发者与 agent 回溯决策上下文。

## 记录约定

- 文件名格式：`NNN-简短主题.md`，`NNN` 为三位递增编号（001 起），一条笔记对应一次有实质意义的变更（或多个密切相关的变更）。
- 每条笔记包含以下字段：
  - **日期**：变更发生日期
  - **变更**：本次做了什么（新增/修改/删除哪些文件、做了什么决策）
  - **理由**：为什么这样做（用户指令 / agent 决策及其依据）
  - **来源**：变更由谁发起（用户原话要点 / agent 自主判断）
  - **关联**：相关文件、commit、issue 等
- 笔记与对应的项目变更**在同一个 git 提交中推送**，保证记录与实际代码一致。
- 用户亲自添加的补充资料（用户会另行告知），由 agent 在笔记中记录"资料到达"事件及后续影响。

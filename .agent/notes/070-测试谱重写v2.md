### 2.4 相似度自检（`tools/chart_analysis/similarity.py`）

第一次跑出**两条命中**，都改掉了：

1. **m041 与参考谱整小节一字不差**：`{8},,1b,,,,,8b,`。
   这是我照着 note 069 §2.5 引的那一小节写的——**拿到的是「一小节只放两个单绝赞」这个做法，
   却把键位和落点也一起抄了**。改成 `{8},,,3b,,,,6b,`。
2. **三处 8-gram 与参考谱相同**：`1,4,2,5,3,6,4,7`（二连扫的级进形）出现在 m050 / m107 / m113。
   二连扫本身是标准配置（知识 036），但**同一串 8 个键位照搬就是抄**。
   改成换起点 / 中途折返的写法，顺带把 m120 那条「一路同向 16 个十六分」也拆成了折返。

**终值**：

| | 逐小节完全相同 | 其中 ≥2 note | 4-gram 次数重合 | 8-gram 种类重合 |

| **v2 vs 参考谱** | 11（**全部是空小节**） | **0** ✅ | **0.068** | **0.000** |
| v1 基线 vs 参考谱 | 0 | 0 | 0.074 | 0.000 |

4-gram 的**种类**重合 0.059 略高于基线 0.055——v2 的 4-gram 种类总数比 v1 多（757 vs 636，
写法更杂），而**按出现次数算的重合低于基线**，说明「谱面里有多少是共享的形」是降的。

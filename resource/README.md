## 入库策略说明（记录于 `.agent/notes/002`）

- 本目录下的 PDF 与提取文本**不入 git 仓库**（`.gitignore` 已忽略 `resource/*.pdf`、`resource/*.txt`）。
- 理由：① PDF 为 36MB 二进制，入库会永久增大仓库体积；② 该书声明"仅用于非商业性质的学习和交流"，直接托管在公开仓库存在再分发合规风险；③ 消化后的知识以笔记/文档形式入库即可满足开发需要。
- 如用户明确希望将某份资料入库，可随时调整。

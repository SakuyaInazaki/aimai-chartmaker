# tools/chart_check — 谱面检查器（验收工具）

一份 `maidata.txt` 进，**中文报告 + JSON** 出。它不生成谱面，只把 `AGENT.md` 的四条
验收标准拆成可逐条核对的清单：能机检的给结论，不能机检的给**复核清单**。

```
python3 -m tools.chart_check <maidata.txt> [--level 13.5]
    [--analysis song_analysis.json] [--json out.json] [--inote 5] [--quiet]
```

- `--level` 缺省时从 `&lv_N` 粗取（`13+` 记作 13.7）。
- `--analysis` 缺省时找 `maidata.txt` 同目录的 `song_analysis.json`；没有就跳过采音层。
- 退出码：有**错误**返回 1，否则 0。

## 五层与依据

| 层 | 做什么 | 依据 |
|----|--------|------|
| **语法** | `simai_parser` 严格解析 + 零报错安全子集 + ST 黑名单，逐条报错/警告（带**行列**） | `docs/simai-syntax.md` §6、`docs/simai-error-checking.md` §2/§4/§8、`docs/st-chart-elements.md` §三 |
| **手序** | `hands.assign()` → 不可行 / 无理 / 蹭 / 出张落点 / 侧边双押与引导类型 / Hold 尾 / 叠键 | `docs/hand-sequencing.md` §4，知识 008–012、015、064、077、079、080、082 |
| **配置** | `configs_hand.detect_all()` → 按小节顺序的配置构成、种类数、主料/点缀；段落分区对照 | 知识 017–063（定义）、071/073/074（对照，**agent 观察**） |
| **密度** | note 总数 / NPS / 逐小节曲线 / 五段形状 / 密度地板 / 末段形态 / 后半比前半 | 知识 004、031（§1/§2/§4/§5/§7/§10）、001 |
| **采音** | 逐段 全踩 / 舍音 / 留白 与骨架轨对照；标「该有音却整段留白」「采空音密集」 | 知识 068、081、086；三词切点复用 `calibration.sampling.THRESHOLDS` |

## 三个级别怎么读

- **错误**：必须修。语法层的错误 = 会让 SimaiSharp / MajdataEdit / MiaCode 报错或
  ST 谱不该出现的要素；手序层的错误 = **不可行**与**绝对级无理**。
- **警告**：要看一眼。含**硬级无理**——`docs/hand-sequencing.md` §6.2 要求
  `budget.muri`（含硬级）为 0，但 388 官谱自己也踩到几十次（知识 077：
  Hold 尾多押 74 / 超速 24 / 外键 13 / 撞尾 7），记成错误等于宣布官谱不合格。
  写谱时**硬级尽量清零**，清不掉要写明理由。
- **提示**：复核清单，**不判对错**。出张、侧边双押、软级的蹭、配置构成、密度对照、
  采音方式都在这一档。

## 两条边界（报告里也会印）

1. **外部三检待接**：`docs/simai-error-checking.md` §10-4 要求
   **SimaiSharp lint + MajdataEdit SyntaxCheck + MiaCode strict** 三方实跑，
   本机没有装这三个工具——语法层是**按它们的规则交集实现的内部校验**，
   **不能代替真机跑谱**。
2. **手序只有一套**：无理计数依赖 `hands.py` 选出的**一套**手序，而合法手序不止一套
   （知识 065）。「绝对无理 0」读作「**存在一套合法手序**」，不读作「任何手序都合法」。
   配置层与采音层的对照基准（知识 068–087）是 **agent 观察条目、未经用户确认**。

## 官方谱基线（2026-09-20）

五首官方 ST MASTER（`out/calib/<曲名>/maidata.txt`，带各自的 `song_analysis.json`）：

| 曲目 | 定数 | 语法错误 | 不可行 | 绝对无理 | 硬级无理 | 出张 ‰ | 出张/slide | 侧边双押（无引导） | 配置种类/主料 | note | NPS |
|------|-----:|---------:|-------:|---------:|---------:|-------:|-----------:|-------------------:|--------------:|-----:|----:|
| ぽっぴっぽー | 13.3 | 0 | 0 | 0 | 0 | 27.6 | 0.514 | 4（0） | 11 / 6 | 507 | 5.13 |
| ダンスロボットダンス | 13.3 | 0 | 0 | 0 | 0 | 27.3 | 0.219 | 3（0） | 18 / 9 | 826 | 5.74 |
| コトバ・カラフル | 13.7 | 0 | 0 | 0 | 0 | 12.3 | 0.076 | 7（0） | 12 / 5 | 575 | 6.58 |
| 緋色のDance | 13.7 | 0 | 0 | 0 | 0 | 12.1 | 0.192 | 0（0） | 11 / 9 | 484 | 4.76 |
| ジングルベル | 14.2 | 0 | 0 | 0 | **10** | 29.0 | 0.158 | 10（0） | 22 / 10 | 737 | 7.87 |

读法：

- **语法零错、不可行 0、绝对无理 0** 在五首上全部成立——这就是检查器的合格线；
- **硬级不是零**：ジングルベル 的 10 次是 6 次 Hold 尾多押 + 4 次超速，与知识 077
  在 388 谱上的分布一致 → 硬级只能当警告；
- 出张 12–29 ‰，与知识 079 的官谱中位 21.1 ‰ 同量级；
- 侧边双押 0–10 次，**八型引导全部判得出**（无引导 0），与知识 082「388 谱 685 次里
  只剩 1 次判不出」一致；
- 配置种类 11–22 类、主料 5–10 类，与知识 073（40 类透镜下中位 15 类 / 主料中位 4 类）
  同量级，低定数谱偏少。

复现：

```
for s in ぽっぴっぽー ダンスロボットダンス コトバ・カラフル 緋色のDance ジングルベル; do
  python3 -m tools.chart_check "out/calib/$s/maidata.txt" \
      --analysis "out/calib/$s/song_analysis.json" --quiet
done
```

## 单测

```
PYTHONPATH=tools python3 -m pytest tests/test_chart_check.py -q
```

素材全部是自写的合成片段（不复制官方谱原文）。容易误报的三条各配了负例：
`{8}…,{16}…` **不是**连写两个分音标记、`3<3` 绕一整圈**不是**几何违规、
星星头绝赞 `1b-5[…]` **不是**滑条绝赞。

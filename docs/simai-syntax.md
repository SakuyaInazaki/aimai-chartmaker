> **待办**：官方 wiki 调研完成后交叉核实并升版；v0.2 已就中文社区报告与初稿完成交叉印证（结论：三方一致，无推翻项，仅补充细节）。
> **配套文档**：`docs/simai-error-checking.md`（报错判定逻辑，另文整理）。

## 0. 阅读说明

- simai 是一种**纯文本制谱语言**，用相对时间描述音符：BPM + 分音 + 逗号（时间单位），而不是绝对时间戳。
- 所有符号均为**半角英文符号**。
- 本文档面向本项目生成器：目标是产出的 maidata.txt 在 **Majdata 生态（MajdataEdit/MajdataView）与 AstroDX（SimaiSharp）** 中均零报错。为此专门给出 §6"零报错安全子集"。
- 版本背景：simai 语言历经 simai / 2simai（pink 后星星）/ 3simai（touch）三代，语法被 Majdata 等工具沿用；新要素持续加入（DX、Festival 拼接星星、Break/Ex HOLD 等）。

## 1. 设计原理

1. **相对时间**：BPM 标记 `(bpm)` 定义速度，分音标记 `{x}` 定义"一个逗号 = 几分音符"，逗号 `,` 是时间推进单位。
2. **拍点推进公式**：每遇到一个 `,`，时间推进 1 拍，拍长 = (60/BPM) × (4/拍号分母)。
3. **最细分音**：社区规范中最小时间单位为 **384 分音**——分音 x 必须是 384 的约数（4、8、12、16、24、32、48、64、96、192、384 等合法；100 等不合法）。
4. **物件格式**：所有音符写在一个时间单位（两个逗号之间）内；同一时间单位内可用 `/` 分隔多押（Each）。

## 2. 文件结构

### 2.1 必需文件

一个自制谱压缩包解压后应包含（文件名**固定**）：

| 文件 | 必需 | 说明 |
|------|------|------|
| `maidata.txt` | ✅ | 谱面本体（元数据 + simai 谱面代码） |
| `track.mp3` | ✅ | 音源 |
| `bg.jpg` / `bg.png` | 否 | 背景图（建议 1080×1080） |
| `pv.mp4` / `bg.mp4` | 否 | 背景视频 |

音源建议：44100Hz 采样率、CBR ≥ 192kbps 的 mp3。

### 2.2 meta 指令（文件头 `&key=value`）

指令行以 `&key=value` 开头；值可持续到下一个 `&` 行。MajdataEdit 明确识别的键：

| 指令 | 含义 | 备注 |
|------|------|------|
| `&title=` | 曲名 | 必填 |
| `&artist=` | 艺术家 | 必填 |
| `&des=` | 制谱人 | 必填 |
| `&first=` | 谱面起始时间偏移（秒，float） | 控制第一个音符出现的时间 |
| `&lv_1=` … `&lv_7=` | 各难度等级 | 如 `&lv_5=14+` |
| `&inote_1=` … `&inote_7=` | 各难度谱面体（多人合作谱用） | 常规单谱只写正文即可 |

其他指令（`&wholebpm=`、`&shortid=`、`&genre=`、`&version=`、`&clock_count=` 等）MajdataEdit 会原样保留（passthrough）。**生成器至少输出 `&title=`、`&artist=`、`&des=`、`&first=0`。**

## 3. 时间标记

### 3.1 BPM 标记 `(bpm)`

- 小括号内写数字，**从该处起生效直到下一个 BPM 标记或谱面结束**。
- 例：`(170)` 之后谱面速度为 170BPM。
- 合法位置：一拍开头（MajdataEdit 要求；SimaiSharp 允许任意拍点——以严格方为准：放在一拍开头）。
- 与分音标记相邻连续书写（`(170){8}`），中间不留空拍。
- ⚠️ 不要连续写两个 BPM 标记（如 `(170)(175)`），部分环境不兼容。

### 3.2 分音标记 `{x}`

- 大括号内写数字 x，表示**之后一个逗号 = x 分音符时长**。
- 例：`{8}` 下一个逗号代表一个八分音符（半拍）；`{4}` 下一个逗号代表一拍。
- x 必须是 384 的约数（见 §1.3）。
- ⚠️ 不要连续写两个分音标记（如 `{16}{32}`），部分环境不兼容。
- 变更分音后，从下一个逗号起按新分音计。

### 3.3 逗号 `,` 与空拍

- 每个逗号推进一个"当前分音单位"的时长。
- 连续多个逗号 = 空拍（休止）。例：`(150){4},,` = 空 4 拍。
- 谱面最后必须以 `E` 结束（见下），`E` 前的每个逗号段须完整。

### 3.4 结束标记 `E`

- 谱面正文末尾写 `E`，表示谱面结束。
- **必须写**：缺 `E` 在 MajdataEdit 会警告、SimaiSharp 不报错，但跨工具零报错要求必须写（SimaiSharp Serializer 也强制输出 `E`）。

### 3.5 注释 `||`

- `||` 起至行尾为注释，会被解析器忽略。
- ⚠️ 单个 `|` 会抛错（SimaiSharp UnexpectedCharacterException）——注释必须写两个竖线。

### 3.6 Hi-Speed（MajdataEdit 扩展，谨慎使用）

- `<HS*数字>` 变速标记，仅 MajdataEdit 支持；跨工具兼容性差，**生成器不使用**。

## 4. 物件标记（note）

### 4.1 键位与判定区

- **键位编号 1-8**：环形 8 个按键，1 在上方，顺时针排列（1,2,3,4,5,6,7,8 对应上、右上、右、右下、下、左下、左、左上）。
- **Touch 判定区 A-E**：屏幕上分 5 大区（A 左下、B 左上、C 中央、D 右上、E 右下…以 majdata 判定区域图为准），每个区再细分 8 个子区。
  - 写法：`区字母+键位`，如 `A4`、`B5`、`E8`；**字母大写**。
  - `C` 单独写 = 中央 touch（C1/C2 在游玩中视为同一 C 区）。
  - 历史：DX 版本 Touch 只能放 E/B/C 区；Festival 起开放 A/D 区。
  - ⚠️ **C2 写法分歧**：SimaiSharp 接受、MajdataEdit SyntaxChecker 拒绝 → 生成器只写 `C` 或 `C1`。

### 4.2 TAP

- 写法：`1`-`8` 单个数字。
- **双押连写**：两个 TAP 的双押可省略 `/`，如 `73` = 7 号与 3 号键双押。仅限"纯双 Tap"（无 break/ex/星星头等修饰）时可省。

### 4.3 Each（多押）与伪 Each

- 多押分隔符 `/`：同一时间单位内多个物件用 `/` 分隔。例：`8/E5`（tap+touch 双押）、`E7/B7/B8`（三押）。
- **伪多押分隔符 `` ` ``（反引号）**：`` ` `` 后的物件比前面的**略晚**出现，手感近似同时但判定为先后，着色由黄变红/蓝。实现细节：MajdataEdit 为 1/128 拍间隔（wiki 称 0.001 秒，与代码不符，以代码为准）。
- **强制真 Each `0/`**：以 `0`（或 `0/`）开头的拍点强制为真双押（SimaiSharp ForceEach）。

### 4.4 HOLD

- 写法：键位 + `h` + 时长。`2h` = 无时值的短 hold（等效短按）。
- 时长标记 `[ … ]` 三种形式：
  | 形式 | 含义 | 例 |
  |------|------|-----|
  | `[x:y]` | x 分音符 × y 个 | `4h[4:1]` = 按住 1 拍（四分音符×1）；`4h[8:3]` = 八分×3 |
  | `[#秒]` | 直接秒数 | `4h[#2.5]` = 2.5 秒 |
  | `[bpm#x:y]` | 以 bpm 速度的 x 分 y 拍 | `4h[120#4:2]` |
  - 约束：`[x:y]` 中 x>0 整数、y≥0 整数；`[#秒]` 秒≥0。
  - ⚠️ wiki 写法 `[##2.5]` 在 SimaiSharp 会报错，**禁用**。
- 修饰符（`b`=Break、`x`=EX）可放 h 前或后（建议顺序 `b x h`）：`1bh[4:1]`。
- 注意：不带 `h` 但带 `[…]` 的 note 会被 SimaiSharp 视为 Hold——所以 TAP 不要加时长标记。

### 4.5 TOUCH 与 Touch-Hold

- Touch：`A1`-`E8`、`C`、`C1`（见 §4.1）。
- Touch-Hold：**仅 C 区**可加 `h` 变 Touch-Hold：`Ch[4:1]`、`C1h[4:1]`。
- Touch 无 Break/EX，只有烟花修饰 `f`（见 §4.7）。

### 4.6 SLIDE（星星）

基本写法：`<起始键位><形状><终止键位>[时长]`。例：`1-4[4:1]` = 从 1 到 4 的直线星星，时长一拍。

> **启动拍机制（游戏语义，生成器必须建模）**：星星头被击打后**停 1 拍（一个四分音符）才开始滑动**，开始滑动的时刻称"启动拍"。`[x:y]` 中的 y 拍是滑动时长，星星头另有 1 拍等待（`[bpm#x:y]` 形式中等待=该 bpm 的 1 拍）。启动拍不可随意修改（乱改会产生撞尾/多押无理，见知识库 014）。

#### 形状符号表

| 符号 | 形状 | 端点约束 | 备注 |
|------|------|----------|------|
| `-` | 直线 | 终点与起点间隔 ≥ 2 键（不能是起点自身及其左右邻键） | 初代就有的基础形状 |
| `^` | 贴边弧线，自动取劣弧（较短侧） | 起终点不能同键、不能对向 | 最常用 |
| `>` | 贴边弧线，定方向：起点在上半圈则顺时针，下半圈则逆时针 | 同 `^` | |
| `<` | 贴边弧线，方向与 `>` 相反 | 同 `^` | |
| `v` | 折线：起点→圆心（C 区）→终点 | 终点不能是对向键；终点可为自身但**不推荐**（1v1/2v2 折返星星不合规） | MajdataEdit 另禁同键——安全起见：终点≠起点且≠对向 |
| `V` | 大折线：起点→中折点（与起点相隔一键）→终点 | 中折点必须与起点相隔一键；终点不能是起点/中折点/中折点邻键 | 写法 `1V38`（起点V中折点终点） |
| `q` | 绕 C 区一圈（顺时针）后直线到终点 | 终点任意（含自身） | 完整环绕 |
| `p` | 绕 C 区一圈（逆时针）后直线到终点 | 终点任意（含自身） | |
| `pp` | 绕 B 区小圆（顺/逆）后到终点 | 无硬限制 | 圆与 C 区、屏幕边缘相切 |
| `qq` | 绕 B 区小圆后到终点 | 无硬限制 | |
| `s` | 闪电/二重折线（过 C 区，S 形） | **终点必须是对向键（180°）** | 起点上半圈先向左折，下半圈先向右折 |
| `z` | 闪电/二重折线（与 s 相反方向） | **终点必须是对向键（180°）** | |
| `w` | 扇形/WiFi | **终点必须是对向键（180°）** | **视作双押，占用双手**；不能作为组合星星的一段 |

- 对向键：与起点相隔 4 键（180°），如 1↔5、2↔6、3↔7、4↔8。
- 相对终点编码（MajdataView 内部）：终点相对起点的编号 1-8（1=同键，5=对向）。

#### 时长标记 `[ … ]`

| 形式 | 含义 |
|------|------|
| `[x:y]` | x 分音符 × y 拍（推荐、最直观） |
| `[bpm#x:y]` | 按 bpm 的 x 分 y 拍；星星等待 = 该 bpm 的 1 拍 |
| `[bpm#秒]` | 星星等待 bpm 的 1 拍 + 按秒移动 |
| `[秒##秒]` | 等待秒数 ## 移动秒数（SimaiSharp Serializer 的统一输出格式） |
| `[秒]`（无冒号） | 直接秒数（SimaiSharp 支持；MajdataEdit 校验器不认此形式 → **生成器不用**） |

#### 组合（拼接）星星（Festival）

- 连续书写多段形状即可拼接：`1-4^6` = 直线 1→4 接弧线 4→6。
- 时长写法二选一：
  - 整条共享一个时长：`1>5-8[1:1]`
  - 每段独立时长：`1>5[1:4]-8[1:1]`
- ⚠️ **混合写法（部分段有时长、部分没有）→ 报错**（SLIDE CHAIN ERROR）。

#### 同头星星（Festival）

- 相同起点的多条星星用 `*` 连接，后续段不重复写起点：`1-4[8:1]*-6[8:1]` = 从 1 出发到 4 与 6 的双押直线星星。
- ⚠️ **禁用** `1-4[8:1]/1-6[8:1]` 写法：会制造两个重叠的星星头，无法正常游玩。

#### 无头星星（进阶）

- 装饰符 `!`（SuddenIn）/ `?`（FadeIn）写在首键后：无头星星，启动时不出现在画面上。
- MajdataEdit 与 SimaiSharp 均支持；MaiLib 不支持（本项目目标工具链不含 MaiLib，可用但谨慎）。

### 4.7 修饰符

| 修饰符 | 含义 | 适用 | 写法例 |
|--------|------|------|--------|
| `b` | Break（绝赞）：严判、加分、失误多扣分 | Tap/Hold/Slide 头部/Slide 滑条 | `4b`、`4hb[4:1]`、`4-1b[4:1]`、`4b-1b[4:1]` |
| `x` | EX（保护）：防误触，Perfect 得全分 | Tap/Hold（Slide 滑条**不可**加） | `4x`、`4bx`、`4hbx[4:1]`、`4bx-1[4:1]` |
| `f` | 烟花效果（纯视觉听觉，无判定影响） | 仅 Touch | `E8f` |

- Slide 头部与滑条的 Break 可自由组合（`4-1[4:1]` / `4b-1[4:1]` / `4-1b[4:1]` / `4b-1b[4:1]`）。
- Break Slide 判定：`b` 紧贴 `[` 前 = 滑条 break；`b` 在串尾 = 星星头 break。
- ⚠️ **Slide 加 `x`**：MajdataEdit 接受但 SimaiSharp 抛异常 → **生成器禁止**。
- ⚠️ **`@`（ForceNormal）、`m`（Mine）装饰符**：仅 SimaiSharp 支持，MajdataEdit 报错 → 生成器不使用。
- ⚠️ **`$`（ForceStar）、`$$`（旋转星星）**：支持面窄且 MajdataEdit 内部判定不一致 → 生成器不使用。

## 5. 完整示例（正确写法）

```
&title=Example Song
&artist=Artist
&des=ai-chartmaker
&first=0.0

(120){4}
1,2,3,4,

(160){8}
1-4[8:1]/5,2,8/1-5[8:1],7,1-4[8:1]*-6[8:1],2,

(120){4}
Ch[4:1],E8f,1bx,4hb[8:2],2q8[4:2],E
```

## 6. 零报错安全子集（生成器强制规则）

> 依据：MajdataView README 自述语法宽松，Majdata 能跑的谱面未必能在 maipad/simai/Astro 运行。**以最严格的 SimaiSharp 为最终校验基准**，语法取 MajdataEdit + SimaiSharp 交集。

生成器输出必须满足：

1. **输出格式对齐 SimaiSharp Serializer 规范序列化**：`(bpm){拍号}` 开头 → 每拍物件后写 `,` → 以 `E` 结尾。
2. **禁用清单**（跨工具分歧项）：
   - ❌ hold 时长 `[##秒]`（SimaiSharp 报错）→ 用 `[#秒]` 或 `[x:y]`
   - ❌ Touch `C2`（MajdataEdit 报错）→ 用 `C` 或 `C1`
   - ❌ Slide 加 `x`（SimaiSharp 报错）→ EX 只用于 Tap/Hold
   - ❌ 装饰符 `@`、`m`、`$`、`$$`（MajdataEdit 不支持/不一致）
   - ❌ slide 时长 `[秒]` 无冒号形式（MajdataEdit 校验器不认）→ 用 `[x:y]` 或 `[秒##秒]`
   - ❌ 组合星星时长混合写法（SLIDE CHAIN ERROR）
   - ❌ 同头星星用 `/` 分隔（重叠星星头）
   - ❌ 拍号用 `{#秒}` 小数形式 → 只用整数拍号
   - ❌ 单个 `|` 注释 → 用 `||`
   - ❌ 连续 BPM 标记 / 连续分音标记
   - ❌ 缺结尾 `E`
3. **slide 端点规则**（§4.6 表，生成时必须校验）。
4. **分音 x 必须为 384 的约数**。
5. **最终校验**：用 SimaiSharp 做 lint（异常带 line+character 可定位），MajdataEdit 校验器作辅助。

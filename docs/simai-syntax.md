# simai 语法规范（调研定稿）

> **状态**：v1.0 定稿（2026-09-10）。三路调研合流：① 官方 simai wiki（记法定义者 Celeca 的规范，经 Wayback 快照）② 社区解析器源码分析（MajdataView/MajdataEdit/SimaiSharp/MaiLib/maidata-rs）③ 中文社区调研（MMFC 教程、B站教程、无理综述）。**交叉核实结论：核心语法三方一致，初稿无推翻项；分歧点全部标注于 §6/§8。**
> **配套文档**：`docs/simai-error-checking.md`（报错判定逻辑，另文）；三份原始调研报告见 `docs/research/`；**ST 谱面要素年表与黑白名单见 `docs/st-chart-elements.md`**（本项目只生成 ST 谱，DX/FESTiVAL 要素禁用）。
> **本项目定位**：生成器产出的 maidata.txt 需在 Majdata 生态与 AstroDX（SimaiSharp）中零报错。官方 simai 语为权威基准，Majdata 语法宽松（其 README 自述），不能作为兼容性基准。

## 0. 阅读说明

- simai 是**纯文本制谱语言**，用相对时间描述音符：BPM + 分音 + 逗号（时间槽），而非绝对时间戳。
- 所有符号均为**半角英文符号**。
- 版本背景：simai 语由 Celeca 于 2013 年定义；历经 simai/2simai/3simai；官方软件 2023-02-05 停止公开，规范保留，各模拟器（Majdata、AstroDX 等）沿用并有各自扩展。官方规范明言："这里只列出被正式定义为 simai 语的记法，各模拟器可能有自己的扩展。"

## 1. 设计原理

1. **相对时间**：BPM 标记 `(bpm)` 定义速度，分音标记 `{x}` 定义"一个逗号 = x 分音符"，逗号 `,` 是时间推进单位。
2. **槽长公式**：槽长(秒) = 240 / BPM / 分音数。例 `(120){4}` 每槽 0.5 秒；HOLD/SLIDE 移动时长 `[x:y]` = (240/BPM/x)×y 秒。
3. **没有小节线、没有拍号指令**：隐含 4/4（一小节 = 4 个四分音符）；竖线 `|` 不是小节线（只出现在注释 `||` 中）；没有 `(time)` 时间标记语法（秒数用 `{#秒}` 表达）。
4. **最细分音**：社区规范中最小时间单位为 **384 分音**——分音 x 必须是 384 的约数（4、8、12、16、24、32、48、64、96、192、384 合法；100 不合法）。
5. **键位编号**：**1 号在屏幕右上（1 点钟方向），顺时针编号 1→8**：
   ```
   　⑧①　
   ⑦　　②
   ⑥　　③
   　⑤④　
   ```

## 2. 文件结构

### 2.1 必需文件（文件名固定）

| 文件 | 必需 | 说明 |
|------|------|------|
| `maidata.txt` | ✅ | 谱面本体（meta + simai 正文） |
| `track.mp3` | ✅ | 音源（astrodx 亦接受 ogg） |
| `bg.jpg` / `bg.png` | 否 | 背景图（建议 1080×1080） |
| `pv.mp4` / `bg.mp4` | 否 | 背景视频 |

音源建议：44100Hz、CBR ≥ 192kbps 的 mp3。**文件编码：UTF-8（建议带 BOM，杜绝探测歧义）。**

### 2.2 meta 指令（文件头 `&key=value`）

每条 `&key=` 另起一行、值可跨多行（下一个 `&` 行结束）。官方未规定顺序（惯例顺序仅供参考）。**转义规则**：meta 文本中的半角 `&` `+` `%` `\` 必须写成 `\＆` `\＋` `\％` `\￥`（半角 `\` + 全角字符）；全角 ＆＋％ 可直接用。

官方定义变量（wiki 变量页 510）：

| 指令 | 含义 | 备注 |
|------|------|------|
| `&title=` | 曲名 | `┃` 之后的文字显示为小字副标题 |
| `&artist=` | 艺术家 | |
| `&smsg=` | 单条留言 | 选曲/播放画面显示；`┓` 换行（最多 3 行） |
| `&des=` | 谱师名 | |
| `&first=` | 谱面起始偏移（秒，可小数） | 音乐播放 first 秒后第一个逗号开始计时 |
| `&lv_1=` … `&lv_7=` | 各难度等级 | 1=EASY…5=MASTER,6=Re:MASTER,7=ORIGINAL；可写 `13+`（+半角）、`※X` 自定义 |
| `&inote_1=` … `&inote_7=` | 各难度谱面正文 | `=` 后到下一个 `&` 行之间的全部内容 |
| `&amsg_*=` | Active Message 歌词字幕 | 进阶功能，生成器初期不用 |

另有 `_N` 后缀变体：`&smsg_N=` `&des_N=` `&first_N=`（选该难度时优先于无后缀版）。
社区普遍使用（非官方 wiki 定义但各播放器透明忽略，输出无害）：`&wholebpm=`（整曲 BPM）、`&freemsg=`、`&tap_ofs=` 等判型 offset。

**生成器最低输出**：`&title=`、`&artist=`、`&des=`、`&first=0`（注意转义）+ 谱面正文（可写 `&inote_5=` 或直接正文）。

## 3. 时间标记

### 3.1 BPM 标记 `(bpm)`
- 小括号内写数字，**可为小数**（如 `(174.5)`）。从该处生效直到下一个 BPM 标记或谱面结束。
- 必须位于一拍开头；**BPM 必须写在分音之前**（`(120){4}` ✓，`{4}(120)` ✗）。
- ⚠️ 不要连续写两个 BPM 标记；`(#...)` 不是合法写法。

### 3.2 分音标记 `{x}`
- 大括号内写整数 x = 之后一个逗号代表的 x 分音符：`{4}` 四分音符/槽、`{8}` 八分、`{16}` 十六分。
- x 必须是 384 的约数（见 §1.4）。⚠️ 不要连续写两个分音标记。
- 变更分音后，从下一个逗号起按新分音计。

### 3.3 秒数槽 `{#秒}`（官方语法）
- 直接指定每槽秒数（BPM 不明/人声对齐时用），如 `{#0.35}`。
- 历史：2023-06 快照曾误写 `(#0.35)`，官方已更正为 `{#秒}`；SimaiSharp 只接受 `{#...}`。
- ⚠️ 跨工具策略：MajdataEdit 校验器要求 `{}` 内容为整数 → **生成器避免使用**，用 `(bpm){x}` 组合表达。

### 3.4 逗号 `,` 与空拍
- 每个逗号推进一个槽（当前分音单位）。连续逗号 = 休止。
- 谱面最后以 `E` 结束；`E` 前每个逗号段须完整。

### 3.5 结束标记 `E`
- 正文末尾写**大写** `E`（`e` 无效）。不写则播到音频结束。
- ⚠️ 结束点不能超过音频长度（超出部分不播放）；HOLD/SLIDE 进行中途结束会丢分。
- 跨工具零报错：必须写 `E`（SimaiSharp Serializer 也强制输出）。

### 3.6 注释 `||`
- `||` 起至行尾为注释；**必须以换行结尾**否则不生效；注释内禁用半角 `&` `+` `%`。
- ⚠️ 单个 `|` 会报错（SimaiSharp）。

## 4. 物件标记（note）

### 4.1 键位与判定区
- 键位 1-8（§1.5 图）。
- Touch 判定区（DX 共 34 区）：**A 组**（紧邻按键，8 区）、**B 组**（A 与中央之间，8 区）、**C 组**（中央，2 区：C1 在右、C2 在左）、**D 组**（填充 A 组之间，8 区）、**E 组**（D 稍内侧靠 B，8 区）；组内顺时针编号。写法 = 字母+数字（字母大写），中央写作 `C`。
- `C`/`C1`/`C2` 官方等价（均落正中央）。⚠️ 跨工具：MajdataEdit 校验器只认 `C`/`C1` → 生成器只写 `C` 或 `C1`。

### 4.2 TAP
- `1`-`8` 单个数字。`1b` = BREAK TAP（b 必须在数字后，`b1` 非法）。
- `1x` = EX TAP；`1bx` = BREAK+EX TAP（b/x 顺序任意）。

### 4.3 EACH（多押）与伪 EACH
- `/` 分隔同一槽内任意数量的多押成员；顺序无关（先写的 SLIDE 显示在前）。
- **纯 TAP（非 BREAK）多押可省略 `/`**：`12`、`123` 合法；**只要成员里有非 TAP 或 BREAK，`/` 不可省略**。
- EACH 成员变黄（BREAK 除外）；同刻启动的多条 SLIDE 视为 EACH。
- **伪 EACH**：反引号 `` ` `` 分隔，后面的比前面的**晚 1ms**（官方定义；MajdataEdit 实现为 1/128 拍，MajdataView wiki 写 0.001s，以官方 1ms 为准）→ 不变黄、不计 EACH。可连续 `` 1`2`3/4 ``。

### 4.4 HOLD
- 通式 `键位h[时长]`。官方三种时长形式：
  | 形式 | 含义 | 例 |
  |------|------|-----|
  | `[x:y]` | x 分音符 × y 个（秒 = 240/BPM/x×y；可约分应约分） | `5h[2:1]`、`4h[8:3]` |
  | `[#秒]` | 直接秒数 | `4h[#5.678]` |
  | `[BPM#x:y]` | 按指定 BPM 计算 | `4h[150#2:1]` |
- `3h`（省略时长）= "伪 TAP"（六角形 TAP 效果，内部等价 `[1280:1]`）。
- 修饰符与 h 顺序任意：`5hb[2:1]`≡`5bh[2:1]`（BREAK HOLD）、`3hx[2:1]`（EX HOLD）、`7bxh[4:1]`（BREAK+EX HOLD）。
- ⚠️ 禁用：`[##秒]`（MajdataView wiki 笔误，SimaiSharp 拒绝）、`h[X]`/`h[#X:Y]`（仅 bilibili 转述，官方与参考实现均不支持）。
- 注意：不带 `h` 但带 `[…]` 的 note 会被 SimaiSharp 视为 Hold → TAP 不要加时长标记。

### 4.5 TOUCH 与 Touch-Hold
- Touch：`A1`-`E8`、`C`、`C1`。Touch-Hold：`Ch[4:3]`。
- simai 语法允许任意区 TouchHold，但官方谱面只有 C 区出现过、**MajdataView 显示层仅支持 C 区** → 生成器只在 C 区写 TouchHold。
- `f` = 烟花特效（`B7f`、`Chf[1:2]`，`hf`≡`fh`），纯视觉。`Ch`（省略时长）= 伪 TOUCH。
- Touch 无 BREAK、无 EX。

### 4.6 SLIDE（星星）

基本格式：`<起始键位><形状><终止键位>[时长]`。例：`1-4[8:3]` = 1→4 直线，移动耗时 8 分×3。

> **启动拍机制（官方语义，生成器必须建模）**：星形 TAP 到达判定线后，引导星**等待 1 拍（四分音符，60/BPM 秒）**再开始移动——**与当前 `{x}` 分音无关**。启动拍不可随意修改（乱改会产生撞尾/多押无理，见知识库 014）。⚠️ SimaiSharp 实现疑随 `{x}` 变化（见 §8），生成器按官方语义、校验时写回归测试。

#### 形状符号表（官方 + 三源交叉）

| 符号 | 形状 | 端点约束（官方） | 备注 |
|------|------|------------------|------|
| `-` | 直线 | 终点与起点至少隔一键（1 号不能终点 1/2/8） | 基础形状 |
| `^` | 圆弧，自动取最短路径 | 终点不能是起点正对面；官方确认相邻键（如 `1^2`）合法 | 最常用 |
| `>` | 圆弧，沿判定圈向右 | 建议至少隔一键（无官方硬限制） | 上半屏键(1,2,7,8) `>`=顺时针；下半屏键(3,4,5,6) `>`=逆时针 |
| `<` | 圆弧，沿判定圈向左 | 同上 | 与 `>` 相反 |
| `v` | 小 V 形：经 C 区转折 | **终点不能是自身、不能是正对面**（`1v1` 非法；`1v2/1v3/1v4` 合法） | |
| `V` | 大 V 形/屈折形，**三键记法** `1V36`（起点V转折点终点） | 转折点只能是起点的"2 个键位之外"（1 号只能在 3 或 7 转折）；1 在 3 转折后终点不可为 1/2/3/4 | 起点→转折点短直线，转折点→终点任意长直线 |
| `q` | 绕中央（C 区）一周曲线，**顺时针** | 终点任意（含自身） | `5qq5` 官方谱出现心形 |
| `p` | 同上，**逆时针** | 终点任意（含自身） | |
| `qq` | 绕"中央—外圈切线圆"大弧，**顺时针** | 终点任意（含自身） | |
| `pp` | 同上，**逆时针** | 终点任意（含自身） | |
| `s` | 闪电形（3 段短直线折线） | **终点必须是对角（正对面）键** | 折点：先经 B(X+6) 再 B(X+2) 到 A(Y) |
| `z` | 闪电形（反向） | **终点必须是对角键** | 折点：先经 B(X+2) 再 B(X+6) |
| `w` | 扇形/Wifi | **终点必须是对角键**；展开为覆盖 3 个端点的扇形、产生 3 颗引导星（等效三条独立直星） | **视作双手配置**；`w` 之后不能再接连锁段 |

- 对向（正对面）键：相隔 4 键（180°），1↔5、2↔6、3↔7、4↔8。
- 全 SLIDE 移动速度恒定（任何形状中途不变速）。
- ⚠️ 官方"始点-终点关系表"是图片（64 格矩阵），本调研未能逐格转录——生成器严格校验前需人工/视觉模型对照补齐（URL 见 §8）。

#### 时长标记 `[ … ]`（6 种官方形式）

| 写法 | 等待时间 | 移动时间 |
|------|----------|----------|
| `[x:y]` | 当前 BPM 一拍 | 当前 BPM 的 x 分×y |
| `[BPM#x:y]` | BPM 的一拍 | BPM 的 x 分×y |
| `[BPM#秒]` | BPM 的一拍 | 直接秒数 |
| `[秒##秒]` | 直接秒数 | 直接秒数 |
| `[秒##x:y]` | 直接秒数 | 当前 BPM 的 x 分×y |
| `[秒##BPM#x:y]` | 直接秒数 | 指定 BPM 的 x 分×y |

SimaiSharp 另接受 `[#秒]`（移动秒数、等待默认一拍）。⚠️ `[秒]`（无冒号单值）MajdataEdit 校验器不认 → 生成器不用。

#### 组合（连锁）SLIDE（FESTiVAL）
- 多段首尾相接：`1-4q7-2[1:2]`（总时长写在最后，全程匀速）；或每段各自给时长 `1-4[2:1]q7[2:1]-2[1:1]`（官方允许）。
- **官方：分段写时必须给全每一段时长，缺任一报错**；总时长形式与分段形式不可混用。
- ⚠️ 跨工具：每段独立时长的写法（token 含 >1 个 `[…]`）在 **MiaCode strict 模式会报错**（"Slide 时值块位置可能导致转谱错误"）→ **生成器统一用"总时长在最后"形式 `1-4q7-2[1:2]`**。
- 连锁 BREAK：只能在**最后一个 `]` 后**加 `b`，整条为 BREAK，不能局部 BREAK。

#### 同始点 SLIDE（multi-slide）
- `*` 连接、后续段省略起点：`1-4[4:3]*-6[8:5]`；星同时启动 → 相互构成 EACH。
- ⚠️ 禁用 `/` 写同始点（`1-4[8:1]/1-6[8:1]` 制造两个重叠星星头，无法游玩）。

#### 滑轨/星头的 BREAK 与 EX 位置
- 滑轨 BREAK（官方写法）：`1-4[8:3]b`（b 在 `]` 后）；MajdataView wiki 写 `1-4b[4:1]`（b 在 `[` 前），SimaiSharp 两种都接受 → **生成器用官方形式 `]b`**。
- 星头 BREAK：`1b-4[4:1]`（计数 BREAK 1 + SLIDE 1）。
- 星头 EX：官方允许 `2x-4[4:1]`；⚠️ SimaiSharp 对 slide 上的 `x` 抛异常 → **生成器禁用**。
- 可分别修饰：`7bx-2[8:1]b`（星头 BREAK+EX、滑轨 BREAK）。

### 4.7 修饰符汇总

| 修饰符 | 含义 | 适用 | 生成器策略 |
|--------|------|------|-----------|
| `b` | BREAK（严判、加分、失误多扣分） | Tap/Hold/滑轨/星头 | ✅ 使用 |
| `x` | EX（GOOD 以上都按 CRITICAL PERFECT 计） | Tap/Hold/BREAK/星头(官方)；滑轨不可 | ✅ 使用（禁用于 slide） |
| `f` | 烟花特效（纯视觉） | Touch/TouchHold | ✅ 可用 |
| `$`/`$$` | Tap 强制星形/星形旋转（官方） | Tap | ⚠️ 可选；MajdataEdit 校验器对 `1$`/`1$$` 接受、对 Hold 上 `$` 拒绝 → 仅 Tap 可用，默认不用 |
| `@` | Slide 星头强制还原为圆形 Tap（官方） | Slide 头 | ❌ MajdataEdit 不支持 → 禁用 |
| `!`/`?` | 无星头 Slide：`?` 渐显式、`!` 突现式（官方） | Slide 头 | ⚠️ 可用（MajdataEdit/SimaiSharp 支持；MaiLib 不支持） |
| `m` | Mine 地雷 | — | ❌ 仅 SimaiSharp 内部扩展 → 禁用 |

## 6. 零报错安全子集（生成器强制规则）

> 依据：MajdataView README 自述语法宽松（Majdata 能跑的谱面未必能在 simai/Astro 运行）。**以官方 simai 语为语法基准、以最严格的 SimaiSharp 为最终 lint**（异常带行列可定位），语法子集取 MajdataEdit + SimaiSharp 交集。

生成器输出必须满足：

1. **输出格式对齐 SimaiSharp Serializer 规范序列化**：`(bpm){分音}` 开头（BPM 在前）→ 每拍物件后写 `,` → 以大写 `E` 结尾。文件 UTF-8（建议 BOM）。
2. **时值换算**：槽 = 240/BPM/分音；HOLD `[x:y]` = (240/BPM/x)×y；SLIDE 启动拍 = 60/BPM（固定一拍）。
3. **禁用清单**（跨工具分歧项）：
   - ❌ hold 时长 `[##秒]`、`h[X]`、`h[#X:Y]` → 用官方三形式
   - ❌ Touch `C2`（MajdataEdit 报错）→ 用 `C` 或 `C1`
   - ❌ Slide 上加 `x`（SimaiSharp 抛异常）
   - ❌ 装饰符 `@`、`m`；Hold 上的 `$`
   - ❌ slide 时长 `[秒]` 无冒号单值形式 → 用 `[x:y]` 或 `[秒##秒]`
   - ❌ 组合星星时长混合写法 / 分段缺时长（SLIDE CHAIN ERROR）；连锁 slide 统一用"总时长在最后"形式（分段独立时长在 MiaCode strict 报错）
   - ❌ 同头星星用 `/` 分隔（重叠星星头）
   - ❌ `{#秒}`（官方合法但 MajdataEdit 校验器拒）→ 用 `(bpm){x}`
   - ❌ 单个 `|` 注释 → 用 `||`（且以换行结尾）
   - ❌ 连续 BPM 标记 / 连续分音标记；`{4}(120)` 顺序颠倒
   - ❌ 缺结尾 `E`；小写 `e`
4. **slide 端点规则**（§4.6 表 + 待补的 64 格关系表），生成时必须校验。
5. **分音 x 必须为 384 的约数**。
6. **meta 转义**：title/artist/des 中的半角 `&` `+` `%` `\` 按 §2.2 转义。
7. **最终校验**：SimaiSharp lint（零异常）+ MajdataEdit 校验器（零错误零警告）双检。

## 8. 存疑 / 待核实

1. **SLIDE 始点-终点关系表**：官方表为图片（https://img.atwiki.jp/simai/attach/1003/54/slides_eng.png ），64 格矩阵需人工/视觉模型对照补齐。**已找到机读替代**：MiaCode 的 `assets/reference/slide_data.json` 提供 608 个合法 slide shape key + 8 个 wifi key 白名单（`^` 折叠为 `</>` 后查表），生成器校验可直接复用/对齐该数据源；人工对照图片仅作交叉验证。
2. **扇形 w 的 3 个端点**：是否恒为"对角键 + 环上两邻键"需对照官方图或实测。
3. **SimaiSharp 两处疑似 bug**：(a) 启动拍随 `{x}` 变化（官方固定 60/BPM 一拍）；(b) p 形序列化误输出 `pp`。本项目直接依赖 SimaiSharp 时要写回归测试。
4. **`fi` 属性**：权威来源中不存在；最接近的是烟花 `f`。
5. 键音记法、`(time)` 时间标记：simai 语中均不存在。
6. `^` 相邻键（如 `1^2`）：官方评论区确认合法；关系表图是否标为允许需对照。

# ST 谱面要素年表（核对稿）

> **目的**：本项目只生成 **ST（通常）谱面**，因此只需关注 **FiNALE（2018-12-13）及以前** 的旧框要素；DX（でらっくす，2019-07-11）及以后的特性一律不采用。
> **来源**：MMFC《MAIMAI 谱面创作基础学 长篇指南》§1.2（用户提供 PDF）+ 日语 Wikipedia 版本日期交叉核对 + 本机 388 个官方 ST 谱面（13.0–14.5 定数）实证统计。

## 一、版本要素年表（只列"新增谱面要素"的版本）

| 版本 | 稼働日 | 新增谱面要素 |
|------|--------|--------------|
| maimai（初代） | 2012-07-11 | TAP、HOLD、BREAK（无分数加成）；SLIDE 仅直线与贴边弧线，**长度限定 3 格**；不存在短星星/折线/wifi/同头星星。HOLD 为圆滑边框样式 |
| maimai GreeN | 2013-07-11 | 无新要素 |
| **maimai GreeN PLUS** | **2014-01-31**（书载 2014-02-26，以 Wikipedia 为准） | BREAK 内置严判（2600/2500 分数增益）；HOLD 样式改六边形；SLIDE 大量更新：小折线 `v`、二重折线 `s`/`z`、短直线（`1-3`）、环绕中心区曲线 `q`/`p`（`1q4`/`1p8`/`1q5`）、长弧线（`1>8`） |
| ORANGE / ORANGE PLUS | 2014-09-18 / 2015-03-19 | 无新要素 |
| **maimai PiNK** | **2015-12-09** | **旧框时代最后一次添加新谱面要素**。五大要素：WIFI 星星 `w`、星星绝赞头（break slide head）、大折线星星 `V`、同头星星 `*`、ppqq 大曲线（不绕中心区）。此后仅有微小更新：MURA/MILK 附近绝赞判定色蓝→黄、HOLD 正确提示色粉→黄 |
| PiNK PLUS / MURASAKi(PLUS) / MiLK(PLUS) / **FiNALE** | 2016-06-30 … **2018-12-13** | 无新谱面要素（书："pink 是旧框时代最后一次添加新的谱面要素的版本"） |
| ~~maimai でらっくす（DX）~~ | 2019-07-11 | ~~去除 HOLD 尾判；EX TAP/EX SLIDE 头；Touch / Touch HOLD（仅 E/B/C 区）~~ **ST 谱不用** |
| ~~FESTiVAL~~ | 2022-09-15 | ~~拼接（连锁）星星；Break Slide（滑条绝赞）；Break/Ex HOLD；A/D 区 Touch；EX Break~~ **ST 谱不用** |

## 二、ST 谱面要素白名单（生成器可用）

- **TAP**（1-8）、**HOLD**（含短 hold）、**BREAK**（`b`）
- **SLIDE 全 12 形状**：直线 `-`、贴边弧线 `^` `>` `<`、折线 `v`、大折线 `V`、绕心曲线 `q` `p`、绕大圈 `qq` `pp`、闪电 `s` `z`、扇形 `w`
- **星星头绝赞**（`1b-4[8:1]`，b 在形状前）、**同头星星**（`1-4[8:1]*-6[8:1]`）
- 组合（GreeN PLUS 起的多段拼接式写法在旧框是否可用待定——见 §三 存疑）

## 五、存疑

1. **组合星星的旧框可用性**：MMFC 教程把"拼接（组合）星星"列为 FESTiVAL 要素（"fes 拼接星星"），388 个 ST 谱中连锁写法 0 使用——与年表一致，ST 谱不使用组合星星。但注意：simai 语法层"多段首尾相接"写法在旧框谱面数据中不存在，生成器在 ST 谱中不写组合星星。
2. 初代"三种样式"的精确所指（直线 + 两种方向弧线？）书中未逐格列出，不影响生成器。
3. GreeN PLUS 日期：书载 2014-02-26，Wikipedia 载 2014-01-31，已按 Wikipedia 记录。

## 1. 方法与口径

### 1.1 时间轴与小节

simai 没有小节线、没有拍号指令（`docs/simai-syntax.md` §1.3），隐含 4/4。因此：

- 一个逗号推进 `4 / 分音` **拍**、`(240 / BPM) / 分音` **秒**；
- **小节 = 4 拍**，小节号 `= floor(拍位置 / 4)`，从 0 起；**BPM 变速不改变小节划分**（这正是
  用"拍"而非"秒"当主轴的原因——变速段若按秒切会把小节切碎）；
- 密度曲线的范围取「首个 note 所在小节 → 末个 note 所在小节」，开头的纯静默小节不计入。

### 1.2 note 计数口径

与 manifest（mai-notes / 查分器口径）对齐：`notes = taps + hold + slide + touch + breaks`。

- **星星头计入 TAP**（`*` 同头多 slide 只有一个星头）；
- **每条滑轨计 1 SLIDE**；首尾相接的连锁 slide（`1-4q7-2[1:2]`）**整体计 1**；`w`（Wifi）也计 1；
- **BREAK 从本类中移出、单列**；
- `3h`（省略时长的伪 TAP）仍按 HOLD 计。

完整口径与已知歧义（滑轨 BREAK 归属）见 `tools/chart_analysis/README.md`。

### 1.3 密度指标定义

| 指标 | 定义 |
|------|------|
| 逐小节密度 | 该小节内的 note 总数 |
| 归一化曲线 | 逐小节密度 ÷ 该谱峰值小节密度 → [0,1] |
| 32-bin 曲线 | 按面积加权重采样到 32 个等长区间，再除以自身峰值 |
| 休息小节 | note ≤ 1 的小节 |
| 低密段 | 连续小节，归一密度 ≤「全曲中位密度 × 0.5」 |
| 密度台阶（平台段） | 3 小节中值平滑 → 0.125 量化 → 长度 ≥ 4 小节的同档连续段 |
| 峰值位置 | 单小节最大密度处的相对位置 ∈ [0,1] |
| 高潮段位置 | **4 小节滑动均值**最大处的窗口中心（比单小节峰值稳健） |
| 等分五段画像 | 等分 5 段求均值，再除以 5 段最大值 → 与知识 001 的 T 同尺度 |
| 结构对齐五段画像 | L2 变点检测分 5 段（**带最小段长 10% 约束**），再除以 5 段最大值 |

> **方法学坑（务必记住）**：变点检测若不加最小段长约束，DP 会把「末尾一两个收尾小节」
> 单独切成一段——实测 **37.4% 的谱第 5 段短于全曲长度的 5%**。这会凭空制造出
> 「尾部渐弱」的假象。本报告全部结构对齐结果均带 `min_len_frac=0.10`。

## 2. 解析覆盖率与校验

### 2.1 覆盖率

| 项 | 结果 |
|----|------|

抓取残留文本 `ページ名またはURL`（重复 3 次），**是抓取污染而不是语法问题**。污染文本把
一个 BREAK TAP 的 `b` 从键位上挤开（`2/8ページ…b`），导致该 note 被判成普通 TAP：
**总 note 数仍与官方一致（464），但分项是 taps 417 / breaks 27，官方为 416 / 28。**
建议后续重抓该文件。

3 条告警（各 1 次，均已容错解析）：

1. `1[4:1]` —— TAP 带时长括号却缺 `h`，按 HOLD 处理（SimaiSharp 行为，语法文档 §4.4 末注）；
2. `1-5b[8:1]` —— 滑轨 BREAK 的 `b` 写在 `[` 之前（MajdataView 写法，官方形式是 `]b`）；

三个一眼可见的事实：

1. **开头 3 个 bin（前 ~9% 曲长）是唯一明显的爬坡**：0.46 → 0.57 → 0.60，之后就进入平台；
2. **中段（bin 4–19，约 12%–62% 曲长）几乎是一条直线**，稳定在 0.62–0.64；
3. **后段（bin 20–30，约 62%–97%）缓慢抬升到 0.73，是全曲最高**；只有最后一个 bin
   回落到 0.63——**这个回落只是"最后一两小节收尾"的边缘效应，不是段落级的"渐弱"**：
   末小节相对全曲均值的密度中位只有 0.73（37.9% 的谱末小节不到均值的一半），
   但**曲末 10% 整体的相对密度是 1.084 倍全曲均值**，曲末 5% 也有 1.047 倍。
   也就是说，减压只发生在最后一两个小节，而不是最后一个段落。

按难度/定数分组的曲线**形状几乎一致**，只是 Re:MASTER 起手更高（bin00 0.53 vs MASTER 0.45）、
14.5 档中段更"塌"（bin12–17 只有 0.50–0.55，说明高定数谱的高低落差更大）。

### 3.2 k-means 形状聚类

对 388 条 32-bin 曲线做 k-means（k-means++ 初始化 × 25 次重启）：

| k | inertia | 轮廓系数 |
|---|--------:|---------:|
| 3 | 390.26 | 0.0711 |
| 4 | 375.36 | 0.0678 |
| 5 | 364.43 | 0.0552 |

**轮廓系数全部 < 0.08 ——官方谱的密度曲线形状是一个连续谱系，没有清晰可分的"流派"。**
这是本节最重要的结论：不要把聚类结果当离散类别用，只能当作"典型倾向"的描述。

k=3 的三簇（按 inertia 最优取）：

| 簇 | 占比 | 峰位中位 | 形状特征 | 一句话描述 |
|----|-----:|---------:|----------|------------|
| 0 | 40.7% | 0.52 | 起手就 0.59、全程 0.68–0.81、无深谷 | **「全程高密平台型」**——从第一小节就压到接近峰值，起伏小，靠配置而非密度制造强度变化 |
| 1 | 33.5% | 0.60 | 0.37 起 → 前 1/4 快速爬到 0.64 → 中段平 → 后 1/3 再抬到 0.74 | **「双段递进型」**——弱起，两级台阶推到后段，最典型的"循序渐进" |
| 2 | 25.8% | 0.77 | 全程 0.37–0.55 徘徊，只在 bin22 之后冲到 0.60–0.64 | **「单峰后置型」**——大半首都克制，把密度全部留给最后 1/3 |

k=5 时会从簇 1 里进一步分出一个 **「中段挖谷型」**（n=67，17.3%，bin15–19 塌到 0.46–0.48、
bin22–26 冲到 0.79–0.82）——即"两个副歌之间挖一个明显的间奏/休息段"，这正是知识 002
描述的 SPICY SWINGY STYLE 叙事。

## 4. 知识 001 五段模板检验

知识 001 的量化候选：**T = [0.20, 0.45, 0.30, 1.00, 0.10]**，对应「弱 → 较强 → 较弱 → 强 → 渐弱」。

### 4.1 等分五段（按段长比例）

| 统计量 | 值 |
|--------|-----|
| 逐谱与 T 的 Pearson r | 均值 **0.125**，中位 0.196，r > 0 占 62.4% |
| 逐谱 RMSE | 均值 **0.539**，中位 0.544，p90 0.608 |
| 允许仿射变换后的 R²（`density ≈ a + b·T`） | 均值 **0.245**，中位 0.160，R² > 0.5 只占 17.0% |
| 数据估计模板（均值，归一到峰值） | **[0.81, 0.92, 0.91, 0.97, 1.00]** |
| 数据估计模板（相对全曲均值） | **[0.88, 0.99, 0.98, 1.06, 1.09]** |

序关系检验：

| 命题（来自 T） | 实测成立比例 |
|----------------|-------------:|
| 最强段落在第 4 或第 5 段 | 67.3% |
| 第 1 段最弱 | 48.2% |
| 第 2 段 > 第 3 段（"较强 → 较弱"的回落） | 48.5% |
| 第 5 段 < 第 4 段（"渐弱"） | **44.3%** |

**结论 A：T 的数值幅度被严重高估。** 等分五段下真实的段间落差只有
[0.81 … 1.00]（相对全曲均值 [0.88 … 1.09]），而 T 要求 [0.10 … 1.00]——**T 的动态范围
是真实值的约 4.5 倍。** 如果拿 T 当密度目标直接驱动生成，第 5 段只会给出 1/10 峰值的密度，
远低于官方谱的下限。

**结论 B：「渐弱淡出」在官方谱里不成立。** 第 5 段做到 0.97–1.00（全五段最高），
曲末 10% 的相对密度是 **1.084 倍全曲均值**，只有 32.2% 的谱曲末 10% 低于全曲均值。
官方谱**不收尾减压，而是把最后一段做成全曲最密**。

### 4.2 结构对齐五段（变点检测，最小段长 10%）

等分五段会把不同长度的乐段揉在一起，所以再做一次结构对齐的分割（n=388 全部成功）：

- 段长占比均值：`[0.206, 0.215, 0.186, 0.191, 0.202]`（近似等长，说明官方谱的结构分段本身就均匀）
- **估计模板（均值）= [0.619, 0.766, 0.721, 0.777, 0.817]**
  - 95% 自助 CI 下界 `[0.599, 0.747, 0.699, 0.755, 0.800]`
  - 95% 自助 CI 上界 `[0.639, 0.785, 0.744, 0.799, 0.835]`
- 中位模板 = `[0.626, 0.797, 0.727, 0.808, 0.841]`
- 段序（由弱到强）= **1 → 3 → 2 → 4 → 5**；T 的段序 = 5 → 1 → 3 → 2 → 4

**结论 C：T 的定性形状前四段完全正确，第五段完全错误。**

把两者的段序并排看：

```
T（知识 001）：  s1(弱) < s3(较弱) < s2(较强) < s4(强)      ，s5 最弱（渐弱）
实测（结构对齐）：s1(弱) < s3(较弱) < s2(较强) < s4(强) < s5(最强)
```

**前四段「弱 → 较强 → 较弱 → 强」的顺序被 388 谱完整验证**（s3 = 0.721 确实低于
s2 = 0.766，"较弱"的回落是真实存在的，只是等分切法会把它抹平）。
唯一被推翻的是第五段：**官方谱的第 5 段是全曲最强（0.817），而不是 T 说的 0.10。**

逐谱与 T 的相关只有 0.094（中位 0.087）——相关系数被第 5 段这一项彻底拖死。

### 4.3 密度的"地板"

为什么真实模板这么平？因为**谱面密度有可玩性地板**：任何一小节只要还在出音，
就得给出基本的踩音密度。实测各谱归一化逐小节密度的分位数（对 388 谱取均值）：

```
p10 = 0.264     p50 = 0.514     p90 = 0.730
```

即**典型小节的密度只有峰值的一半，最低的 10% 小节也还有峰值的 26%**。
段落尺度上这个地板被进一步抬高到 0.62（结构对齐五段的最弱段）。

**这正是「强度曲线 → 谱面密度」映射要建模的核心非线性：音频强度可以逼近 0，
谱面密度不能。** 建议的映射形式：

```
density_norm = floor + (1 - floor) · intensity_norm
```

- 段落尺度（用于给每段定基调）：`floor ≈ 0.60`
- 小节尺度（用于段内细分）：`floor ≈ 0.25`

**知识 002 的「第二副歌相对第一副歌升级」得到量化支持**：约 8 成官方谱后半程高密段比前半程更强，
中位提升 **约 12%**。但注意这只是**密度**尺度的提升；知识 002 说的升级也包含"单星星 → 双手星星"
这类**配置**升级，配置维度不在本报告范围内。

### 5.3 休息段

| 指标 | 值 |
|------|-----|
| 有至少 1 个休息小节（note ≤ 1）的谱 | **64.9%** |
| 每谱休息段（连续休息小节）数 | 均值 1.57 段 |
| 休息段长度 | 均值 1.37 小节，中位 1，p90 2，最长 7 |
| 休息小节占全曲比例 | 均值 **2.43%** |
| 休息段起点相对位置 | 中位 0.544 |
| 低密段（< 中位密度 × 0.5）每谱数量 | 均值 **5.91 段**，平均长 1.69 小节 |
| **"夹在两个高密段之间"的低密段** | 每谱均值 **2.41 段**；**61.9% 的谱至少有 1 段** |
| 密度台阶（≥ 4 小节同档平台） | 每谱均值 **7.09 个**，中位 7 |

**结论**：

1. **真正的"空小节"很稀缺**——休息小节只占全曲 2.43%，且 35% 的谱一个都没有。
   官方谱的"休息"主要靠**低密段**（每谱近 6 段、每段 1–2 小节）实现，而不是真的停手。
2. **"高密 → 低密 → 高密"的三明治结构是主流**：61.9% 的谱至少出现一次，平均每谱 2.4 次。
   这直接对应知识 002 的「高强度段落之间插入低强度的休息段」。
3. **每谱约 7 个密度台阶**——曲子被切成约 7 个"密度基调"不同的平台段。
   考虑到中位小节数 85，**平均每 12 小节换一次密度基调**。这是生成器做段落规划时的天然粒度。

## 6. 个案：785-SPICY SWINGY STYLE-mas（MMFC 教程举例）

定数 13.4，官方 660 note，解析 660 note（**完全一致**），114 小节，113.9 秒，BPM 242。

### 6.1 结构对齐的自动分段结果

### 6.2 与知识 002 的三点对照

1. **副歌前的"深呼吸"**：M48 是整首唯一的 0-note 空小节，紧接着 M49 就是全曲峰值（12 note）。
   "休息段紧贴高潮"这个手法在这首里是教科书级的。
2. **第二副歌 vs 第一副歌**：密度 7.06 vs 6.72，**只提升 5.1%**；BREAK 数 7 vs 6。
   **密度几乎没变**——这恰好印证知识 002 的原话「第二副歌与第一副歌**踩音相同**但**配置升级**」：
   升级发生在配置维度（单星星 → 双手星星），不在密度维度。
   **⚠️ 推论**：不能把"第二副歌更强"一律翻译成"第二副歌更密"。
3. **该谱的等分五段画像 = [1.00, 0.81, 1.00, 0.98, 0.98]，与 T 的相关是 −0.085（负相关）。**
   而结构对齐五段画像 = **[0.899, 0.469, 0.927, 0.602, 1.000]**——呈"强-弱-强-弱-最强"的
   **双峰 + 段间挖谷**形态，和 T 的单峰形态完全不同。
   这再次说明：**等分切法会毁掉结构信息，且 T 的单峰假设对双副歌曲不成立。**

## 7. 对知识 001 的修订建议（只提建议，不改条目）

> 以下 5 条建议供用户裁决。证据全部来自 388 个官方 ST 谱（定数 13.0–14.5），
> **样本不覆盖 12 级及以下、也不覆盖 DX 谱**，外推需谨慎。

### 建议 1（高置信）：把 T 拆成两个量，不要混用

知识 001 现在的 T 既被描述为「**歌曲情绪**走势」，又被写成「用于强度曲线 DTW 匹配」的参数。
本次测的是**谱面密度**，不是音频强度。建议在条目里明确区分：

- `T_audio` —— 音频强度曲线的形状先验（**本次未测，仍标"待标定"**，需要真实音频分析才能标定）；
- `T_density` —— 谱面密度的形状先验（**本次已标定**，见建议 2）。

### 建议 2（高置信）：`T_density` 用实测值替换 T

- **推荐值（结构对齐五段，归一到峰值 = 1）**：
  **`T_density = [0.62, 0.77, 0.72, 0.78, 0.82]`**
  95% 自助 CI：`[0.60–0.64, 0.75–0.79, 0.70–0.74, 0.76–0.80, 0.80–0.84]`（n = 388）
- 等分五段口径下则是 `[0.81, 0.92, 0.91, 0.97, 1.00]`（相对全曲均值 `[0.88, 0.99, 0.98, 1.06, 1.09]`）。
- 使用时必须同时注明口径（结构对齐 / 等分），两者不可混用。

### 建议 3（高置信）：删掉"渐弱淡出"，改成"末段最强"

原文「大多数歌曲的情绪呈"弱 → 较强 → 较弱 → 强 → **渐弱淡出**"的走势，谱面强度也应遵循这一模式」
的最后一环与官方谱**明确矛盾**：

- 第 5 段实测 0.817，是五段最高；
- 曲末 10% 的密度是全曲均值的 1.084 倍，只有 32.2% 的谱曲末低于均值；
- 24.2% 的谱把高潮段放在最后 10%（最大众数）。

建议改写为「**弱 → 较强 → 较弱 → 强 → 最强（不减压收尾）**」，并注明：
"歌曲可能淡出，但**谱面不跟着淡出**——官方谱把最后一段做成全曲最密，收尾只在最后 1–2 小节。"

### 建议 4（高置信）：补上"密度地板"这条非线性

新增要点：**谱面密度不与情绪强度线性对应，存在可玩性地板。**

- 小节尺度：归一密度 p10 = 0.264、p50 = 0.514、p90 = 0.730（峰值 = 1）；
- 段落尺度：最弱段 ≈ 0.62；
- 建议映射：`density_norm = floor + (1 − floor) · intensity_norm`，
  段落尺度 `floor ≈ 0.60`、小节尺度 `floor ≈ 0.25`。

不加地板直接用 T 驱动生成，会产出官方谱里根本不存在的"空段"。

### 建议 5（中置信）：补上"强度 ≠ 密度"的警告

SPICY SWINGY STYLE 的第二副歌只比第一副歌密 5.1%，而知识 002 说它"配置升级"。
全库层面也一致：后半 / 前半强度比中位只有 1.119。建议在知识 001 中补一句：

> **强度提升不等于密度提升。** 官方谱后半程副歌相对前半程的密度提升中位只有约 12%；
> 更大的强度差异由配置复杂度（知识 003 的四大因素）承担，密度只是其中一个维度。

### 附：不建议改的部分

- 「谱面强度必须随歌曲情绪起伏、不能全程匀速」——**部分成立但要打折**：
  40.7% 的官方谱属于聚类簇 0「全程高密平台型」（曲线在 0.68–0.81 之间几乎不动），
  它们的强度变化主要靠配置而非密度。建议保留原则，但补一句"密度起伏不是唯一手段"。
- 「段落意识：先划段再定基调」——**强支持**。实测每谱约 7 个密度台阶、平均每 12 小节换一次基调，
  变点检测能从密度曲线里直接还原乐曲段落边界（SPICY 个案 4/4 命中）。

## 8. 局限

1. **只覆盖 ST 谱、定数 13.0–14.5、MASTER/Re:MASTER**。12 级及以下、DX 谱、低难度谱未测。
2. **密度 ≠ 强度**。本报告只量化了 note 数量维度，没有量化配置复杂度、位移量、手序难度。
   知识 003 的"四大因素"里只覆盖了一个。
3. **小节划分假定 4/4**。变拍曲目的小节边界会与乐谱错位。
4. **语料是社区转录**（mai-notes），不是 SEGA 原始数据；note 总数有 2.84% 的谱存在 ±1～±3 的转录差，
   1 个谱（`66-ワールズエンド・ダンスホール-mas`）含抓取污染文本。
5. **k-means 轮廓系数 < 0.08**，聚类只能当"倾向描述"，不是可判别的类别。
6. **副歌位置是用密度推断的，不是用音频标注的**。"第一副歌/第二副歌"的划分在全库层面
   只用了"前半 / 后半"这个粗代理；SPICY 个案的段落名是人工对照知识 002 贴上的。

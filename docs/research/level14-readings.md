## 重要发现：BPM 与分音值的补偿关系（第三轮）

精读 14.4 组时出现一个**反复成立**的设计规律，值得单独提出：

| 谱面 | BPM | 主要分音 | 实际音/秒（16分基准） | 现象 |
|---|---|---|---|---|
| 375-7thSense | 150 | 16 → 32 → 512 | 10 / 20 | 低 BPM 用 32 分制造爆发 |
| 591-Moon of Noon | 200 | 8 / 16 / 32 | 13.3 / 26 | 高 BPM 以 8–16 分为主，32 分只做短 burst |
| 379-Contrapasso | 243 | 8 分为主 | 8 分 = 32/秒（滑条承载） | 极高 BPM 用 8 分 + 双星齐奏 |
| 393-Panopticon | 110 | 16 / 32 / 48 | 7.3 / 14.7 / 22 | 极低 BPM 用 48 分铺满 |
| 71-YA･DA･YO | 105 | 8 / 16 / 32 | 7 / 14 | 极低 BPM 用 32 分 burst + 跳拍 |
| 204-System“Z” | 147 | 16 为主 + `{1}` 长音 | 9.8 | 跳拍切分 |

**结论（候选，待用户确认）**：
1. **配置强度不等于 BPM**：低 BPM 谱用高分数值（32/48 分）补偿，高 BPM 谱用低分数值（8 分）+ 滑条承载。
2. **"实感密度"才是强度基准**：约 10–14 音/秒 = 14 级主线手感；20+ 音/秒只作为极短 burst 或滑条齐奏出现。
3. **低 BPM + 高分数值**会让**读谱难度**显著高于**手速难度**（Panopticon 110BPM/48分、YA･DA･YO 105BPM/32分空档）；**高 BPM + 低分数值**则相反（Contrapasso 243BPM/8分双星）。
4. 写作时可据此选择"BPM × 分音"的组合来把同一段音乐做成"读谱型"或"手速型"。

## ★ 时长读法更正（重要，2025 精读 14.3 组时发现）

**错误**：我在读 7thSense / 極圏 / 花と、雪と / Panopticon Re:MAS 时，把 `[512:1]`、`[1024:1]` 记成了"超长 hold / 缓段"。
**实际**：按 `docs/simai-syntax.md` §1 的槽长公式 —— **`[x:y]` = (240 / BPM / x) × y 秒**，x 是**分音数的分母**，x 越大时长越**短**：

| 写法 | 含义 | BPM 150 下的实际时长 |
|---|---|---|
| `[1:1]` | 1 个全音符 | 6.4 秒（超长） |
| `[4:1]` | 1 个 4 分音符 = 1 拍 | 1.6 秒 |
| `[8:3]` | 3 个 8 分音符 = 1.5 拍 | 2.4 秒 |
| `[16:3]` | 3 个 16 分音符 = 0.75 拍 | 1.2 秒… 实际上 0.3 秒（150BPM：240/150/16×3 = 0.3 秒） |
| `[32:3]` | 3 个 32 分音符 | 0.15 秒（极短星） |
| `[512:1]` | 1 个 512 分音符 | **≈ 0.003 秒（约 3 毫秒，等于零长 hold）** |
| `[1024:1]` | 1 个 1024 分音符 | **≈ 1.5 毫秒** |
| `[32:31]` | 31 个 32 分音符 = 3.875 拍 | 6.2 秒（长 hold） |
| `[16:31]` | 31 个 16 分音符 = 7.75 拍 | 12.4 秒（长 hold） |
| `[16:29]` | 29 个 16 分音符 = 7.25 拍（长星） | 11.6 秒 |
| `[1392:539]` | 539/1392 全音符 ≈ 1.55 拍 | 3.1 秒（Halcyon，非整数） |

**结论（对写谱的直接意义）**：
1. `[512:1]`、`[1024:1]` 是**毫秒级"零长 hold"**，功能上等于**断奏打点**，应归入"短 hold 链"家族，而非"缓段/呼吸"。
2. 真正的"缓段/呼吸"用的是 **`[1:1]`、`[2:1]`、`[4:1]`、`[16:31]`、`[32:31]`** 这类**大 y / 小 x** 的写法（如 468 的 `1h[16:31]/7h[16:31]`、Revive 的 `h[1:1]`、YA･DA･YO 的 `h[1:1]`）。
3. **写谱约定（自我约束）**：我们的生成器只输出**整数分音 + 适中 y** 的时长（如 `[4:1]`、`[8:3]`、`[16:3]`），不写 `[512:1]` 这类毫秒级写法，也不写 Halcyon 的浮点秒数写法。

  2. **前段**：星+单点流（星-单-单）+ 双押收尾 → 中高、密集

- **强度/难度分布（时间轴）**：
  1. **开头**：散点 16 分（4 行同型、换双押收尾）→ 中高，**读谱难**（无规律）
  2. **前段**：子弹+定拍混合（4 行）→ 手速与稳定性要求（同键成对连打）
  3. **中段（篇幅最大）**：长条+跳拍织体 → 强度中高但**节奏最难**（空拍切分与长条并行）

  3. **稀有星星**（V 折线双星、大曲线双星）作为"技术点"点缀
  4. **分音切换**（32→48→12→32）制造节奏变化，不靠变速
  5. **全绝赞收尾**（每音带 b）

- **问题/存疑**：长条+跳拍织体是否是该谱师/该曲的个性写法（后续谱面再对照）

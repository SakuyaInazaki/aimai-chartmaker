**为什么是 13.6 而不是 13.9 / 14.0**（知识 003 第 3 条、015、072）：

- 205 BPM 下 `{8}` = 6.83 键/秒、`{16}` = **13.67 键/秒**。持续 16 分交互在本曲等同于
  Halcyon（191 BPM `{16}` ≈ 12.7 键/秒，定数 14.3）的量级——**本曲写不起成段的 16 分**。
  所以全谱骨架是 **8 分**，16 分只在六处短爆发（m048 / m059 / m096 / m116 / m122 / m123），
  每处 ≤ 1 小节。这正是知识 **072** 说的"BPM 是分音与块长的旋钮"：
  ≥200 BPM 档官谱的 `{8}` 占比 61%、`{16}` 只剩 5%。
- 反过来，**曲子长**（可写 1–128 小节 = 149.9 s，比典型 120 s 长两成半），
  所以 918 这个总数看着接近 p90，换算成 NPS 只有 6.13，**正好落在 13.5 档的均值上**。
- 前奏 19 小节完全无鼓、breakdown 8 小节鼓全退，这两段把均值压下来；
  真正的难点集中在 ドロップ2（10.7 note/小节）。这是"定数由整曲摊平"的典型形态。

## 3. 几个具体决定，以及它们的依据

### 3.1 前奏 19 小节：为什么写得这么稀、又不敢更稀

- 管线的"结构封顶"给的是 ≤ 3.72 note/小节，SOP §2 注意事项 4 明说**那是上界提示不是目标值**；
  知识 088 给的 イントロ 中位是 6.82 note/小节。我写的是 **4.63**。
- 取中的理由是**这一段真的没有鼓**（drums stem 低频 −89.3 dB，等于没有）：
  可踩的只有 pad 的起音与琶音的落点。知识 031 §2 的密度地板（归一 p10 ≈ 0.26）折算到本谱
  峰值 16 note 上是 ≈ 4.2 note/小节——**4.63 刚好压在地板上方**，不是空段。
- 知识 **088 §2** 说前奏是全曲星星最稀的地方（0.50 条/小节），我写 0.53 条/小节；
  但知识 **092** 同时说这是分布不是处方（只有 21% 的曲子前奏星星密于本曲均值）。
  本曲前奏是长混响 pad，**慢星星与长条是唯一贴得上的东西**，所以用它们而不是纵连族
  （知识 074 说 イントロ 归纵连族，本曲**整段不适用**——那里根本没有可纵连的连打）。

### 3.2 205 BPM 下"错位"几乎写不了，所以主力是连续拍滑

按知识 017 的海底谭形（头 → 错位音 → 启动拍，各隔一个八分），在 205 BPM 下每个八分只有 **146 ms**；
而滑完 `1-5` 这样的穿心之后，同一只手要在下一个头之前飞回起点——
在 120 BPM 的海底谭那里是 250 ms 走 4 格（16 键/秒），**在 205 BPM 是 146 ms 走 4 格 ≈ 27 键/秒**，
直接越过知识 015 的红线。这与知识 **072** 的实测一致（错位小节占比与 BPM 强负相关，
≥200 BPM 档只剩 12.2%）。

处理办法：

- **主力换成连续拍滑（知识 049）**——头与启动拍相隔一个四分（293 ms），而且**两手相位差一拍**，
  滑完的那只手有整整两个八分回位。全谱有十小节走这副骨架（m029 / m036 / m046 / m051 / m057 / m061 / m063 / m098 / m099 / m109），检测器认出其中 7 处（5% 小节，进主料）。
- **错位只留半小节**，放在 ドロップ2 的 m119 作为配置升级的标记：
  `1-5[8:1],2,1/8-4[8:1],7,8,,45,,`——两个循环之后立刻回双押，不让手连续飞。

### 3.3 ドロップ2 的"升级"走配置，不走密度

知识 002 / 031 §8 / 003：第二次高潮**踩音不变、配置升级**。本曲的升级清单：

| | ドロップ1（49–64） | **ドロップ2（105–124）** |
|---|---|---|
| 星星骨架 | 连续拍滑（单手一根、两手交替） | **双压连续拍滑**（知识 050，两手同相位各一根：m106 弧版 / m112 直星版 / m121 收束版） |
| 错位 | 无 | **有**（m119 半小节版） |
| 16 分 | 半小节短爆发（m059） | **整小节二连扫**（m123，8 组二连）+ m116 峰值小节 + m122 |
| 单双双单 | 四分双押 + 八分单点 | **满档**（m117 / m118：每个八分都有东西，双押与单点严格交替） |
| note/小节 | 8.25 | 10.70（+30%） |

密度只涨了 30%，**其余的强度由 note 种类与两手同时占用承担**。

### 3.4 出张与侧边双押：只用两招，并且回头量过

知识 **091**：生成端写不出出张，只能写出**逼出它的形状**——① 长条钉专属键；② 侧边双押。
知识 **064**：轻易不要写；**写了就要做好引导**。知识 **G14 / 091 的实测教训**：这两招很容易写过头。

本谱的做法与结果：

- **钉手出张 2 处**（有意为之，各写在段落的"呼吸点"）：
  - m044 `6h[2:1],,7,,2,,3,4,`——`6h` 钉左手，第 3 个八分的 `7` 只能交给右手；
  - m073 `3h[2:1],,2,,1,8,7,6,`——`3h` 钉右手，`2` 只能交给左手。
  两处都在**密度下探的小节**（B 段的两小节减压 / 减压段），符合知识 087「出张出现在过门与铺垫段落多于最后高潮」。
- **侧边双押 12 处**，全部写成 **C 型等距轮转**（`18 / 23 / 45 / 67` 沿环走；知识 030 用户原话的第三个例子，
  它自己就是引导），分布在 m042 / m047 / m053 / m095 / m111 / m120，六个小节各两组，
  每次换一个轮转起点与方向，避免同一形状连写。
- 其余出张是**星星轨道自己跨过去**（知识 087 类 3，官谱占 22.3%），出现在连续拍滑的链尾。
- **量过的结果**：出张 **19 处 = 22.75 ‰**（官谱中位 21.1 ‰、五首基线 12.1–29.0 ‰）；
  **出张 / slide = 0.2323**（官谱 0.232）。**没有写过头。**
- **软级的蹭 9 次**（撞尾 8 + 路径蹭键 1），来源是贴边弧 `3^6` / `7^4` 的轨道扫过沿途 A 区。
  知识 **091 §3**：48% 的官谱一次蹭都没有，**这一项不该当指标追**，这 9 次是贴边弧的自然产物、没有刻意加。

### 3.5 采音：舍哪一半

按知识 **089** 的三条线索排序（军鼓 → 重音 → 后面有空隙的那一下），**先删只有踩镲的格子**。
最典型的是 A 段（m021–m028）：鼓件里 hat 是连续八分而 kick/snare 只有 2–5 下，
谱面**只踩 kick/snare 与重音**，八分踩镲整片舍掉。
`{16}` 的四小节（m065–m068）是反过来的例子——那四小节鼓点本身是切分的，
所以谱面改写成 `{16}` 的跳拍**逐格对上鼓的 onset**（m067 / m068 的骨架轨候选 2/2 全踩）。

⚠️ 本轮没有解决 `e2e-trial-02` 的缺口 **G12**（"coverage 降不下来的真正原因是踩哪条轨"）：
检查器报的全曲采音方式分布是 **全踩 29% / 舍音 28% / 留白 9% / 判不出 33%**，
官谱 160 首是 59.2 / 24.3 / 8.4 / 8.1。**"判不出"高出四倍**，因为本曲有 31 个小节
（前奏 19 + breakdown 8 + 尾奏 4）骨架轨**一个候选都没有**——那是曲子本身的形态，不是写法问题。
把这 31 小节剔掉之后是 全踩 41% / 舍音 40% / 留白 13%，**舍音比官谱高、全踩比官谱低**。

## 8. 已知弱点与不确定处

**我最没把握的三处，按不确定度排序：**

1. **`&first` 的半拍归属**（analysis-notes §2.2 已标为"必须写明"）。
   全曲 onset 的拍内相位直方图有**两簇、间隔恰好半拍（0.1463 s）**。本谱取 `1.349`，
   依据是：乐曲本体的硬切入点 1.3478 s、all-in-one 的第一个 downbeat 1.35 s、
   加权质量 129.5 vs 90.7。**但鼓件分带统计对两簇的偏好只差 1 个百分点，这条歧义靠鼓点本身分不开。**
   → **若导入后发现整体错半拍，把 `&first` 改成 `1.2027`**（或 `1.4954`），谱面正文不用动。
   我没有听感，这一条只能靠用户耳朵判。

2. **本曲的难点到底该有多密**。918 note / NPS 6.13 是按**跨谱分布**算的
   （知识 004/031 的 13.5 档均值），**本曲没有官方谱可比**。

   「定数 → note/小节」锚在 BPM ≥ 200 上被实测证明系统性高估 3.1–3.7 note/小节
   ——我按 NPS 锚走（知识 031 §7 的规定），但**"NPS 锚在 205 BPM 上准不准"本身没有被单独验证过**。

### 10.4 这一节的边界

1. **减速段与尾奏的 BPM 是采信值不是实测值**。tempo map 里 195 段与 205 段标
   `measured`，其余标 `adopted`（音频在那几段分不开拍点）。**如果那几个值是错的，
   本节重排的落点也跟着错**——但网格换掉之后至少不再是"整段系统性偏"。
2. **采音层这一轮跑不了**：`song_analysis.json` 还是旧网格（`first=1.349` / 恒定 205），
   与新谱的小节线最大差 **>1 s**。检查器本轮新加了**网格漂移检测**，
   这种情况直接**跳过采音层并说明原因**，不再报一堆假的"整段留白"。
   要恢复采音层的对照，得用新网格重跑一遍音频分析。
3. **没在真机上跑过**（同 §9.7）。
4. **外部抄谱的 maidata 一个字没看**——只用了转述过来的 BPM 表；
   配置、摆位、note 全部出自本项目自己的设计意图表。

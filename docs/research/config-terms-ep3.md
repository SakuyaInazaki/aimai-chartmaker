## 3. 逐术语

### 3.0 前置知识 `[00:10–01:41]` → 知识 **047 / 048**

- **乐理（047）**：BPM＝每分钟四分音符数、每拍 `60/BPM` 秒；音符等分体系；小节＝强拍到下一强拍；拍号 `Y/X` 先读分母（几分音符当一拍）后读分子（每小节几拍）。**音游口语的"三分/六分/十二分音符"在乐理里不存在，指三连音族**。`[00:59]` **LastSamurai 标 BPM57，其实是 BPM171 的 3/4 拍**——**标注 BPM 与拍号都只是初始值**。
- **星星的容错（048）**：`[01:39]`「**星星头到达终点以后，大概会有前后 15 帧左右的容错，只要在这个时间内画完星星就能黄**」。agent 理解：它与 014 的启动拍共同框出 slide 的可行时间区间，**"提前快滑 / 留尾 / 同时处理"三族手法全部是在这个窗口里挪动"划完时刻"**；也解释了教程为什么把"蹭"当可接受的设计手段（**蹭得到但仍能黄 ≠ 无理**）。

### 3.1 连续拍滑 `[01:45–04:47]` → 知识 **049**

- **教程怎么讲**：「均匀的四分音间隔，打完第一个双压抬手等一拍，**从第二个四分音开始打完双压就开始左右轮流滑星星**」；识别窍门「**都是打 ○（普通 tap）那个手去滑星星**」；「**基础中基础配置，务必熟练掌握**」，后续的井字星星、防蹭出张换手、**八分音拍滑**都建立在它之上。
- **谱例（定位成功）**：`379-Contrapasso -paradiso--mas.txt` **m090–m095**（`{8}`@243）
  ```
  m090| 2-6[8:1],,2/7-4[8:1],,7/3-8[8:1],,3/6-2[8:1],,
  m091| 6/1-5[8:1],,1-3[8:1]/8-4[8:1],,18,,6,6,
  ```
  每个四分音的 tap 键**恒等于上一根星星头的键**（＝它的启动拍），与新头同刻构成双押。八分音版：`393-Panopticon-mas.txt` **m041 末→m042 前半 / m045 末→m046 前半**（`{8}`@110）。
- **agent 理解（手级）**：每个四分音换一次手；单手循环＝「拍头 →（一拍后）拍启动拍＋划 → 拍头」，两手相位差一拍。**新头压在上一根启动拍键位上时可不换手**（推断）。八分音版之所以难：启动拍恒为一个四分音符，头间距缩到八分后**同时有 2–3 根星星在飞**。
- **关系**：**049 是 017 错位的母型**（017＝049 + 八分夹键在别的键；053＝049 + 八分夹键在同一个键）。

### 3.2 双压连续拍滑 `[04:50–06:53]` → 知识 **050**

- **教程怎么讲**：「打完星星等一拍，接下来**只需要双压然后滑滑滑滑滑滑滑**，**能写得费体力也能写得很蹭**」。
- **谱例（定位成功）**：`431-猫祭り-mas.txt` **m034–m037**（`{4}`@160，定数/难度/BPM 三项全对）
  ```
  m034| 4-2[8:1]/5-1[8:1],4-8[8:1]/5-7[8:1],4-2[8:1]/5-1[8:1],4b-8[8:1]/5b-7[8:1],
  ```
  另有 `503-FFT-mas.txt` **m078–m079**（键对固定在 1/5）。
- **agent 理解（手级）**：两手各守一个键、**同相位**；每次按下**既是新一对的头、又是上一对的启动拍**；**段内不换手**。"费体力"＝放射跨度大，"很蹭"＝轨道贴回自己那对键的回程。红线是 030 的"禁侧边双押"——教程谱例的键对全是 {4,5} 或 {1,5}，正好绕开 23/67。
- **与 049 的可机检分界**：同一格内的星星头数量（1 个＝049 异相位，2 个＝050 同相位）。

### 3.3 CYCLES 型星星 / 马洼路 `[06:56–09:06]` → 知识 **051**

- **教程怎么讲**：「**每次滑完都要尽快抬手避免蹭到下一个星星头**，滑**里面的两条**星星时**手尽量靠中间**」「**个人差较大**……讲究一个**快滑快抬**，**有邪道手法**」。另有"**类 CYCLES**"子标签（未给判据）。
- **谱例（粗定位）**：`258-CYCLES-mas.txt` **m041–m056**（帧达成率 ≈76.6% → m056，段长 ≈16 小节吻合）
  ```
  m049| 1p5[8:1]/5p1[8:1],5^8[8:1]/1^4[8:1],1p5[8:1]/5p1[8:1],5^8[8:1]/1^4[8:1],
  ```
  **同一对端点的两条反向曲线同时出现**，下一格立刻换成一对贴边弧，**头就落在刚被划过的区域里**。
- **agent 理解（手级）**：两手同相位、各守一条镜像曲线、**段内不换手**。本条特有的风险是"**划完的手把下一个星星头蹭掉**"——与 010 方向相反，建议单列检测项。"手靠中间"推断为**避免两手在交叠区互撞**。

### 3.4 菱形星星 / 类菱形星星 `[09:09–10:16]` → 知识 **052**

- **教程怎么讲**：**全部原文只有一句**——「**一个字形容就是蹭，无论是正攻还是邪道，能黄就是好**」；压轴谱例批注「**集大成之作 / 当用邪道的人多了，正攻就变成了邪道**」。
- **谱例（agent 依形态定位）**：`663-KING is BACK!!-mas.txt` **m032–m038**
  ```
  m032| 1-5[16:1]/2-5[16:1],,3,,1b/2b,,,,8-4[16:1]/7-4[16:1],,6,,8b/7b,,,,
  ```
  相邻两键出发、汇到同一终点 → 两条轨道夹出狭长菱形缝；两格后缝下落一个 tap `3`；再两格是 `1b/2b` 启动拍。集大成＝`325-ロストワンの号哭-remas.txt` **m075–m079**。
- **agent 理解（手级）**：两手各领一条边、不换手；**夹缝中的那个 tap 由离它近的那只手顺手补**，手掌必然从自己的轨道上方扫过 → **没有一种手序能避开，只能靠 048 的窗口抢时间**。因此**它是"靠判定容错解"而不是"靠手序解"的配置**，建议列为「识别得出、但不主动生成」。
- **⚠️ 定义是 agent 补的**（教程只给评价不给结构），标存疑。

### 3.5 夹键拍滑 `[10:19–14:28]` → 知识 **053**

- **教程怎么讲**：「把夹键放上去以后变得更抽象了，**由拍滑变成了八分音拍三下然后滑星星**」；`[11:21]` 亲自演示"**把夹键移开，这不就是**（拍滑）"。
- **谱例（定位成功）**：`400-ECHO-mas.txt` **m022 / m026**（`{8}`@140，三项全对）
  ```
  m022| 1/8-4[8:1],8,3-1[8:1]/8,3,3/5-7[8:1],5,1-5[8:1]/5,1,
  ```
  按键位摊开＝ **8,8,8 → 3,3,3 → 5,5,5 → 1,1,1**：**每个键连吃三个八分音**，第一下是星星头、第三下是启动拍，相邻两组首尾同刻咬合。同曲 m020/m024 是"把夹键抽掉"的对照组。
- **agent 理解（手级）**：单手在自己的键上连打三个八分、第三下划出；另一只手在第三下的同刻按下新头。**每四分音换一次手**，与 049 同构。难点在**识别**（三下叠在同一个键上，看不出哪下该划）而非体力。

### 3.6 海底谭错位 `[11:29–14:28]` → **017 补充**（不另立条目）

- **教程怎么讲**：「**海底谭就是指这类一手打夹键的同时去滑星星的夹键错位，本质就是在四分音拍滑间插入了八分音符（或者其他节奏）**」「**理解其本质有助于攻克难度更高的错位**」「海底谭**既不是错位的起点也不是错位的终点**……下位入门曲还有很多（如易碎、**白妄想**）」。`[13:59]` 另给一屏"夹键错位练习曲"（13.0–13.4，画面注「个别不是海底谭错位」）。
- **谱例**：`336-ウミユリ海底譚-mas.txt`（13.4 / MASTER / BPM120，与 017 原有谱例同一首同一难度）。
- **agent 理解**：与用户讲授（017）**无冲突**。教程"一手打夹键的同时去滑星星"字面有歧义，**按 017 原文定性：错位音固定由滑动的那只手自己拍**（头 → 错位音 → 启动拍 → 划）。教程多出来的价值是把错位放进"拍滑家族"坐标系（049/053/017 三分表）与给出难度梯度（入门 13.0–13.2 → 标准 13.4 → 高阶 14.0+）。

### 3.7 换手 `[14:31–17:47]` → 知识 **054** + 007 补充

- **教程怎么讲**：「**星星头和星星本体是两个独立的部分，并不一定要在一个手顺里解决**，比如左手拍了星星头用右手去滑星星」「一些谱面配置会**有意的引导去换手**」；`[16:58]`「掌握换手以后……**怎么打得舒服就怎么来**；反过来说，平常都是在换手的地方**你选择不换手也能获得不一样的乐趣**」。**教程自带换手难度阶梯**：小换手 11.8/12.1 → 换手拍滑 12.7/12.8 → 加入了夹键 12.6/12.8 → 更频繁的换手 13.2/13.3 → 「会就是会，不会就是不会」ECHO 13.5。
- **谱例**：**未能精确定位到小节**——换手是手序现象不是谱面形状，同一段谱既可换也可不换，教程画面也没标换手点。旁证：`699-幽闇に目醒めしは-mas.txt` m048/m056、`400-ECHO-mas.txt` m020–m026。
- **agent 理解（手级）**：换手的**前提是 014 给的整整一拍交接时间**，代价是接手那只手这一拍必须空出来。"有意引导"的三种做法（推断）：① 把下一个必打 note 放在拍头手正前方；② 用 hold/第二根星星钉住一只手；③ **让终点落到另一只手的半圈**——按 007「划 slide 的手＝末尾所在半边」，**终点过中线就等于点名换手**，这是"引导换手"唯一可机检的形式。
- **对本项目最硬的一条**：**手序分配器不能假设"拍头手＝划轨手"**。

### 3.8 穿心 / 风车 / 大风车 `[17:51–22:37]` → 知识 **055**

- **教程怎么讲**：「**穿过圆心，以顺时针或逆时针，在相邻键位上连续出现的直线星星**；**一组 3 根就可称穿心配置，转一圈的可称大风车**；**考验滑星星的精度**」。**四种处理思路**：正攻（「大量出张动作发生，手容易打结……**可以适当扭腰**」）／换手（「注重手序设计」）／打完星星头直接滑（「**只要滑得够快就不用防蹭**，适用于比较快且没有夹键的穿心」）／同时处理（「**从第二根开始滑，滑的时候同时把第一根滑掉**」）。形态阶梯：只有星星头 → 一圈 → 带夹键 → 带夹键一圈 → 带启动音 → 启动音+夹键 → 复杂节奏 → 圣剑穿心。

### 3.10 一笔画 `[24:26–28:35]` → 知识 **057** + 007 补充

### 3.13 同起点拍滑 / 发牌段 / 电车段 `[35:10–37:13]` → 知识 **060**

- **教程怎么讲**：「也可以叫**同头星星**……**星星从一个起点开始向其他键位放射**，正攻情况下**左右手每次交替拍滑处理一根星星**」「（也可以叫**发牌段**）」「**考验防蹭**，部分曲目按**左右左右的手序打会有出张星星**」。**三种处理手法**：① 一手打星星头一手滑星星（白火花、Selector）；② **同时处理：位置相邻星星，8 分音 75BPM / 4 分音 150BPM**（**全片唯一的数值阈值**）；③ 画"Z"字（深海少女标准谱、白香水 Fragrance）。`[36:52]` **电车段**：「大量的连续的单起点拍滑，**不提前背板根本看不清顺序**，还很蹭，**基本上第三个星星头开始就得切内屏打**」；`[37:02]`「电车段的下位，东方电车，**星星头全带保护**」。

### 4.1 三个"家族"的手级归纳

1. **拍滑家族（异相位、每拍一换）**：049 → 053 → 017（插入的八分音落在哪个键） → 062（同骨架 + 故意写蹭） → 059/060（同骨架 + 特定摆位）。**共同手级特征：拍头手与划轨手是同一只，两手相位差一拍。**
2. **同相位家族（不换手、两手做镜像的同一件事）**：050 → 051 → 052。**共同手级特征：段内手序固定，难度押在体力与判定容错上。**
3. **双任务家族（左右长期分工，一手一条线）**：058 ↔ 027 ↔ 033 ↔ 061 ↔ 045。**共同手级特征：段首定下分工就不再换；难点是左右协调与抓两条不同的节奏。**

> **一条横贯的观察**：本期 19 个术语里，**只有 054 换手、055b 同时处理、060② 同时处理**这三条会改变"一只手能吃几个音"的账；其余全部可以在"一只手一次只处理一个 note 对象"的模型下表达。这对 `hands.py` 是个好消息——**默认模型不必一上来就支持"一手多音"，只要为这三条留出扩展点。**

## 6. 给 `tools/chart_analysis/hands.py` 与配置识别器的建议

> ⚠️ **本节只是建议，本轮没有改动 `tools/` 下任何文件**（`hands.py` 由另一条子代理在写）。

### 6.1 对手序分配器（`hands.py`）的 5 条

1. **不能假设"拍星星头的手＝划轨的手"**（知识 054）。至少要把 slide 拆成 `head`（一次按压）与 `track`（一段占手区间）两个可独立分配的对象，并允许二者落到不同的手。**这是本轮最硬的一条结论**，因为本片有整整一节在讲它。
2. **占手区间的两端由两条不同的机制决定**：**最早开始 = head + 一个四分音符**（知识 014）、**最晚结束 = 引导星到终点 ± 15 帧**（知识 **048**）。**建议把 slide 的占手写成一个可伸缩区间 `[t_start_min, t_end_max]` 而不是一个固定时长**——本片一半以上的"手法"（提前快滑 / 留尾 / 同时处理 / 撞过去）都是在这个区间里挪动。
3. **用 007 的"末尾半边"规则当分配打分项，而不是硬约束**。本片 `[16:58]` 明说"该换手的地方不换也能打"，`[35:10]` 明说"按左右左右打会有出张星星"——即**违反该规则不等于不可玩，而是代价（出张）**。建议输出"**出张次数**"作为该段的代价指标，正好对上知识 043。
4. **给三条"一手吃两个对象"的手法留扩展点**（不要默认开启）：055b 穿心·同时处理、060② 同起点·同时处理（阈值 ≈400 ms）、042 狗刨。默认模型按"一手一次一个对象"跑，这三条作为可选放宽项。
5. **起手手的奇偶性是一个全局自由度**：60 的"相反起手能规避出张"说明**同一段的两种起手会给出完全不同的代价**。建议分配器对每个星星段**两种起手都跑一遍，取代价低者**，并把差值报出来（差值大＝该段"必须选对起手"，是谱师意图的信号）。

### 6.3 三条跨规则的工程提醒

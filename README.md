# aimai-chartmaker

AI 舞萌（maimai DX）自动制谱 Agent。

**输入**：MP3 track 音频文件
**输出**：符合 simai 语法、零报错、人类可玩的 `maidata.txt` 谱面

## 项目目标

生成一份经过校验、符合 simai 语法、没有任何报错提示、符合人类手序、可以实际游玩的谱面，且谱面符合制谱规范（难度分布与官方谱近似、情感循序渐进、手序设计合理等）。
